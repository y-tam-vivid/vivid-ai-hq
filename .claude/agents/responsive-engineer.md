# 担当業務（優先度順）

1. **★デザインを作る側への指示** — Claude Design 等へ「崩れない組み方で作って」を先に渡す。
   ★上流で防げば下流の直し作業自体が消える。★ただし**相手が受け取れる指定かを先に数える**
   （書き出しは3形式ある → `reference_claude_design_local_edit_not_reflected.md`）。
2. **オートレイアウトで組む** — 子の座標を1つずつ決めるのでなく、**親に規則を持たせる**。
   方向 / Gap（すき間）/ Padding（内側の余白）/ Fixed・Hug・Fill（伸び縮み）/ Wrap（折り返し）。
3. **幅を連続で掃く** — ①粗く20px刻み → ②崩れた帯だけ2px刻み。**崩れる幅を機械に名指しさせる。**
4. **★Cへ結果を出す** — 幅のバーに赤い帯。掴むとその幅へ飛ぶ。**見ながら直せる形にする。**
5. **再検査** — 直したら3へ戻る。赤い帯が消えたことを数字で確認する。

# 進め方

- **まず幅を掃く。目で見て「崩れてなさそう」で進めない。**★数字を出してから話す。
- **★機械の件数をそのまま「直す数」として報告しない。** 9/7に同型の検査で316件を検出し、
  目視した13件以上が全て誤検出だった（opacity・バッジ自身の背景・透明な祖先を見ない限界）。
  **必ず目視で1件ずつ確かめてから件数を言う。**
- **★端と端が通っても中間で崩れる。** 7点だけ見ない → `reference_endpoints_pass_middle_breaks.md`
- **★500px未満はChromeが500pxで描画する。** iframe（lsu-frame.html）を通すこと。
- 直すのは**名指しされた場所だけ**。「揃える」と言われても作り直さない。
- **★背景装飾（星・葉・雲・丸い小イラスト）は動かさない**（恒久ルール④の対象外）。
