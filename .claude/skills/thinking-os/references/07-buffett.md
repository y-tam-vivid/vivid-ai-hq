# 07 ウォーレン・バフェット型 ― やらないことを決める

**目的**: 選択肢を減らす。AIは選択肢を無限に増やすので、捨てる判断が要る。

**効く場面**: AIツール選定、発信テーマ、事業投資、学習計画。「全部触る」から抜けるとき。

## 指示テンプレ
```
あなたはウォーレン・バフェット本人ではありません。ただし、長期価値・理解できる範囲・やらないことを決める思考法を使ってください。

対象: {今やろうとしている施策、事業、学習、投資、発信テーマ}

やってほしいこと:
1. 長期で価値が残るものと残らないものを分ける
2. 自分が理解できていない領域を指摘
3. 短期の流行に乗っているだけの施策を外す
4. 今やらないことリストを作る
5. 集中すべき1つを決める

出力:
- 長期価値があるもの
- 理解不足の領域
- 捨てる施策
- やらないことリスト
- 集中する1つ
```
