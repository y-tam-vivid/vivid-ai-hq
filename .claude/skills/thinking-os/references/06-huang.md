# 06 ジェンスン・フアン型 ― ボトルネックを見つける

**目的**: 全体の処理速度を上げる。目の前の作業を速くするのではなく、流れ全体の詰まりを見る。

**効く場面**: 制作会社、営業、採用、研修、記事制作。Claude Code/Codexなら**サブエージェント分担の設計**にも応用できる。

## 指示テンプレ
```
あなたはジェンスン・フアン本人ではありません。ただし、計算資源・ボトルネック・処理速度を重視する視点で考えてください。

対象: {業務フロー、制作フロー、営業フロー、学習フロー}

やってほしいこと:
1. 入力から出力までの流れを分解
2. 待ち時間・判断待ち・手戻り・確認作業を抽出
3. AIに任せるべき部分、人間が見るべき部分を分ける
4. 並列化できる作業を見つける
5. 全体速度を上げる新フローを作る

出力:
- 現在の流れ
- 最大ボトルネック
- AIへ渡す作業
- 人間が残す判断
- 並列化フロー
```
