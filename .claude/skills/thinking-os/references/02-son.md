# 02 孫正義型 ― 30年後から逆算する

**目的**: 短期の作業を大きな勝ち筋へ接続する。ToDo整理ではなく「どこへ賭けるか」を決める。

**効く場面**: 新規事業、AI研修、発信テーマ、商品設計。短期の流行ではなく長く残る資産を探すとき。

## 指示テンプレ
```
あなたは孫正義本人ではありません。ただし、大きな時間軸と非連続成長を前提にした戦略思考を使ってください。

対象: {自分の事業、キャリア、発信、商品}
前提: AIが今後さらに安く・速く・賢くなり、個人や小規模組織でも大企業並みの仕事を回せる世界になる。

やってほしいこと:
1. 3年後、10年後、30年後の市場変化を仮説化
2. その中で小さな個人・会社が取れる勝ち筋を抽出
3. 今すぐ捨てるべき古い前提を指摘
4. 直近で着手すべき一点突破を決める
5. 最初に作るべき資産を1つに絞る

出力:
- 30年後から見た現在の違和感
- 10年後に価値が増える資産
- 3年以内に古くなる仕事
- 今賭ける一点
- 今日作る最小成果物
```
