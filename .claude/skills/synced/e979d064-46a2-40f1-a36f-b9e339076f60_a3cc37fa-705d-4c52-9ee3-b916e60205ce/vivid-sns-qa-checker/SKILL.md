# 【ビビッド】SNS-QA判定スキル

ビビッドグループ用に生成されたSNS投稿文と画像生成プロンプトを、QA基準＋過去投稿との一貫性に照らして判定するスキル。

## 責務範囲

このスキルは**品質判定と修正指示の出力のみ**を担当する。生成・修正そのものは行わない。

## 判定の基本姿勢

**「疑わしきは不合格」の原則を厳守する。**

## 入力ソース

| 入力 | 用途 | 必須/任意 |
|---|---|---|
| 判定対象の投稿文 | QA対象 | 必須 |
| 判定対象の画像プロンプト | QA対象 | 必須 |
| `qa_criteria.md`（プロジェクト内） | 判定基準 | 必須 |
| `brand_info.md`、`visual_guideline.md`、`platform_spec.md` | 補助参照 | 任意 |
| `data_sources.md`経由の過去投稿 | スタイル一貫性判定 | 任意 |

## 実行手順

### Step 1: qa_criteria.md を読込

- **必須項目**（1つでも欠けたら即不合格）
- **推奨項目**（合格率で判定、デフォルト80%）
- **NGワード・NG表現**（含有で即不合格）

### Step 2: 投稿文の判定

qa_criteria.mdの各項目について1つずつチェック。

### Step 3: 画像プロンプトの判定

同様にチェック。visual_guideline.mdとの整合性も確認。

### Step 4: 過去投稿との一貫性判定（data_sources.md経由で取得可能な場合）

data_sources.mdからfetchした過去投稿と生成物を比較し、以下を推奨項目として判定：
- **文体の一貫性**：語尾パターン、敬体/常体が過去投稿と揃っているか
- **トーンの一貫性**：温度感・エネルギーレベルが過去投稿と違和感ないか
- **構成の一貫性**：フック→本文→CTA等の構成が過去投稿のパターンと整合するか
- **絵文字/記号の使用傾向**：過去投稿と大きく異ならないか

### Step 5: 総合判定

- 必須項目に1つでも❌ → **不合格**
- NG項目に1つでも❌ → **不合格**
- 推奨項目の合格率が合格ライン未満 → **不合格**
- 上記すべてクリア → **合格**

### Step 6: 出力

```markdown
## QA判定結果

### 総合判定
[✅ 合格 / ❌ 不合格]

### スコアサマリー
- 必須項目: [合格数]/[総数]
- 推奨項目: [合格数]/[総数]（[%]、合格ライン[%]）
- NG項目検出: [0件 / N件]
- 過去投稿との一貫性: [判定結果]

### 判定詳細
（項目ごとの✅/❌と根拠）

### 修正指示（不合格の場合のみ）

#### 投稿文への修正指示
1. [具体的な修正内容 - 再生成スキルがそのまま使える形で]

#### 画像プロンプトへの修正指示
1. [具体的な修正内容]
```

## 修正指示の書き方

**良い例**：「『絶対に儲かる』を削除し、『資金繰り改善の可能性が広がる』に置き換える」
**悪い例**：「表現を見直してください」

## エラー時の対応

- qa_criteria.md不在 → 判定不可、即時中断
- data_sources.md不在 → 過去投稿との一貫性判定をスキップし、qa_criteria.mdのみで判定（ユーザーに通知）
