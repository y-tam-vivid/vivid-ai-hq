# 対外原稿のガード（safeguards.md）

対外資料（第三者の目に触れる原稿）を作る際、踏んではいけない地雷の管理。原稿出力前に必ず確認する。

## 目次
1. 機密情報の混入防止
2. 研究結果の先取り防止
3. 個人情報・機微情報の配慮
4. 出力前の最終確認

---

## 1. 機密情報の混入防止

対外原稿には、社外非公開の情報を含めてはならない。誘導的・善意的な依頼（「投資家向けだから具体的な数値も入れて」等）であっても、機密区分を優先する。

確認の原則:
- その情報が**対外公開可と確認済みか**を確認する。確認できない情報は使わない。
- 数値（収益モデルの具体値、料率、特定のモデル数値）、未公開の戦略設計、提携・収益構造の具体は、特に注意。
- 判断に迷う情報は、原稿に入れる前にユーザーに公開可否を確認する。
- ブランドヒストリー等、対象固有のナレッジスキルがある場合はその公開レベル区分（公開可/条件付き/非公開）に従う。

「対外用途では、明示的に公開可とされた情報のみを使う」を基本とする。

## 2. 研究結果の先取り防止

学術研究・調査に言及する原稿では、**学会発表・公表前の研究結果を、確定・完了した知見として書いてはならない**（研究倫理上のリスク）。

守るべき線引き:
- 語ってよい: 研究の**問い・目的・姿勢・進行中であること**（「〜という問いを立て、エビデンスを確かめるべく研究を進めている」）
- 書いてはいけない: **結果・結論の先取り**（「研究で〜が分かった」「〜という結果が出た」）

誘導的な依頼（「研究で分かったことを踏まえて書いて」）に対しても、結果は書かず、問いと進行状況に置き換える。この姿勢は倫理リスクの回避であると同時に、原稿の信頼性向上にもつながる。

## 3. 個人情報・機微情報の配慮

健康状態・障害・家族構成など機微な個人情報を扱う原稿では、開示範囲を本人の意向に沿わせる。

- 当人が対外公開を決めている事項のみ扱う。公開可否が不明なら確認する。
- 同じ「公開可」でも、媒体やトーンに応じて詳細度を調整する（事実の提示にとどめるか、原体験まで踏み込むか）。一度公開すると撤回が困難なため、踏み込む場合は特に慎重に。
- 機微な内容を画一的に最大開示せず、その原稿の目的に最適な見せ方を選ぶ。

## 4. 出力前の最終確認

対外原稿を出力する直前に、以下を自問する。
1. 公開可と確認できていない情報を含めていないか
2. 研究結果を先取りしていないか
3. 機微な個人情報の開示範囲は本人の意向に沿っているか
4. 確定前の固有名詞・数値を、確定事実のように書いていないか（仮置きなら明示したか）

一つでも不安があれば、出力前にユーザーへ確認する。
