# 文体ルール集（style_rules.md）

原稿の文体を決める際の参照。**推奨デフォルト**を起点としつつ、案件に合わなければ**汎用選択肢**から選ぶ。文体は原稿全体で一貫させること。どの文体を採るか迷う場合はユーザーに確認する。

## 目次
1. 推奨デフォルト
2. 汎用選択肢（人称）
3. 汎用選択肢（語尾・敬体常体）
4. 文体を決める際の確認フロー
5. その他の表記ルール

---

## 1. 推奨デフォルト

今回の制作で確立し、有効に機能した文体。三人称の人物紹介・インタビュー記事で特に推奨。

- **地の文: 三人称・である調**（例:「田村は幼少期からボランティアが身近な環境で育った」「転機は30歳の頃だった」）
- **会話文・引用文: 一人称・ですます調**（例:「〜実感したんです」「〜貢献したい想いがあります」）

この使い分けにより、地の文の客観性と、会話文の本人の肉声が両立する。インタビュー記事・人物紹介記事の標準形。

注意点:
- 一文の中で人称・敬体が混ざらないようにする
- 一人称の語り口を地の文に出したくなったら、その部分を会話文（カギ括弧）として切り出す

## 2. 汎用選択肢（人称）

案件に応じて選ぶ。

- **三人称**: 「田村は〜」。人物紹介・記事・第三者視点の紹介文。客観性・信頼感が出る。
- **一人称**: 「私は〜」。自己紹介文・本人寄稿・代表メッセージ。当事者の肉声・熱量が直接伝わる。
- **二人称志向**: 「あなたは〜」。読者への語りかけ。広告コピー・LP・行動喚起。

## 3. 汎用選択肢（語尾・敬体常体）

- **である調（常体）**: 簡潔・断定的・引き締まった印象。記事・レポート・論説。
- **ですます調（敬体）**: 丁寧・柔らかい印象。代表メッセージ・顧客向け案内・寄稿。
- **混在運用**: 上記「推奨デフォルト」のように、地の文と会話文で敬体・常体を意図的に分ける運用。記事で本人の声を引用する場合に有効。

## 4. 文体を決める際の確認フロー

1. 文書の種類と読者を確認する（記事か、自己紹介か、提案書か。誰が読むか）
2. 推奨デフォルトが合うかを判断する（三人称記事なら高確率で合う）
3. 合わない場合、汎用選択肢から候補を2つ程度、メリット・デメリットを添えて提示し、ユーザーに選ばせる
4. 決定した文体を原稿全体に一貫適用する

## 5. その他の表記ルール

- **表記統一**: 同義の語が複数表記で混在しないようにする（例:「福祉とお金」と「福祉×お金」は一原稿内で統一）。一覧表記・送り仮名・英数字の全角半角も統一。
- **「たり」の用法**: 「〜たり」を使う場合は原則として連続させる（「Aしたり、Bしたり」）。単発で使うと校正ルール上の指摘対象になりやすい。一つしか挙げないなら言い切りに変える。
- **第三者表記**: 第三者を指す場合の語を統一する（例:「方々」と「人々」が混在しないよう、文書の基調に合わせる）。
- **固有名詞・数値**: 確定前の固有名詞・数値は仮置きとし、確認事項として明示する。確定情報での差し替えを前提に進める。
