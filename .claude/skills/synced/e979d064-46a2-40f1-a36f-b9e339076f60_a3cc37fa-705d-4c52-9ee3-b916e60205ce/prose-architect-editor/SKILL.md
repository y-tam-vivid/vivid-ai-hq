# 文章構成・校閲アーキテクト

対外向け長文原稿を、構成設計→執筆→校閲の一連のフローで一定品質に仕上げるためのスキル。

## このスキルの全体フロー

原稿制作を二つのフェーズに分けて進める。多くの依頼はどちらか一方、または両方にあたる。まず依頼が「これから構成を考える/書く」段階なのか「すでにある原稿を直す」段階なのかを見極め、該当フェーズに入る。

- **フェーズ1: 構成設計**（方向性・力点の確定 → 構成骨格の設計）
- **フェーズ2: 執筆・校閲**（文体適用 → 推敲 → 校閲チェック → 文字数調整）

詳細な手順は参照ファイルに分けている。各フェーズに入る際、対応する参照ファイルを読むこと。

- `references/composition.md` — フェーズ1の手順（力点の言語化、構成パターン、確認の進め方）
- `references/editing.md` — フェーズ2の手順（推敲・校閲チェックリスト、文字数管理）
- `references/style_rules.md` — 文体ルール集（推奨デフォルトと汎用選択肢）
- `references/safeguards.md` — 機密・研究倫理など、対外原稿で踏んではいけない地雷の管理

## 進め方の基本姿勢（最重要）

このスキルの利用者は、**結論ファースト・メリデメ提示・選択肢明示**のコミュニケーションを好む。以下を徹底する。

1. **着手前に前提・制約を整理し、確認してから進む。** 曖昧な指示を勝手に解釈しない。解釈の分岐点や未確定事項をまとめて提示し、確認を得てから実行する。これは本スキルの核心であり、今回の制作プロセスで最も価値を発揮した姿勢である。
2. **大きな構成変更・方向転換は、一気に書き換えず、まず設計図（構成案）を言語化して合意を取る。** 認識のズレがあると全体の手戻りになるため、骨格確認を先行させる。
3. **選択肢を複数提示 → ユーザーが選択 → 実行、のパターンを基本とする。** 文体・構成・表現に複数の妥当な選択肢がある場合、それぞれのメリット・デメリットを添えて提示し、ユーザーに選ばせる。推奨案がある場合は理由とともに明示する。
4. **一度の質問は要点を絞る。** ただし着手前の確認では、分岐点をまとめて提示してよい。

## フェーズ1: 構成設計（着手時に composition.md を読む）

原稿を「いきなり書き始めない」。まず次の順で土台を固める。

1. **現状の方向性を言語化する。** 既存原稿やドラフトがある場合、その構成と力点を一度言葉にして、ユーザーと認識を揃える。「どこを変えたいか」の議論はその後の方が速い。
2. **力点を決める。** 何を主軸に据えるか（人物の原体験か、事業の新規性か、論点の説得か等）を確定する。
3. **構成骨格を設計し、合意を取る。** 時間構成（現在→過去→未来 など）や論理構成のパターンから選び、骨格を提示して確認を得る。
4. 確定後、執筆フェーズへ移る。

## フェーズ2: 執筆・校閲（着手時に editing.md と style_rules.md を読む）

1. **文体ルールを適用する。** style_rules.md の推奨デフォルト（地の文＝三人称・である調／会話文＝一人称・ですます調 など）を確認し、案件に合わなければ汎用選択肢から選ぶ。文体は原稿全体で一貫させる。
2. **執筆または改稿する。**
3. **校閲チェックを行う。** editing.md のチェックリストに沿って、推敲の二重表現・重複、文体の混在、助詞の重複・脱字、文字数を点検する。
4. **文字数を機械的に計測する。** 目視に頼らず、スクリプトやコマンドで数える（editing.md に方法を記載）。指定字数がある場合は厳守。
5. **safeguards.md のガードを確認する。** 対外原稿なら、機密情報の混入と、研究結果の先取り（学会発表前の知見を確定事実として書く等）がないかを必ず確認する。

## 成果物の出力

- 完成原稿をWord（.docx）等のファイルで求められた場合は、該当するドキュメント作成スキル（docx等）の手順に従う。
- ライターや第三者に戻す前提の原稿では、**確認事項・修正趣旨を文書冒頭やコメントとして明示する**と差し戻しがスムーズ（今回の制作で有効だった運用）。
- バージョン管理: 大きな改稿は版数（第N稿）を明示し、版ごとの変更点サマリーを添える。

## 完了前の自己点検

原稿を出力する前に必ず確認する。
1. 構成・力点はユーザーと合意したものになっているか
2. 文体ルールは一貫しているか
3. 推敲の二重表現・重複・脱字が残っていないか
4. 指定文字数を満たしているか（機械的に計測したか）
5. 機密情報の混入・研究結果の先取りがないか（対外原稿の場合）
