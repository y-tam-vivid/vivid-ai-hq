# 語彙・定型パターン集

SKILL.md の「関係の温度で語彙だけ切り替える」を実行するための参照資料。構造（結論→理由1行→次の一歩）は共通で、語彙だけを差し替える。

## 目次

1. 関係性別の語彙対応表
2. 類型別の骨格パターン
3. 保留語の言い換え表

5. 断り切るための終端表現

## 1. 関係性別の語彙対応表

| 場面 | 相手 | 文体 | 長さの上限 | 注意点 |
|---|---|---|---|---|
| 私的・近い | パートナー、家族、旧友 | 常体。敬語を外す | 2〜3行 | 丁寧すぎると距離が出て、かえって気まずさが伝わる |
| 私的・やや距離 | 知人、コミュニティ関係 | 敬体だが柔らかく | 3行 | 定型文に寄せすぎない。一言だけ体温を残す |
| 仕事・継続関係 | 取引先、協力者、支援機関 | 敬体。簡潔 | 4〜6行 | 次のアクションを必ず明示する |
| 仕事・単発 | 初回商談、紹介経由 | 敬体。やや硬め | 4行 | 断る場合も相手の面子を潰さない |
| 断ち切りたい | 営業、勧誘、しつこい連絡 | 敬体。言い切る | 2〜3行 | 理由を厚く書かない。書くほど反論材料になる |

## 2. 類型別の骨格パターン

**初動型（まだ何も返していない）**

```
〈返答の結論、または期日の提示〉
〈理由を1行、任意〉
〈次の一歩〉
```
例：「ご連絡ありがとうございます。◯日までに可否をお返しします。」

期日を切るだけで、判断を先送りにしたまま保留を終わらせられる。最も負荷が低い型。

**保留放置型（曖昧に返したまま止まっている）**

```
〈保留していたことへの一言〉
〈今回の結論を明言〉
〈次の接点、または「また誘って」〉
```
例：「返事あいまいなままでごめん。今回は見送ります。次は行きたいから、また声かけて。」

「見送ります」「行きません」を必ず含める。ここを濁すと同じ状態に戻る。

**遅延型（期限を過ぎている）**

```
〈謝罪1行〉
〈本題の結論〉
〈次の一歩〉
```
謝罪を先頭で完了させ、本題に移る。理由を積まない。

**撤回型（一度受けたものを断る）**

```
〈申し訳ないという一言〉
〈できない旨を明言〉
〈代替案 or 次の接点〉
```
代替案は「いつ」を具体化する。「また今度」は代替案として機能しない。

## 3. 保留語の言い換え表

| 使わない | 置き換える |
|---|---|
| 行けたら行きます | 今回は見送ります／参加します |
| また連絡します | ◯日までに連絡します |
| 前向きに検討します | ◯日に可否をお伝えします／今回は見送ります |
| 都合がつけば | ◯日なら伺えます |
| 落ち着いたら | ◯月以降で改めて相談させてください |
| 検討させてください（期日なし） | 一度持ち帰り、◯日までにお返事します |

原則：期日か結論のどちらかが必ず入っていること。両方欠けている文は保留であり、送っても頭からタスクが消えない。

## 4. 遅延謝罪の1行パターン

長さの順に並べてある。上ほど軽く、下ほど重い局面向け。

- 返信遅くなりました。
- ご連絡が遅くなり失礼しました。
- お返事が遅くなり申し訳ありません。
- 長らくお待たせしてしまい、申し訳ありませんでした。

いずれも1行で完結させ、直後に本題の結論を置く。「バタバタしておりまして」等の事情説明は入れない。事情を書くほど、次回の遅延時に同じ説明が必要になり、送信の負荷が上がっていく。

---

## 5. 断り切るための終端表現

再提案の余地を残さずに終わらせたい相手（営業・勧誘など）に使う。

- 今回は見送らせていただきます。今後のご連絡も不要です。
- 必要になりましたら、こちらからご連絡します。
- 検討の予定はありませんので、恐れ入りますがご連絡は控えていただけますと幸いです。

避けるべき表現は「今は」「タイミングが合えば」「またの機会に」。いずれも相手に再アプローチの根拠を与え、同じ連絡が再発する。断り切れないまま連絡が繰り返される状態こそが、心理的負荷の主因になる。
