# 【ビビッド】SNS画像プロンプト生成スキル

ビビッドグループ用に、SNS投稿文に添える画像のプロンプトをNano Banana（Gemini 2.5 Flash Image）向けに最適化して生成するスキル。

## 責務範囲

このスキルは**画像生成プロンプトの作成のみ**を担当する。

## Nano Banana 最適化の原則

1. **シーン記述型**：キーワード羅列ではなく、自然言語の文章で情景を描写
2. **構成要素を明示**：被写体・構図・ライティング・スタイル・色調を文章中に織り込む
3. **テキスト描画は短く**：画像内文字は短いキーフレーズに限定（10文字以内推奨）
4. **キャラ一貫性**：シリーズ投稿の場合、人物の特徴を毎回同一の文言で記述

## 入力ソース

| 入力 | 用途 | 必須/任意 |
|---|---|---|
| 投稿文 | プロンプト生成の主軸 | 必須 |
| `visual_guideline.md`（プロジェクト内） | 世界観・色調・スタイル定義 | 必須 |
| `brand_info.md`（プロジェクト内） | ブランドカラー・人格情報 | 任意 |
| `data_sources.md`（プロジェクト内） | 過去投稿画像の参照先 | 任意 |

## 実行手順

### Step 1: 入力の確認

- 投稿文が提供されているか確認
- `visual_guideline.md`を読み込み、世界観・色調・避けるべき表現を把握
- `data_sources.md`があれば、過去投稿の画像トーンを参照（取得可能な範囲で）

### Step 2: 投稿文の感情トーン抽出

投稿文から以下を抽出：
- **感情トーン**（例：希望、信頼、温かさ、躍動感）
- **核となるメッセージ**（1〜2文に要約）
- **想定される視覚的シンボル**（例：手を取り合う、芽吹き、光が差す等）

### Step 3: シーン記述型プロンプトを構築

以下の5要素を必ず文章中に含める：

| 要素 | 内容 |
|---|---|
| 被写体（Subject） | 何が/誰が中心にいるか |
| 構図（Composition） | アングル、配置、画面比率 |
| ライティング（Lighting） | 光源、時間帯、明暗 |
| スタイル（Style） | 写真/イラスト/3D等、画風 |
| 色調（Color palette） | 主要色、トーン、彩度 |

過去投稿の画像が参照できた場合、そのビジュアルトーン（色調、画風、構図傾向）も踏襲する。

### Step 4: 出力

```markdown
## 画像生成プロンプト（Nano Banana用）

### コンセプト
[投稿文との対応関係を1〜2文で説明]

### プロンプト本文（日本語版）
[シーン記述型プロンプト 200〜400字程度]

### プロンプト本文（英語版）
[同内容の英語版]

### 画像内テキスト（任意）
[短いキーフレーズ1〜2語推奨、10文字以内]

### 画像仕様
- アスペクト比: [プラットフォームに応じた推奨値]
- 推奨枚数: [単発/カルーセル等]

### visual_guideline.mdとの整合性
- 採用したスタイル要素: [箇条書き]
- 避けた表現: [箇条書き]
```

## 重要な原則

- **visual_guideline.mdの絶対遵守**
- **人物表現の配慮**：障害福祉領域を扱うため、ステレオタイプ表現を避ける
- **金融関連の慎重さ**：札束・現金の直接描写は避ける
- **著作権配慮**：実在キャラクター・ブランドロゴ・有名人を想起させる描写は避ける
- **投稿文とのトーン一致**：感情トーンの乖離を防ぐ

## エラー時の対応

- `visual_guideline.md`が存在しない → 生成を中断し、ファイル準備を依頼
- 投稿文が未提供 → 生成不可、投稿文の提供を依頼
