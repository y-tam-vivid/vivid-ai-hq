# イベントレコード テンプレート

`validate_record.py` に渡すJSONの雛形。確定していない項目は空文字のままにする（推測で埋めない）。

```json
{
  "イベント名": "",
  "通称": "",
  "ステータス": "企画中",
  "開催初日": "",
  "最終日": "",
  "開催時間": "",

  "会場": "",
  "所在地": "",
  "自社の立場": "",
  "主催者・共催者": "",
  "参加費": "",
  "予約": "",

  "ターゲット": [],
  "投稿先アカウント": [],
  "プレス配信": false,
  "メディア招致": false,
  "ブランドカラー": "#0A1630 / #FF8A00",
  "掲載NG事項": "",

  "来場実績": null,
  "メディア掲載": "",
  "振り返り": ""
}
```

## 値の候補

| 項目 | 候補 |
|---|---|
| ステータス | 企画中 / 開催決定 / 告知中 / 開催中 / 終了 / 振り返り済 |
| 自社の立場 | 主催 / 共催 / 出展 / 協力 / 後援 / 視察 |
| 参加費 | 無料 / 有料 / 一部有料 / 未定 |
| 予約 | 不要 / 要予約 / 一部要予約 / 未定 |

## 推測してはいけない5項目

`会場` `参加費` `予約` `自社の立場` `主催者・共催者`

空欄のまま検証にかけると確認要求として出力される。ユーザーに確認してから埋める。
