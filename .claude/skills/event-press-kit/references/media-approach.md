# Media Approach

配信後のメディアアプローチと取材対応。Step 4・Step 5 で読む。

---

## 1. 4つのアプローチ手法

Web配信だけでは届かない。配信は出発点であって到達点ではない。

### ① Webプレスリリース配信

| 基盤 | 特徴 |
|---|---|
| PR TIMES | 国内シェア最大。配信先を自社で選択でき、幅広くリーチできる |
| @Press | 自動で関連媒体を選定して配信。サポートが手厚い |

### ② 電話での個別アプローチ

- 事前に媒体・番組の内容を1〜2分チェックしてから架電する
- **1分以内で、定量データを中心に、ゆっくり話す**
- アポイントが取れなければメールアドレスかFAX番号を入手する
- 上級：テレビはコーナー別に担当者を指定、新聞は記者名を指定する

### ③ 記者クラブへの投げ込み

- 全国に多数存在し、商工会議所・区役所・省庁内などに設置されている
- 幹事社に電話して配布方法の指示を受け、指定日時に必要部数を持参する
- **地方の記者クラブに、その地方と関係のないネタは持ち込まない**

### ④ 人脈活用・顧問営業

- 過去の取材時にもらった名刺・メールのやりとりを活用する
- 社員の知人に記者・ディレクターがいないか確認する
- フリーのメディア関係者を顧問に迎える選択肢もある

## 2. 媒体ごとのアプローチ難易度

| 媒体 | 難易度 | 方針 |
|---|---|---|
| 全国紙の本社 | 高い | 直接のアポイントは困難。向こうからの依頼を待つ |
| **地方支局・地方紙・業界紙** | **低い** | **地域ネタが不足しており歓迎される。獲得率が高い** |
| テレビ（キー局） | 中 | ディレクターまたはADとのアポイント。30分以内の打ち合わせ |
| Webメディア | 低〜中 | 掲載希望日の数日前〜当日でも可。フットワークが軽い |

地方紙・業界紙から始めるのが現実的。実績が積み上がると全国紙にも届きやすくなる。

## 3. メディア側が見ているもの

現役の記者・ディレクターが挙げた要素。

**新聞・Webメディア（地方紙記者）**

- 見出しが最初の印象を決める
- リード文で5W1Hが分かりやすく書かれている
- **写真が複数枚あると記事化しやすい**
- 具体的な数字と裏付け情報
- 紙媒体ではネタ元の相当割合がプレスリリース。ネットメディアではSNSの比重が上がる

**テレビ（報道番組ディレクター）**

- 特徴が簡潔に書かれている
- **撮影可能な映像のイメージが湧く**
- 業界用語を避けた分かりやすい表現
- 失敗例：タイトルで何を伝えたいか不明確／難しい言葉や長文／会社名・社長名の押し出しすぎ

テレビは季節性キーワード（連休、暑さ対策、花粉など）で検索してネタを探すことがある。
イベントを季節文脈に接続できると拾われやすい。

## 4. 取材対応

### 速さが決定的

- 取材依頼は**お客様対応として最優先**で扱う
- 当日朝の連絡で昼取材、夕方放送という展開がある
- メディアは複数の候補先に同時連絡している。**第一候補より、早く返事をした第三候補が採用される**
- 「おそらく大丈夫、進めてください」という前向きな回答が効く

そのために、**リリースを書く段階で取材対応の可否を代表と確認しておく**。
依頼が来てから社内調整を始めると間に合わない。

### 準備するもの

- 想定質問への回答（代表の経緯、他との違い、今後の展開、最新の数値）
- 配布資料：プレスリリース、会社概要、最新数値、写真・動画素材
- 撮影場所と機材の確保
- 技術的な質問に答えられる人の確保

訪問時は**プレスリリースを印刷して持参する**。多くの人は詳細まで読んでいないため、
対面で紙を見せながら説明する意味がある。訪問前に相手の過去の記事・番組を調べ、
具体的に言及すると信頼が作れる。

## 5. 掲載後の二次活用

**露出そのものより二次活用に価値がある。** 一過性で終わらせない。

| 対象 | 活用方法 |
|---|---|
| 新規顧客 | Webサイト・SNS・営業資料・展示会での掲載。信頼性向上で成約率が上がる |
| 既存顧客 | メルマガ・DMで告知。リピートとファン化 |
| 取引先・金融機関 | 融資交渉、条件交渉、資金調達での信頼材料 |
| 採用 | 求人での信頼性向上、社内モチベーション、離職率低下 |

### クリッピング

新聞・雑誌は購入して該当記事をスキャン保存、Web記事はURLと画面を保存、
テレビは放送データを保管する。**掲載実績は資産**なので、その都度残す。
`event-db-sync` 経由で台帳へ記録し、次回の企画書で根拠として引けるようにする。
