# スプレッドシートに直接触る（サービスアカウント経由）

> **なぜこれがあるか** ── 2026-08-19 まで、mini に Google 認証が1つも無かった。
> そのため AI はシートを読み書きできず、**調査1回ごとに GAS を Drive へ置いて
> 有璽氏が貼って実行する**運用になっていた。往復が積み上がり、
> 「この作業すら私がやるべきなの？」という指摘が出た（正当な指摘）。
>
> **AIが代われない理由は能力ではなく認証だった。** サービスアカウント1つで消える。

```

```

**繋がるなら GAS を書かない。** 人にスクリプトを貼らせるのは、この経路が使えないときだけ。

## 使い方

```python
import sys; sys.path.insert(0, '/Users/yuji_macmini/.vivid-relay')
from sheets_client import Sheets, WORKBOOK_ID, INTAKE_ID

sh = Sheets()
meta = sh.meta(WORKBOOK_ID)                      # シート名・器の行数・列数
rows = sh.read(WORKBOOK_ID, '00_企業マスタ')       # 全行（★打ち切りなし）
f    = sh.read_formulas(WORKBOOK_ID, '08_関係フォロー!A3:N3')   # 数式の在処
```

| 目的 | メソッド |
|---|---|
| 実物を見る | `meta(file_id)` … **触る前に必ず** |
| 読む | `read(file_id, 'シート名')` / `read_formulas(...)` |
| 書く | `update(file_id, 'シート名!A795', values)` / `append(...)` |
| 器を増やす | `add_rows(file_id, sheet_id, n)` |
| バックアップ | `backup(file_id, '…_バックアップ_YYYYMMDD-HHMM')` |

## 書く前に必ず守ること

```
① バックアップ    backup() を呼び、返ってきた size が 0 でないことを確かめる
                   ★「取った」と「戻せる」は別物。取れているかの確認までが復帰経路
② diff を見せる   何をどう変えるかを提示して承認を得る
③ 本実行
④ 突合            書いた直後に読み直し、意図した値が入ったかを1件ずつ照合する
```

**有璽氏が自分で触るときはバックアップ不要。AIが自律で書くときだけ必須**（2026-08-13）。

## 踏んだ地雷（同じ穴に落ちないため）

**「値が無い」と「行が無い」は別物。**
`使用行数` と `器の行数` が同じなら、次の行は物理的に存在しない。書くと
「範囲の座標がシートのサイズから外れています」で落ちる。先に `add_rows()`。

**数式のセルへ値を書くと数式が消える。**
`read_formulas()` で先に調べる。08_関係フォローの B/C/J/K/M は数式。A列にIDを入れれば
会社名・関係区分・きっかけ・案件IDが自動で出る。**08で手入力するのは A/D/E/F/G/H/N。** B/C/J/K/M は数式なので触らない
（★2026-08-20 実測で訂正。それまで「A/D/I/L の4列だけ」と書いてあり、実態と食い違っていた。**AIが読む側が腐っていた**）。

**入力規則に無い値は弾かれる。** しかも部分書き込みしてから落ちる。
選択肢は `90_選択肢マスタ`（見出しは2行目）から読んで、そこにある値だけを書く。
送り仮名まで一致させる（「登録済」ではなく「登録済み」）。

**Drive の `read_file_content` は各シート約88行で打ち切られる。**
これを存在確認に使わない。この経路が繋がっているなら `read()` を使う（打ち切りなし）。

**08_関係フォローの保護は1000行固定。** 超えると新しい行へ入力できなくなる。

## 台帳へIDを新規発番する前に（★2026-08-19 の事故）

**機械が「新規」と判定して、そのまま書いてはいけない。**

会社名1本でしか突合せず、`B-0050`（Blue Ocean Tradings合同会社／代表者 小川晃代）と
`C-0072`（小川晃代）を二重に作った。**01_顧客詳細には代表者名もメールも入っていた。**

```
突合は4キー ： 会社名 ／ 人名 ／ 電話 ／ メール
   ★人名・電話・メールは 01_顧客詳細 から取る
        D 代表者名   G 先方担当者名   I 先方担当者電話番号   J 先方担当者メールアドレス
   1つでも当たったら発番しない。候補を出して人へ返す
```

健全性の点検は `python3 ~/.vivid-relay/ledger_audit.py`（読むだけ）。
