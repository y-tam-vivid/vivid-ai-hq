## 1. 基本構成

Instagramのフィード投稿は冒頭2行しか初期表示されない。ここで読む価値を提示できないと展開されない。

```
[1] フック（1〜2行）      … 情景 or 開催情報。最重要
[2] 状況説明（2〜4行）    … いつ・どこで・何が起きているか
[3] 中身（3〜6行）        … 具体的な描写。数字や固有名詞で解像度を上げる
[4] 意味づけ（2〜4行）    … なぜそれが良かったのか。個人アカウントではここが主役
[5] CTA（1〜2行）         … 開催中なら時間と場所。終了後なら次回や保存の誘導
[6] ハッシュタグ
```

告知性の高い投稿では [1] に開催情報を置き、[4] を省く。
思想性の高い投稿では [1] を情景から入り、[5] を軽くする。

長さの目安は本文300〜600字。イベント告知は短く、振り返りは長くてよい。

## 2. アカウント種別ごとのトーン

同じ素材でも軸をずらす。同一文の使い回しは、両方フォローしている人の体験を損ない、
プラットフォーム上も重複コンテンツとして扱われうる。

### 個人アカウント（経営者・専門家）

現場で何を感じ、何に気づいたかが主役。イベントの説明は背景に退かせる。
自分の事業領域や思想と接続する一段が入ると、単なる報告から「その人が書く意味のある文章」になる。
断定を避け、観察から入って解釈へ進む順序が読みやすい。

絵文字は使わないか、ごく控えめに。

### 主催・公式アカウント

情報の正確さと来場促進が役割。冒頭に【本日開催】のような状態表示を置き、
日時・場所・参加条件を早い位置に出す。読者は「行けるかどうか」を判断しに来ている。

明るい丁寧語。絵文字は1投稿に2〜4個程度なら親しみやすさに寄与する。
子ども向けイベントでは多少多くてもよい。

### 法人・事業者アカウント

取り組みの意義と実績。落ち着いた丁寧語。誇張を避け、事実を並べて意味を語らせる。
関係先への謝辞を入れる場合は具体的に。

### 施設・店舗アカウント

現場スタッフの視点。「今日はこんな一日でした」という語り口。
親しみやすさ優先で、堅い言い回しは避ける。

## 3. 冒頭2行の設計

効きやすい型。

| 型 | 例 |
|---|---|
| 状態表示 | 【本日も開催中】◯/◯（◯）10:00-17:00 |
| 情景 | 昨日の会場は、すごい熱量でした。 |
| 引用・セリフ | 「これ、ぼくがつくったやつ」 |
| 意外性 | いちばん夢中だった子が、最初は「わからん」と言っていました。 |
| 数字 | 2日間で◯◯組の親子が来てくれました。 |

避けるべきは「先日、〇〇に参加してきました。」のような無風の書き出し。情報量がなく、展開されない。

## 4. ハッシュタグ

10〜15個程度。3層に分けて構成する。

| 層 | 役割 | 個数の目安 |
|---|---|---|
| 固有 | イベント名・会場名・主催者名 | 2〜4 |
| カテゴリ | ジャンル・テーマ（例 #ワークショップ #プログラミング教育） | 4〜6 |
| 地域・行動 | 地名・行動意図（例 #大阪イベント #親子でおでかけ） | 3〜5 |

- 大規模タグ（投稿数100万超）だけを並べても埋もれる。中規模タグを混ぜる
- 投稿内容と無関係なタグは付けない
- アカウントごとにタグセットを変える。個人は思想・専門系、公式は集客系に寄せる

## 5. 事実の扱い

**根拠のない事実は書かない。** 特に次の項目は、プロファイルかユーザーの発言に裏付けがある場合だけ書く。

- 来場者数・組数
- 「大盛況」「満員」などの評価語
- 共催者・協賛社の名称
- 参加費・予約要否
- 会場の正式名称と区画
- 次回開催の予定

写真から読み取れた情報も、そのまま断定しない。「写真から◯◯と読めますが、正式表記を確認させてください」と返す。

## 6. NG表現

| 種別 | 避けるもの | 理由 |
|---|---|---|
| 立場の誤り | 出展なのに「開催しました」 | 主催者に失礼 |
| 誇張 | 根拠のない「日本初」「業界唯一」 | 景表法上のリスク |
| 断定的な効果 | 「必ず伸びる」「絶対楽しめる」 | 検証不能 |
| 個人の特定 | 参加者の氏名・所属・年齢 | 許諾なしは不可 |
| 他社IP | キャラクター名・作品名の無断使用 | 権利侵害 |
| 比較 | 他イベント・他社の名指し批判 | 争いの種 |

子どもが被写体の場合、外見への言及（かわいい・美形など）は避け、行動や作品に触れる。

---

## 7. 例

同一素材から2アカウント分を書き分けた例。

**個人アカウント（気づき軸）**

> 昨日の会場は、すごい熱量でした。
>
> 親子でゲーム制作に挑戦するワークショップ。朝から人が途切れませんでした。
>
> 印象に残ったのは、最初に「わからん」と言っていた子が、結局いちばん長く画面に向かっていたこと。
> 入口さえ整えば、つまずきは能力の差ではなく設計の問題だったとわかります。
>
> できる／できないを分けているのは本人ではなく、環境のほう。
> テクノロジーは、その環境を組み替えるためにあります。
>
> 本日も10:00〜17:00で開催中です。

**主催アカウント（告知軸）**

> 【本日も開催中】◯/◯（◯）10:00 - 17:00
>
> 昨日はたくさんの親子にお越しいただきました。ありがとうございました！
>
> 本日も引き続き開催しています。ドラッグ＆ドロップで直感的につくれるので、
> はじめてのお子さんも大丈夫です。
>
> 途中からの参加もOK。17:00まで、お待ちしています！

前者は「気づき→意味づけ」で終わり、告知は最後に軽く置く。
後者は開催情報から始まり、参加のハードルを下げて締める。同じ一日を、違う入口から書いている。
