# Channel Lead Times

媒体ごとの配信リードタイムと、PR TIMES運用の実務。Step 1・Step 3 で読む。

---

## 1. リードタイムが逆方向であること

計画層が必要な理由は、媒体によって「早すぎる」「遅すぎる」の向きが逆だから。

| 媒体 | 最適タイミング | 早すぎると | 遅すぎると |
|---|---|---|---|
| メディア招致（取材依頼） | 開催1か月以上前 | ほぼ問題ない | 記者の予定が埋まり取材枠が取れない |
| プレスリリース（告知） | 開催2週間以上前 | 情報が古くなる | イベントが終わってから記事化される |
| Webメディア | 数日前〜当日でも可 | ─ | ─ |
| SNSフィード（告知） | 1〜2週間前 | 流れて忘れられる | 予定を空けてもらえない |
| SNSストーリー | 直前〜当日 | 24時間で消える | 機会損失 |
| 実施報告リリース | 終了後1週間以内 | 数値が固まっていない | ニュース性が落ちる |

一般向けセミナー・イベントの告知は開催2週間以上前が目安とされ、
メディアを招致するイベントでは1か月以上前が推奨される。
記者側のスケジュール確保が必要になるためで、この差が計画の骨格になる。

招致案内を出したあとは、2週間前や数日前にリマインドを入れる。
記者は多数の案内を受け取っており、忘れられる前提で動く。

---

## 2. 配信曜日と時間帯

PR TIMESは平日の火・水・木を推奨曜日として挙げている。
@Pressは月〜木の午前中を推奨しており、メディアが朝一番にプレスリリースを確認する傾向が
根拠として示されている。

実務上の判断。

- **月曜午前**は週明けで受信量が多く埋もれやすい。ただし「月曜に目を通す」と答える記者も多く、一概に悪くはない
- **金曜午後**は避ける。週明けまで読まれない
- **土日祝**は基本的に避ける。速報性のある内容なら例外
- 大型連休・全国的な大ニュースと重なる週はずらす

`build_schedule.py` は火・水・木の午前10時に自動で寄せるが、**祝日は判定していない**。
生成後に必ず目視で確認する。

## 3. PR TIMES の画像実務

メイン画像は、メディアに記事化された際そのまま使われることが多い。
つまり**プレスリリースの画像は自社の顔になる**。

- 画像は最低3パターン以上用意する。Webメディアは複数枚使い、紙媒体は1枚だけ選ぶことが多いため
- 主要な被写体は中央に置き、上下左右に余白を取る。媒体側でトリミングされる可能性がある
- アップロード可能なファイルサイズ上限は10MB（2025年1月に5MBから引き上げ）
- SNSでシェアされたときのOGP表示も考慮する。一般に1200×630px前後が扱いやすい
- 解像度はWeb掲載中心なら72ppi以上、紙媒体での利用を想定するなら350ppi

イベント写真を流用する場合、**肖像権の処理はSNSより厳しく見る**。
プレスリリースは転載され、削除依頼が届いても回収が難しい。
`event-social-kit` の `references/privacy-checklist.md` の基準に従い、判断に迷えば使わない。

## 4. プレスとSNSは文体が違う

同じ文章を流用しない。読者も評価軸も別物。

| | プレスリリース | SNS |
|---|---|---|
| 読者 | 記者・編集者 | 生活者・見込み参加者 |
| 求められるもの | 事実・数値・新規性・社会的意義 | 体験・感情・共感 |
| 主語 | 法人名 | 「私たち」「僕」など |
| 一文の長さ | やや長くてよい | 短く |
| 見出し | 結論と数値を含む | 情景や引用でもよい |
| 冒頭 | 5W1Hを圧縮 | フックで引く |
| NG | 主観的な形容、根拠なき最上級 | 硬い定型文、情報の羅列 |

プレスで「◯◯を◯月◯日に開催します」と書いた同じ事実を、
SNSでは「あの日の熱気をもう一度」と書く。事実は共通、切り口は別に設計する。

---

## 5. 実施報告リリースの扱い

終了後のリリースは、告知リリースより通りにくい。ニュース性が落ちるため。
出すなら次のいずれかの材料が要る。

- 具体的な来場実績（人数・組数・前回比）
- 新しい発表（次回開催の決定、継続実施の決定、連携先の追加）
- 社会的な意義づけ（課題に対してどう作用したか）
- 参加者の声（許諾を得たもの）

数値が固まる前に急いで出さない。憶測の数字を書くくらいなら、
数字を出さずに事実だけで構成する。

---

## 出典について

本リファレンスのタイミング目安は、PR TIMES・@Press・配信代行各社が公開している
一般的な指針をまとめたもの。業界や地域媒体では慣行が異なる場合があるため、
重要な案件では配信先に直接確認すること。
