# イベントプロファイル（ハブ管理版）

> Notionのイベント管理DBがSSOT。このテンプレートはヒアリング時の項目一覧であり、
> 確定後はDBへ反映する（反映前に必ずユーザーの承認を得る）。
> スポークスキル（event-social-kit 等）へ委譲する際は、この内容を引き渡して再ヒアリングを防ぐ。

| 開催初日 | |

## 2. 推測してはいけない5項目

**すべて確認を取る。写真や既存資料からの読み取りは裏取りにならない。**

| 項目 | 内容 |
|---|---|
| 会場（正式表記・階層・区画） | |
| 参加条件（無料／有料・予約要否・出入り自由か） | |
| 自社の立場（主催／共催／出展／協力／後援／視察） | |
| 併記が必要な主催者・共催者・後援者 | |
| 数値（定員・過去実績・来場見込み） | |
