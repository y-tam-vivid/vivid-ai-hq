## ① 制作中の確認用スイッチが、公開版にも出ています 🔴 いちばん直したい

詳細ページのいちばん下に、次の3つのかたまりが出ています。

```
確認用サンプル      写真あり・本文に3枚 ／ 写真なし・本文0枚 ／ その他の市・リンクなし
写真の並べ方        1枚（横長） ／ 3枚（大1＋小2）
本文中の写真の並べ方  1枚（横長） ／ 2枚（横並び） ／ 3枚（大1＋小2） ／ 3枚（横一列）
```

制作中に見比べるための道具だと思います。とても便利なのですが、
**いまの状態だと、サイトを見に来た一般の方にもそのまま見えます。**

お願いしたいこと ──
**この3つのかたまりを、公開時には出ない形にしてください。**
消してしまうと今後の確認で困るので、
**「制作中だけ出る」スイッチを1つ作って、そこにまとめていただけると助かります。**
（例：`state.devMode` のような値が true のときだけ出す。既定は false）

## ③ 空欄のときに出る文字を、読む人の言葉に変えてください

2か所に `'記載なし'` が固定で書かれています。

```
料金が空のとき   いま '記載なし'  →  ★'公式ページをご確認ください'
申込が空のとき   いま '記載なし'  →  ★'主催者情報をご確認ください'
```

**理由**：「記載なし」は、こちら（情報を集める側）の事情の言葉です。
サイトを見ている方は「記載なしって何のこと？」となります。
**次にその方が取れる行動（公式を見る）へ繋がる言葉**にしたいです。

※ 「住所・最寄り・主催・問い合わせ」は、空のとき行ごと消える作りになっています。
   **そちらはそのままで完璧です。**触らないでください。
