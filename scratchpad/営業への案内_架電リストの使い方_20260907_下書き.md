## 2. 入力する場所は、これまでと同じ形です

**覚え直すことはありません。**列の並びは、これまで使っていたファイルと同じです。

```
最新ステータス   いまどうなっているか（1つだけ）
1回目            担当名／かけた時間／ステータス／メモ／次回いつかけるか
2回目            同じ形
3回目            同じ形
```

**1回かけたら、その回の欄を埋めてください。**
最新ステータスは、いちばん新しい状態に上書きしてください。

---

## 3. ステータスは、この中から選んでください

**★いま自由入力になっているので、書き方が人によって違うと集計できません。**

| 書くもの | どんなとき |
|---|---|
| 不通 | 呼び出しても出ない |
| 留守電 | 留守番電話につながった |
| FAX音 | FAXにつながった |
| 現在使われていない | 番号が使われていない |
| 受付NG | 受付で断られた（営業お断り） |
| 本社一括 | 本社でまとめている、と言われた |
| 担当者不在 | 受付は通ったが担当者が不在 |
| 担当NG | 担当者に断られた |
| 見込み | 手ごたえあり。もう一度かける |
| 資料送付 | 資料を送ることになった |
| アポ獲得 | アポイントが取れた |
| 架電NG | もうかけないでほしい、と言われた |

**「架電NG」だけは特別です。**これを書いた先には、以後こちらでもかけません。

---

## 4. 同じ先に2回かけないために

```
法人単位のタブ     1行＝1法人。★同じ番号が重複している行は 3,495中45行だけ
事業所単位のタブ   1行＝1事業所。★同じ法人の事業所が複数あるので、
                   同じ番号への重複が 2,273行あります
```

**★事業所単位でかけるときは、同じ番号に何度もかかる可能性があります。**
最新ステータスが入っている行は、**もう一度かける前に必ず見てください。**

---

## 5. かけた結果は、こちらで顧客台帳へ反映します

**皆さんが台帳（営業案件管理）へ転記する必要はありません。**

```
皆さん      リストに書く
   ↓
こちら      毎日読みに行って、内容を確認したうえで台帳へ反映します
   ↓
台帳        アポが取れた先・見込みの先が、案件として残ります
```

**★間にこちらの確認が入るので、リストに書いてから台帳へ載るまで少し時間がかかります。**
急ぐものがあれば、Slackで一言ください。
