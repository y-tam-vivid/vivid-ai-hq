## 5. 台帳の「掃除」は、この突合にどう効くか

**★用途が変われば、掃除の価値も変わる。** 8/31 に「置いといてよい」と決めたときは
「台帳を眺めるための掃除」だった。**突合に使うなら、同じ汚れでも意味が違う。**

### 5-1. 法人番号の空欄 ── ★突合では「見逃し」と「誤検出」に直結する

```
台帳 467社の突合キー
   法人番号＋電話の両方あり   161社  ← 確実に突き合わせられる
   法人番号だけ               110社  ← 確実に突き合わせられる
   電話だけ                    27社  ← ほぼ確実
   ★どちらも無い（社名だけ）  169社  ← 36%。当たっても外れても人が見るしかない
```

**実測がそれを裏づけた。** 今回の19社のうち、法人番号があった10社は全部確実。
**番号が無かった9社では、3社が別法人（誤検出）だった＝3分の1が外れ。**

```
毎朝の指摘「顧客種別=法人なのに法人番号が空 59件」
   ★眺めるだけなら後回しでよい
   ★突合に使うなら、この59件は「架電を止められない穴」そのもの
```

### 5-2. 重複21組 ── **突合の精度には効かない**

同じ法人が2つのIDを持っていても、どちらの行でも「既存」と判定できるので**架電は止まる**。
効くのは記録するときで、**活動ログをどちらのIDに書くかが割れる**だけ。
★掃除の優先度としては、法人番号の空欄より下。

### 5-3. 🔴 掃除の議論に一度も出ていない汚れを1つ見つけた

```
00_企業マスタ「電話番号_正規化」列
   値が入っている 190件 のうち ★169件で先頭の0が落ちている
   例  B-0034 株式会社ILIFE → 729797885（本来 0729797885）

   隣の「電話番号」列は 190件中1件しか落ちていない＝★生きているのはこちら
```

**「正規化」という名前の列が、正規化されていない。** 今回は隣の列が生きていたので実害は出なかったが、
**この列を信じて突合する処理を書くと、電話での一致がほぼ全部すり抜ける。**

### 7-1. AIが決めてよいこと（承認を待たずに進められる・全部可逆）

| # | やること | なぜ |

### 7-2. ★有璽氏でないと決められないこと

**論点1 ── 架ける前の突合を、仕組みにするか手で1回やるか**

| 案 | 中身 | 向き不向き |
|---|---|---|
| **A** | **今回の21行を紙で渡して、架ける人が手で避ける** | ★今回1回ならこれで足りる。準備0日 |
| **B** | リストに「台帳あり」の列を足し、架ける前に毎回機械で塗る | リストを作り直すたびに塗り直しが要る。次のリストにも効く |
| C | 台帳側に「架電NG」の列を新設し、そこを見る | ★列を足しても運用が乗らないと空のまま（06_テレアポリストが実例） |

**つるの所見は A。** ★理由：いま止めるべきは21行しかなく、仕組みを作る時間より
架け始める方が早い。**ただし2本目のリストを作るなら B へ移す。** 手作業は2回目から破綻する。

**論点2 ── 05と重なる 484社に架けてよいか**

```
7月にフォーム営業でメッセージが届いた相手。反応は無い（クリックは13社のみ）
案A  架ける。「先日フォームからご案内した件で」と繋げる ── 接点として使える
案B  架けない。一度断られたも同然として外す
案C  クリックした13社だけ先に架け、残り471社は後回し
```

★これは営業の判断であってデータの判断ではない。**つるは決めない。**
ただし**「7月に一度出している」という事実を知らずに架けるのは避けるべき**、とだけ言っておく。

**論点3 ── 「断られた」をどこに記録するか（★これがいちばん重い）**

```
いまの状態   記録する場所が無い。台帳4シートで 0件。備考欄も 8,046行中4行しか使われていない
起きること   ★同じ相手に、半年後にまた架ける。1回目より確実に怒られる
             8月の苦情1件は、文章の中にしか残っていない＝機械は次も同じ相手に出す
```

★決めてほしいのは「どの器に書くか」ではなく、**「断られたことを、次に架ける人へ届ける経路を持つか」**。
持たないと決めるのも判断のうち（フォーム営業の規模なら割り切る選択はありうる）。
**だが今のように「持っているつもりで持っていない」のがいちばん危ない。**

**論点4 ── 台帳の掃除の優先順位を、この用途で見直すか**

```

```
