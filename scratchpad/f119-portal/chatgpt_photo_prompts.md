# 119番 解決パートナー 試作用ダミー写真 ── ChatGPT への頼み方

## 手順（1枚ずつ）
1. ChatGPT を開き、下の「共通の指定」を最初に1回だけ貼る
2. 続けて、番号ごとの依頼文を1つずつ貼る（1回に1枚）
3. できた画像を保存し、**ファイル名を左端の名前に変えて**このフォルダへ入れる
   例：`hero.png`、`a.png`（拡張子は png でも jpg でもよい）
4. 全部そろったら（途中でも）Claude に「入れた」と伝える → 取り込んでページに反映します

## 共通の指定（最初に1回だけ貼る）

```
これから施設経営者向けWebサイトの試作に使う写真を1枚ずつ作ってください。共通の条件：
・写実的な写真（イラストではない）。日本の実在しそうな場面、日本人の人物
・横長 16:9
・明るい自然光、落ち着いた信頼感のある雰囲気、彩度は控えめ
・画像の中に文字・ロゴ・看板の文字・ナンバープレートを入れない
・実在の人物や企業に似せない
では次のメッセージから依頼します。
```
