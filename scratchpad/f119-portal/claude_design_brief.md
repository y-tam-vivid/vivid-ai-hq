# 【Claude Design への依頼】「福祉施設の119番」のデザインを1つに揃える

作成：2026-10-27／依頼主：株式会社ビビッド（ふくち。グループ）／取扱：社内限定

---

## 1. お願いしたいこと（3つ・この順で）

1. **「福祉施設の119番」専用のデザインシステムを作る**（ふくち。本体のデザインシステムとは別に）
2. **119番のLPを、そのデザインシステムで組み直す**（文章・構成・リンクは今のまま。見た目だけ）
3. **新しいサイト「119番 解決パートナー（仮称）」を、同じデザインシステムで作る**（試作あり）

提出は段階ごとに分けてください：①デザインシステム（色・文字・部品の一覧）→ ②LPの組み直し → ③解決パートナー。
①が決まるまで②③に進まないでください。

## 2. なぜ必要か（いま起きていること）

119番の見た目が2系統に割れています。

| | 系統A：119番のCI・資料 | 系統B：本番LP |
|---|---|---|
| 土台 | 「福祉施設の119番 CI／VIデザイン仕様書 v1.0」（2026-08-03）と、それに沿った資料3本 | ふくち。グループ本体の Design System v1.0（`design-system-v1-0-f0efa2b4…`） |
| 見出し | ゴシック（Noto Sans） | 明朝（Noto Serif JP） |
| 地 | 白＋サンド色の面 `#F4F1EA` | 生成り色の紙 `#FBF9F6` |
| 紺 | `#0E2A47` | `#0F2940` |
| アクセント | オレンジ `#E2733B`＋ティール `#1C7293`＋スカイ `#57A6C9` | テラコッタ `#C66B3D`＋ティール `#21708E` |
| カード | 上辺6pxの色帯付きのサンド面 | 白地＋1px罫 |

原因：LPは**ふくち。本体のデザインシステム**で組まれている。ところが、そのデザインシステム自身の readme に
「サービスブランド（LIFE STAND UP、orange works、福祉施設の119番）は自身のロゴ色を保つ」
「`#E2733B` / `#0F2A47` は 119番のロゴ内部でのみ使用（ふくち。UIには使わない）」とある。
つまり**119番には119番の見た目が要るのに、それが用意されていなかった**。

**決定（依頼主）：系統Aを正とし、LPも含めて揃える。** ふくち。本体のデザインシステムは変えない。

### 3.3 ★コントラスト（直してほしい点を含む）

実測（WCAG のコントラスト比）：

| 組み合わせ | 比 | 判定 |
|---|---|---|
| 白文字 on ORANGE `#E2733B` | 3.11 | ★本文サイズ・小さいボタン文字は不可（4.5 必要）。18.66px 太字以上なら可 |
| ORANGE `#E2733B` の文字 on SAND | 2.76 | ★不可（大きな数字でも 3.0 に届かない） |
| 白文字 on SKY `#57A6C9` | 2.73 | ★不可 |
| 白文字 on TEAL `#1C7293` | 5.42 | 可 |
| SUB GRAY on SAND | 4.89 | 可 |

提案：**白文字を載せるオレンジ面と、小さなオレンジ文字には一段濃い `#B85A2A`（白文字比 4.63）を使う**。
`#E2733B` はロゴ・色帯・短い棒・18.66px 太字以上のボタンに限る。
（ふくち。本体のデザインシステムでもテラコッタに同じ問題があり、`#A4552D` を追加して解決している。同じ考え方。）
→ この扱いでよいかは①の提出時に確認させてください。

### 3.4 文字

- 見出し・本文とも **Noto Sans JP**（ブランド指定は Noto Sans CJK JP）。欧文・数字は Inter でも可（CI仕様書5章）。**明朝は使わない**（代表メッセージ等の情緒的な文脈のみ例外。CI仕様書5章）。
- 本文 **17px・行間 1.9**（ふくち。本体と同じ。読み手に高齢の経営者が多い）。補足 14px、キャプション 12px まで。
- 見出しはウェイト 500〜700。資料では大見出し 500、カード見出し 700。
- 英字小見出し（`OVERVIEW` `SCHEDULE` など）：ティール・大文字・字間を大きく（.3em 前後）・見出しの上に置く。

### 3.6 ふくち。本体から引き継ぐもの（119番でも守る）

- 本文17px以上・コントラスト 4.5:1 以上
- 絵文字を使わない／「感動」「寄り添う」「No.1」など根拠のない最上級を使わない
- 写真は自然光・低彩度。写真の上の文字は白＋紺のスクリムだけ
- ロゴは実ファイルを使う（SVGで描き起こさない）
- アニメーションは控えめ（ease-out のみ・`prefers-reduced-motion` で止める）
