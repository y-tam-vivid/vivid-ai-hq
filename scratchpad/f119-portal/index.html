福祉施設の119番 解決パートナー（仮称）構想書

1. 結論

「福祉施設の119番」の一部として、施設経営者のお悩みから入り、それを解ける会社の想いと取り組みを読み、119番の窓口から相談するポータルを作ります。土台は9月に作った困りごとリスト118件です。その判定で「119番では触れない（△）」とした94件を提携先で解く場所にする、というのがこのサイトの役割です。

  施設経営者のお悩み（10分類＋経営者本人）
            │
            ├─ 119番で解けるもの（◎○ 24件）──→ 健康診断・ドック・月額3本
            │
            └─ 119番では触れないもの（△ 94件）──→ 解決パートナー（このサイト）
                                                     │
                                                     └─ 相談は119番の窓口が受けて振り分ける

2. 前提と制約

  • 名義は福祉施設の119番（2026-10-27 有璽氏の回答）。運営主体は119番の提供元である株式会社ビビッドを想定しています（未確認）。
  • 掲載候補は承諾をまだ取っていません。試作はダミー名で作っています。
  • 最終的には、福祉経営者と親和性のある会社を束ねたコミュニティにすることを目指します。
  • 参考サイト Bowers は業種での絞り込みだけでした。エリア・タグ・お悩みからの入口は、このサイトで独自に足すものです。

4. インタビュー記事の型

Bowers の型（事業内容 → ここが他社と違う → 会社情報 → プロフィール → 繋がりたい業種 → 相談）を、施設経営者向けに組み替えます。いちばん上に置くのは事業内容ではなく、経営者へのひと言です。

順項目中身Bowersでの対応

3私たちの想いなぜ福祉施設に関わるのか。原体験会社設立経緯

5対応エリア・対応方法本拠地／訪問できる範囲／オンライン可否なし（新設）
6費用の目安載せるかは各社の判断。初回相談の有償・無償だけは必須なし（新設）
7会社情報・プロフィール会社概要、代表または担当者会社情報・プロフィール

8. この形の利点と弱点

利点：経営者は会社名ではなく困りごとで探すので、入口が合っています。119番の窓口に相談が集まるので、119番の見込み客も同時に取れます。困りごとリストと分類を揃えておけば、空いている分野（誰も解けない悩み）が一覧で見え、次に声をかける相手が決まります。

弱点：119番の名前で紹介する以上、紹介先の質の問題が119番の評判に返ってきます。掲載社が少ないうちに細かいタグやエリアを出すと、該当0件ばかりの寂しいサイトに見えます。記事の取材と更新にかかる手間は、掲載社が増えるほど大きくなります。

9. 決めること・確かめること

  • 紹介料・送客手数料を取るか。人材紹介・保険・融資は、紹介して対価を受け取ると職業安定法・保険業法・貸金業法などに触れる可能性があります。取る場合は、ジャンルごとに法務の確認を先に通します。
  • 掲載の基準。誰が掲載を決めるのか。掲載料を取るかどうか。
  • 相談の受け方。119番の窓口で一度受けるか、各社へ直接つなぐか（試作は前者）。
  • サイトの置き場所。119番のサイトの下に置くか、別ドメインにするか。
  • 空いている分野の候補。中小企業診断士と社労士に心当たりはあるか。
