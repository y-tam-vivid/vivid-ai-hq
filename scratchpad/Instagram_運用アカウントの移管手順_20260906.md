# Instagram アカウントを、会社で運用する形に切り替える手順

対象：`life.standup_official`（LIFE STAND UP の Instagram）

---

## なぜやるか

いまのアカウントは、スタッフの方の**個人のメールアドレス**で作られています。
そのままだと、

- その方が退職・異動すると、**誰もログインできなくなる**
- パスワードを忘れたときの再設定メールが、**会社に届かない**
- ホームページに Instagram の写真を出す仕組みが**使えない**

この3つを一度に解消します。**アカウントは作り直しません。**
いまのフォロワー・投稿はそのまま残ります。

---

## 全体の流れ

```
① 締め出されない準備   ← ★ここを飛ばすと、途中で誰も入れなくなります
        ↓
② メールアドレスを会社のものへ
        ↓
③ パスワードを変える
        ↓
④ 二段階認証を会社側へ移す
        ↓
⑤ プロアカウント（ビジネス）に切り替える
        ↓
⑥ 会社の管理下に入れる      ← これで「会社の資産」になります
```

**所要時間の目安：40分〜1時間**（⑥だけ別日でも構いません）

---

## 先に用意するもの

| | 中身 |
|---|---|
| 会社のメールアドレス | 個人ではなく、**複数人が見られるもの**が理想です |
| 会社の携帯番号 | ④で使います。個人の番号は使わないでください |
| いまのログイン情報 | ユーザーネームとパスワード。**★スタッフの方に聞いてください** |
| スマートフォン | Instagram アプリが入ったもの |

★**いまのパスワードが分からないと、この手順は始められません。**
まずそこだけ、いまの担当の方に確認してください。

---

## ① 締め出されない準備（★最初にやる）

途中で二段階認証が絡むと、**誰もログインできなくなる**ことがあります。
先に「非常用のコード」を控えておきます。

1. Instagram アプリを開く
2. 右下の自分のアイコン → 右上の三本線 → **アカウントセンター**
3. **パスワードとセキュリティ** → **二段階認証**
4. アカウントを選ぶ → **追加の方法** → **バックアップコード**
5. ★**表示された8桁のコードを、紙かメモに控える**

> これは「1回だけ使える合言葉」です。電話番号が変わっても、これがあれば入れます。
> ★スマホの中だけに保存しないでください。そのスマホが使えないときに要るものです。

---

## ② メールアドレスを会社のものへ

1. アカウントセンター → **個人の情報** → **連絡先情報**
2. いまの個人メールアドレスを選ぶ
3. **会社のメールアドレス**に書き換える
4. 会社のメール宛に確認コードが届く → 入力

★**個人のメールは、確認が終わってから外してください。**
先に外すと、確認コードの受け取り先が無くなります。

---

## ③ パスワードを変える

1. アカウントセンター → **パスワードとセキュリティ** → **パスワードを変更**
2. 新しいパスワードを設定

★**必ず変えてください。**メールだけ変えても、古いパスワードを知っている人は入れます。

---

## ④ 二段階認証を会社側へ移す

1. アカウントセンター → **パスワードとセキュリティ** → **二段階認証**
2. 電話番号が**個人のもの**なら、会社の番号へ変更
3. できれば **認証アプリ**（Google Authenticator 等）に切り替える

★ここでいちばん詰まります。
**個人の携帯にコードが届く状態のままだと、その方がいないと入れません。**

---

## ⑤ プロアカウント（ビジネス）に切り替える

1. 右上の三本線 → **アカウントの種類とツール**
2. **プロアカウントに切り替える**
3. カテゴリは「**教育**」または「**地域サービス**」あたりが近いです
4. **ビジネス**を選ぶ（クリエイターではありません）

★無料です。★いつでも個人用に戻せます。
★ここを切り替えないと、ホームページに写真を出す仕組みが使えません。

---

## ⑥ 会社の管理下に入れる（★ここが本題）

⑤までは「ログインする人を変えた」だけです。
**⑥をやって初めて、アカウントが会社の持ち物になります。**

1. パソコンで **business.facebook.com** を開く
2. 会社のアカウントでログイン（無ければ新しく作る）
3. **設定** → **アカウント** → **Instagramアカウント** → **追加**
4. `life.standup_official` の**ユーザーネームとパスワード**を入力

### ★先に知っておいてほしいこと

```
・追加するには ★ユーザーネームとパスワードが必要です
  （②〜④を先に済ませてから来てください）

・1つのアカウントは ★1つの会社にしか登録できません
  すでにどこかに登録されていると、そこから外してもらう必要があります

・Facebookページと繋がっている場合は、★ページも同じ場所へ入れてください
```

---

## 終わったら確認すること

| | 確かめ方 |
|---|---|
| メールが会社のものになった | 設定 → アカウントセンター → 連絡先情報 |
| 個人のメールが外れている | 同上。個人のアドレスが残っていないか |
| プロアカウントになった | 「個人用アカウントに切り替える」と出れば完了 |
| 会社の管理下に入った | business.facebook.com の一覧に出ている |

>
> いまは個人のメールアドレスで登録されているため、
> ご本人がいないとログインできない状態になっています。
> 会社としてお守りしたいのと、ホームページに投稿を表示する準備のためです。
>
> 一緒に作業させていただきたいので、**ログインに使っているパスワード**を
> 教えていただけますでしょうか。作業は30分ほどで終わります。
> 投稿やフォロワーはそのまま残ります。
>
> ★作業後は新しいパスワードをお伝えしますので、
> 引き続き投稿していただけます。

---

## 困ったときは

| 症状 | 対処 |
|---|---|
| 確認コードが届かない | 迷惑メールを確認。5分待って再送 |
| ログインできなくなった | ①で控えたバックアップコードを使う |
| すでに他社の管理下と出る | 前の運用会社・制作会社に外してもらう必要があります |
| パスワードが分からない | ★登録メールに再設定を送る。個人メールなら本人の協力が要ります |
