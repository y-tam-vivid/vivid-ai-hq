## 4. 入れるもの

`snippet.html` から **Clarity の行を除いた3つ**（Clarity は既にあるので二重にしない）。

```
① SalesBreaker 1行タグ（★会社で共通の1本。ゲームブルLPと ko-station.org に同じものが入っている）
   <script src="https://salesbreaker.jp/v1/sb-track.js?id=17e298ff-5e02-4630-a16d-0f4f25ede23a&amp;token=<TOKEN>" async></script>
   <TOKEN> は https://gamemarke.vivid-global.com/ のページの中にある同じタグから写す
   （公開ページに出ている値。★貼る前に id が SalesBreaker API の account/status の client_id と一致するか確かめる）
② GTM（GTM が無い2サイトだけ）── 判断が要る。下の 5-2 を見る
③ クリックログ（snippet.html の4つ目の <script>…</script> をそのまま）
```

押してほしいボタンに `data-cta="<置き場所>"` を付けられるなら付ける（例 `contact` `tel` `line` `header-cta`）。
付けられないCMS（STUDIO等）でも、クリックログはリンク先で記録するので動く。
