## 2. なぜ8日も残っているのか

**「対応していないから」ではない。理由は3つあり、性質が全部違う。**

### 理由① 「8日前」は、問題が起きた日ではなく、数える仕組みができた日

指摘が初めて出たのは 2026-08-29。**この日、点検処理に「重複と法人番号の欠けも
"対応が要る" に数える」変更が入った。** それまでは画面に表示するだけで、
警告として数えていなかった。

```
汚れ自体は 8/19 の時点で既に見えていた（重複16組・法人番号空58件）
8/29     数える仕組みができた → 「1日目」になった
```

**★「8日連続」は、汚れが8日前に発生したという意味ではない。**

### 理由② 有璽氏は「置いといてよい」と既に決めている

> 「**今の状態の話をしてんじゃないんだよ。今これから取り込むものをちゃんと回せるように
> しろ**っつってんねん。**もう今の紹介はとりあえず置いといてもいいぐらい**やで、ほんま。
> **何回やってんねんそれを。何回繰り返してんねん。**」
> （2026-08-31 有璽氏）

> 「**掃除は掃除で別のやつにやらせろ。優先順位の問題ですらない**」
> （2026-08-31 有璽氏）

```

               既存台帳の掃除は後回しでよい
機械の状態     ★この決定はどこにも反映されていない。
               毎朝の点検は同じ3件を「対応が要る」と出し続けている
```

**★人の決定は文章の中にしかなく、機械が読む場所には入っていない。**
これは既に型として記録されている問題の再発（「判断待ちにしても実行側は止まらない」の裏返し）。

### 理由③ ★掃除として消した行が、指摘を7組増やした

**ここがいちばん重要。** 8/31、有璽氏の「消せ」という明示の指示を受けて
00_企業マスタから3行を削除した。**その削除の翌朝から、重複の指摘が増えている。**

```
毎朝の記録（点検処理のログを実際に開いて数えた）
   08/26〜08/31 の毎朝   要判断 16組 ／ 別法人（対応不要）22組
   09/01 以降の毎朝      要判断 21組 ／ 別法人（対応不要）18組
                          ↑ 削除は 8/31 09:12（その日の点検08:10より後）
```

**何が起きたか ── 消えたのは「行」ではなく「判定の材料」だった。**

```
削除した3行と、その備考に書いてあったもの

  B-0008 SWELL SOCITY株式会社（社名のタイポ）
     備考「社内顧客ID 380 へ統合済み（2026-08-03）。★行は記録として残す」
     ↑ 点検処理はこの「へ統合済み」を見て、この行を毎朝の集計から外していた

  B-0132 株式会社goen
     備考「別法人と確認済み（B-0034 B-0145 B-0149 B-0380 と法人番号が異なる
           ・2026-08-19）。統合しない」
     ↑ 4組ぶんの「もう決着している」という判定材料

  B-0076 個別指導教室トト（顧客種別=個人（事業主））
```

```
削除の前                             削除の後
00に行がある + 備考に決着が書いてある   00から行が消えた
   ↓                                     ↓
点検処理が「決着済み」として外す        ★備考ごと消えたので外せない
                                        ★IDは 01_顧客詳細 に残っている
                                        ★だから「生きている行」として復活し、
                                          7組が新しく指摘に上がった
```

**★削除は目的（重複の解消）を達成していない。** 実測（2経路とも一致）：

```
経路1  01_顧客詳細 を直接読む
       → B-0008（行8）／B-0076（行75）／B-0132（行131）は★今も実在する
       → 00にあって01に無いIDは85件あるが、
         ★01にあって00に無いID（＝今回消して片側だけ残ったもの）は
         ちょうど3件で、削除した3件と完全一致

経路2  今日の21組のうち B-0008 を含む組を数える → 7組
       21 − 7 = 14 ＝ 8/31にドーベルマンが実測した「14組」と一致
```

**★台帳の「備考」欄は、人が読むメモではなく、機械が毎朝読む判定材料だった。**
行ごと消すと、判定材料だけが消えて判定対象は残る。
