# こどもまつりリリースへの引き継ぎ ── 過去のまつり写真と文言（2026-10-03）

サイト側（まつりページ）で「これまでのこどもまつり」が完成したので、リリースへ引き継ぐ。
リリースの残件「3 サイト『これまでのようす』＝できてから1行＋リンクを足す」に当たる。

## 1. 本文に足す段落（そのまま貼れる形）

```
■ これまでのこどもまつり
こどもまつりは、こどもたちが店長になってお店を開き、ゲームや手づくりの品を
「ドラ券」で売り買いするおまつりです。会場には毎回たくさんの家族連れが訪れ、
舞台ではダンスや演奏が行われてきました。
これまでの開催のようすは、団体ホームページの特設ページで写真とともにご覧いただけます。

こどもまつり特設ページ：https://minamikawachi-kodomo-demo.vercel.app/festival.html
```

★ 書いたのは写真に写っている事実だけ（お店・来場者・舞台）。開催年数・来場者数など、測っていない数字は入れていない

## 2. 写真の注記を差し替える（★必須）

いまの紙面の注記「写真はいずれも第36回のもの」は、過去回の写真を足すと事実と合わなくなる。

```
旧  写真はいずれも第36回のものです。
新  写真は第26回（2016年）・第29回（2018年）・第36回（2025年）と、
    2026年3月のミニこどもまつりのものです。
```

★ 第36回の写真だけで組むなら旧の注記のままでよい。混ぜたときだけ差し替える
