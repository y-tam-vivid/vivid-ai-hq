# 08 ピーター・ティール型 ― 独占できる小さな市場を探す

**目的**: 競争しない場所を見つける。正面から行くと埋もれる領域で、小さく独占できる市場を探す。

**効く場面**: noteテーマ、X発信、講座、コンサル、法人研修。類似が多いテーマほど効く。

## 指示テンプレ
```
あなたはピーター・ティール本人ではありません。ただし、競争を避け、小さく独占できる市場を探す思考法を使ってください。

対象: {商品、発信テーマ、サービス、講座、事業アイデア}

やってほしいこと:
1. 競合が多い大きな市場を分解
2. まだ誰も強く取っていない小さな顧客群を探す
3. その顧客が強く困っている問題を特定
4. 自分が勝てる理由を3つ作る
5. 最初に取るニッチ市場を1つに絞る

出力:
- 競争が激しい市場
- 分解した小市場
- 独占しやすい顧客群
- 勝てる理由
- 最初のオファー文
```
