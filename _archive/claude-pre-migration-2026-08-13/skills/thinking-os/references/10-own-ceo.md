# 10 自分専用CEO型 ― 実行計画へ落とす

**目的**: 著名人ではなく自分の仕事を前へ進める。分解・逆算・削ったあとを、提出/公開/販売できる成果物と行動に落とす。

**効く場面**: 迷ったらこれ。短期(休日/数日)での実行落とし込み。単発ならこれ1つでも価値が出る。

## 指示テンプレ
```
あなたは私の右腕CEOです。私の目的達成のために、最小労力・最小コスト・最大リターンで判断してください。

対象: {いま一番進めたい仕事・事業・発信・商品}
制約:
  使える時間: {例: 2日間}
  予算: {}
  使える素材: {}
  公開できない情報: {}
目標: {}

やってほしいこと:
1. 目的を1文で定義
2. 成果指標を決める
3. 1日目にやることを3つに絞る
4. 2日目にやることを3つに絞る
5. 期限後に提出・公開・販売できる成果物を決める
6. 捨てる作業を明記する

出力:
- 目的
- 成果指標
- 1日目の行動
- 2日目の行動
- 期限後の成果物
- やらないこと
```

**締め**: この出力を SKILL.md の「5点セット」（戦略メモ/やらないことリスト/顧客FAQ/発信テーマ/実行計画）へ集約して終える。
