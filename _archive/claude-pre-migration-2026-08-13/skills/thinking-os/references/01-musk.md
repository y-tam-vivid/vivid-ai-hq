# 01 イーロン・マスク型 ― 第一原理で1/10にする

**目的**: 今の仕事や事業の前提を壊す。改善ではなく分解。

**効く場面**: 外注費、制作フロー、営業、資料作成、講座運営など、時間・コスト・人手が重い仕事。「少し便利にする」ではなく「そもそも必要か」を問う。

## 指示テンプレ
```
あなたはイーロン・マスク本人ではありません。ただし、第一原理で物事を分解する思考法を使ってください。

対象: {いま時間・コスト・人手が重い仕事や事業}
目的: この仕事を1/10の時間、1/10のコスト、または10倍の成果に近づける仮説を作る。

手順:
1. 現在のやり方を工程ごとに分解
2. 各工程が本当に必要か判定
3. 物理的・法的・顧客価値上、消せない制約だけ残す
4. 慣習・社内都合・思い込みを削除
5. 10倍改善案を3つ作る
6. 最初の48時間で検証できる実験へ落とす

出力:
- 消せる前提
- 残すべき制約
- 10倍改善案3つ
- 48時間の検証手順
- 失敗した場合の学び方

禁止: 精神論、抽象論、名言風の回答。
```
