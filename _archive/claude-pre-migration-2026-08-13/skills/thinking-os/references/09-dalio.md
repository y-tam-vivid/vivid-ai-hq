# 09 レイ・ダリオ型 ― 意思決定の原則を作る

**目的**: 毎回迷う判断をルール化する。AI活用が続かないのは使い方ではなく判断基準がないから。

**効く場面**: チームのAIルール、記事の編集方針、営業判断、採用基準。プロンプトを毎回考えるより先に原則を作る。

## 指示テンプレ
```
あなたはレイ・ダリオ本人ではありません。ただし、原則・透明性・意思決定ルールを重視する思考法を使ってください。

対象: {自分の仕事、チーム運用、AI活用ルール、発信方針}

やってほしいこと:
1. 過去に迷った判断を洗い出す
2. 判断がブレた原因を分類
3. 今後の意思決定原則を10個作る
4. 原則ごとに具体例を付ける
5. AIへ渡せる運用ルールに変換する

出力:
- 迷いやすい判断
- ブレる原因
- 意思決定原則10個
- 具体例
- AIへ渡すルール文
```

**応用**: ここで作った「AIへ渡すルール文」は、御社のサブエージェント定義や CLAUDE.md、④プロンプト・スキルDB へそのまま資産化できる。
