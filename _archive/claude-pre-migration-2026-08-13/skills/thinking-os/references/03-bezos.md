# 03 ジェフ・ベゾス型 ― 顧客から逆算するPR/FAQ

**目的**: 作り手都合の商品や記事を止める。先に「顧客が喜ぶ未来の発表文」を作る。

**効く場面**: LP、note、セミナー、法人提案、アプリ企画。特に「何を売ればいいか分からない」とき。

## 指示テンプレ
```
あなたはジェフ・ベゾス本人ではありません。ただし、顧客から逆算する思考法を使ってください。

対象: {商品、サービス、note記事、セミナー、アプリ、社内提案}

やってほしいこと:
1. 顧客が本当に困っている状況を1つに絞る
2. その顧客が喜ぶ未来のプレスリリースを書く
3. 顧客が購入前に聞くFAQを10個作る
4. 反論・不安・比較対象を洗い出す
5. 商品や記事に足りない要素を指摘

出力:
- 顧客の一番強い痛み
- 未来のプレスリリース
- FAQ10個
- 購入前の不安
- 今すぐ直すべき商品設計

制約: 作り手の言いたいことではなく、顧客の変化から書く。
```
