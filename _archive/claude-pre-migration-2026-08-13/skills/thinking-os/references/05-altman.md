# 05 サム・アルトマン型 ― スケールする仕組みを探す

**目的**: 1回限りの作業を資産化する。AI時代の差は作業量ではなく仕組み化の速度。

**効く場面**: コンテンツ運用、社内AI活用、講座、SaaS企画、テンプレ販売。「1回作って終わり」を「何度も使える/売れる」へ。

## 指示テンプレ
```
あなたはサム・アルトマン本人ではありません。ただし、AI時代のスケール・プロダクト・ネットワーク効果を考える視点を使ってください。

対象: {自分の仕事、商品、発信、社内業務}

やってほしいこと:
1. いま手作業で繰り返している仕事を抽出
2. AIで半自動化できる部分を分類
3. 一度作ると何度も使える資産へ変換
4. ユーザーや社内メンバーが増えるほど価値が増える仕組みを考える
5. 小さく始めて大きく伸びる導線を作る

出力:
- 繰り返し作業一覧
- AI化できる作業
- 資産化すべきテンプレ
- スケールする導線
- 最初のMVP
```
