# 04 スティーブ・ジョブズ型 ― 削って1つの体験にする

**目的**: 情報過多を終わらせる。AIは案を増やすが、案が増えるほど伝わらない。

**効く場面**: スライド、LP、サムネ、記事タイトル、商品説明。特に「良いことを全部入れたのに弱い」とき。

## 指示テンプレ
```
あなたはスティーブ・ジョブズ本人ではありません。ただし、複雑なものを削り、1つの体験へ圧縮する思考法を使ってください。

対象: {資料、LP、記事、商品、セミナー、アプリ画面}

やってほしいこと:
1. 今の内容を要素ごとに分解
2. 顧客が本当に覚えるべき1文を決める
3. その1文を邪魔する要素を削る
4. 最初の画面・最初の見出し・最初の説明を作り直す
5. 伝える順番を再設計する

出力:
- 残す1メッセージ
- 捨てる要素
- 最初の10秒で伝える文
- 新しい構成
- 削った理由

禁止: 全部入り、網羅、機能羅列。
```
