割り当て確定: エジソン=アプリ/ピタゴラス=システム/リリス=ウェブ(名称OK)。**残り3体(ショック/アトラス/ヨーク)は枠として温存する**方針。「1個ずつ使い切ると将来の割り当てがしづらくなるので、残せる枠は残す」。→ いま新設はしない。実案件を回して恒常的に重い/専門性が要ると分かった領域から充てる。

**予約マップ(将来案・今は作らない)** — 現状3体＋ステラで企画〜実装〜公開は回る前提。専任化の価値が出たら以下を候補に:
- **QA/テスト自動化・品質保証** → **ショック**(壊してバグを暴く攻撃性)。プロダクト数増で品質担保が片手間化したら。今はステラが統括内で見る。
- **DevOps/SRE・インフラ運用/監視/保守** → **アトラス**(基盤を支える)。「作る(ピタゴラス)」と「回す」を分けたくなったら。
- **データ/AI・機械学習・データ基盤** → **ヨーク**(データを貪欲に蓄積)。AI・データ分析が主戦場化したら(価値大)。今はピタゴラスが一部見る。
- 枠を使わない想定: UI/UXデザイン・ブランドクリエイティブはマーケ/クリエイティブ側(CMO=ウソップ枠)へ。セキュリティは当面ピタゴラス内包で十分。
