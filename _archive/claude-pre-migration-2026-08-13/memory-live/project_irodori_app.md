**「いろどり／IRODORI」** は、開発ライン([[project-dev-agents]])の第一号として着手した実案件。ステラの企画9本([[project-dev-agents]]の開発案件DB)からユーザーが選んだ**女性向け美容診断アプリ**。名称は確定(いろどり=彩り、欧文 IRODORI)。2026-07-03 プロトタイプ構築。

# 何を作っているか
- 顔写真から**パーソナルカラー4タイプ**(イエベ春/ブルベ夏/イエベ秋/ブルベ冬)＋**肌コンディション/肌印象年齢**を診断。ウェブ完結・数分・イベント来場者向け。
- **プライバシー**: 画像処理は全てブラウザ内(クライアントJS)完結。送信・保存を一切しない設計(技術的に担保)。撮影は file input + capture 方式。
- **実年齢オプトイン**(ユーザー構想): 通常は年齢なしで気軽に診断。希望者だけ実年齢を任意入力すると、①肌印象年齢との差分 ②タイプ×年代の「似合わせ」補正(その年代に映える色を◆でハイライト＋年代別アドバイス)を出す。年齢も端末内のみ・非保存。
- コピーは「簡易診断/相性の目安」と明記し、正式カラー診断・医学的評価ではない旨を掲載(誠実表現で合意)。

# 精度向上ロードマップ(次フェーズ・ユーザー意向=精度を上げたい)
現状は「頬の平均肌色→黄青×明暗の4分類」の簡易ロジック(遊びの範囲、照明依存)。段階案:
- **Phase 1(費用対効果最大)**: 顔検出で頬/額を正確にサンプル＋ホワイトバランス/照明補正。撮影ガイド標準化。
- **Phase 2**: 清濁(彩度)軸を足して4→8→16タイプ、髪/瞳の色も取り込む。
- **Phase 3**: プロ診断士ラベルの学習モデル。イベントで明示同意のもと匿名データ蓄積→将来資産。プロ一致率をKPI化。
- **重要**: 本格精度向上は**本番ホスティングへ移行が前提**(Artifactは外部CDN/モデル読込不可)。担当は画像処理=ピタゴラス(system-developer)、体験UI=エジソン/リリス。
