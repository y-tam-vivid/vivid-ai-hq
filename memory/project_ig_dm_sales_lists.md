## ★IG DM営業の実務上の制約（投げる前に織り込む）

Instagram は**新規アカウントへの大量DMをスパムとして扱う**。リストが揃っても
そのまま一斉送信はできない。**リストの件数設計はこの上限から逆算する。**

```
1日あたり     数十件が上限の目安。アカウントの年齢・過去の挙動で変わる
文面          同一テンプレの連投は検知されやすい。差し込みで散らす
リスク        制限 → 一時凍結 → アカウント停止。★法人アカウントを飛ばすと痛い
```

**★リストは「一度に何件作るか」でなく「1日何件送れるか × 何日分か」で発注する。**
まず100件のパイロットを投げるのはこのため（＝数日分）。
