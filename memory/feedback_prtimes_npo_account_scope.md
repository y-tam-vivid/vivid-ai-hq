**PR TIMES の契約主体は NPO法人 南河内こどもステーション（企業ID 184772）である。**
ふくち。グループ／ビビッド／ILIFE の名義ではない。口座がNPOにあるため当面変わらない。

**Why:** 2026-08-20 有璽氏の明示指示 ──「あくまでPR TIMESはNPO法人として契約をしているものなので、
そこから逸脱する形になるとよろしくない」。配信サービスは配信主体の実在と活動実態を前提に契約されており、
**別法人の宣伝を配信すると契約上の逸脱になる**。加えて、NPOのアカウントから営利法人の集客リリースが
流れれば、NPO側の信用（1983年から積み上げた地域活動）が毀損する。

**How to apply:**

```
主語            必ず NPO法人 南河内こどもステーション。NPOが「何をしたか／何を担ったか」で書く
営利法人         ソフトバンク・ILIFE・ふくち。・Teala・テレニシ・RIALA 等は「主催」「共催」
                「ゲスト」「企画運営」として事実の範囲で登場させる。★主役に据えない・宣伝文にしない
書いてよい軸      地域の子育て課題／子どもと向き合う時間／担い手の負担軽減／インクルーシブ
書いてはいけない   営利法人の集客導線（申込先・サービス紹介・料金・問い合わせ先が営利側だけ）
                ／営利法人の実績PR／NPOの活動と接続しない発表そのもの
```

## ★NPOの取り組みは「事実の列挙」で終わらせない（2026-08-21 有璽氏）

**指摘** ──「事実は列挙していますが、**上記の世界観を目指している**」と書いてほしい。
こども食堂・一時保育・農業体験…と活動名を並べただけでは、何を大事にしている団体かが伝わらない。

```
書く順序   ① めざしている世界観
             「障害のあるなしにかかわらず、どの子も同じ場所で学び、同じ体験を持ち帰れる場」
           ② それを裏づける活動（ここで初めて事実を列挙する）
             ★活動名は証拠として置く。「どれも“誰が来てもいい場所”として設計してきた」と結ぶ
           ③ 将来設計へつなぐ
             「触れて“おもしろい”と感じた経験が、やがて“やってみたい”という将来の輪郭になる」
             「将来を思い描くための材料を、できるだけ多く・分け隔てなく手渡す」
```

- **「インクルーシブ」は言葉だけ置かない。** 何がインクルーシブなのかを具体で書く
  （障害のある子も、家庭の事情で機会が限られがちな子も、隣に座って一緒に体験する）。
- **この型は当法人名義の全リリースに適用する。** 1本だけ直して他を放置しない
  （2026-08-21、2本とも冒頭を書き換えた）。
