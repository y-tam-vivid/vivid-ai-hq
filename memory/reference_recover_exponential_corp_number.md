**`6.18E+12` のように指数表記で潰れた法人番号は、値そのものからは復元できない。** 有効数字が失われているため。しかし**指数表記は照合の条件として使える。**

```
① 国税庁の全件データから商号で候補を出す
     ローカル ~/data/houjin_bangou/00_zenkoku_all_20260731.csv（1.26GB・2026-07-31時点）
     商号は全角で格納されている（株式会社Ｏｒｉｇａｍｉ）。表記ゆれを吸収して探す
     列: 0連番 1法人番号 6商号又は名称 8法人種別 9都道府県 10市区町村 11丁目番地等 15郵便番号
② 候補の13桁を、元の表示の有効数字の桁数に丸め戻す
③ 元の指数表記と一致するものだけを採る
```

通常の採用条件（13桁＋検査数字＋国税庁の商号が社名と一致）に**これが4つ目の条件として加わる**ので、同名法人が複数あっても、住所が食い違っていても判断できる。

2026-08-12に6社を復元し、全件で丸め戻しが一致した。実例：株式会社BrightLink は同名3社あり登記住所も食い違ったが、`6.18E+12` になるのは愛知の1社だけ（東京は4.01E+12・福岡は9.29E+12）。住所の差は本店移転だった。

検査数字は先頭1桁。下12桁に重み(下位から1,2,1,2…)を掛けた和の mod 9 を 9 から引く。

```python
def ck(n):
    b=n[1:]; s=sum(int(b[11-i])*(2 if i%2 else 1) for i in range(12))
    return (9-(s%9))==int(n[0])
```

**書き込むスクリプト側でも検査数字を計算し直す。** 手元の計算だけを信じない。1件でも通らなければ何も書かずに止める作りにする（`~/data/houjin_bangou/fix_corp_numbers_6.gs`）。

## ⚠️ 単純な丸め戻しは禁止（2026-08-13・`match_kintone.gs` 実物に記載）

**`toFixed(0)` で戻してはいけない。**「13桁で**検査数字も通るが別法人を指す値**」ができる。
**実測: 壊れた4件のうち1件が検査数字を素通りした。検査数字では止められない。**

上の「復元できる」は **国税庁の全件データと突き合わせて1社に絞れる場合のみ**成立する話であって、
値だけを計算で戻してよいという意味ではない。索引の1行だけを見て「復元できる」と判断すると事故る。

- 可: 国税庁全件データ＋丸め戻し一致＋社名等の複数条件で**1社に絞れたとき**
- 不可: 指数表記の値を計算で戻して、そのまま正しい法人番号として使う（検査数字は防波堤にならない）

## ★壊れ方は2種類ある。桁数チェックでは片方しか見えない（2026-09-05 つるの実測）

**「先頭0落ち」だけを疑うと、もう1つの壊れ方を素通りする。** テレアポリストの実測で両方が同居していた。

```
型①  末尾つぶれ（指数表記の丸め）   1120000000000  ← 13桁ある。桁数チェックを通る
型②  先頭桁の欠落                  120001205322   ← 正は 8120001205322。12桁
```

- **★型①は桁数が13のままなので「桁数13か」だけでは検出できない。** 末尾の0の連続で見る。
- **★型②を「先頭0落ち」と診断して `zfill(13)` するのは誤り。**
  法人番号の先頭は検査数字で**0にならない**。ゼロ埋めは `0120001205322` を作るだけで、
  正しい `8120001205322` とは永久に一致しない ＝ **対処したつもりで名寄せが効いていない。**
- **★どちらの型も、同じ列・同じファイルの中で種別ごとに偏る。**
  実測：就労継続支援Ａ型だけ型①（事業所単位 大阪470行中448行／法人単位31行中17行）。
  他4種別は0件。**列全体を1回見て「大丈夫」と言わない。区分ごとに数える。**
- **★法人番号が壊れている区分では、法人番号を突合キーにしてはいけない。**
  代わりに **法人名＋電話番号**で束ね直すと、実測で 3,271法人 → 3,221法人（50行ぶんが同じ法人）。

## ★復元は3経路で組む ── 丸め戻しが「間違った1件」を止めた（2026-09-05 ピタゴラス実測）

テレアポリストの壊れた法人番号 **784行** を国税庁全件データ（`00_zenkoku_all_20260831.csv`・
5,827,771行）で復元した。**717行を確定・67行は確定できず空にした。**

```
経路A  商号（NFKC正規化）＋法人住所（都道府県＋市区町村）で全件データを引き、★1社に絞れたときだけ採る
        絞れなければ 番地 まで見る。それでも複数なら採らない
経路B  型①（末尾に0が9個以上）  ── 復元値を有効3桁へ丸め戻し、表示値と一致するか
        先頭桁欠け（12桁以下）   ── zfill(12) が全件データの下12桁と一致し、検査数字も一致するか
判定    A と B が一致したら確定（587行）。片方しか無いときは「1経路」と明記して採る（130行）
        ★型①は経路Bを必須にした（商号一致だけでは採らない）
```

- **★丸め戻しは効く。** 型①の409行のうち **408行が有効3桁で表示値と一致**し、
  残る1件（合同会社フォレストガンプ 表示 6.13E+12 ⇔ 商号一致の相手 1.12E+12）だけが食い違った。
  **経路Aだけなら、この1件を正しいものとして書き込んでいた。**
- **★`.zfill(13)` は誤り、`.zfill(12)` が正しい。** 落ちているのは検査数字（先頭1桁）で、
  検査数字は **1〜9で0にならない**（`9-(和 mod 9)`・mod 9 は 0〜8）。12桁は
  「会社法人等番号（検査数字なし）」とみなし、**計算した検査数字が全件データの実物と一致するか**で裏を取る。
- **★法人番号の列に別の番号が紛れている。** `2752420949`（10桁・27＝大阪の事業所番号）が
  法人番号欄に入っていた実例が複数。桁数が短い＝先頭0落ち、と決めつけない。
- **★確定できなかった67行は空にした。** 13桁で検査数字も通る壊れ値を残すと、
  kintone・台帳との突合で「ヒットしない」ではなく「別法人に当たる」事故になる。
  消した値は同じファイルの `★修正ログ_法人番号と電話` タブに全件残してある（消さずに移した）。

## ★検査数字が通っても、その法人番号は存在しないことがある（2026-09-06 実測）

**13桁で検査数字も一致するのに、国税庁の全件データに1件も無い番号が3つ見つかった。**
つるが「国税庁に無い番号3件」として出したもので、**3つとも検査数字は正しい。**

```
6114000119163  株式会社Ｇｏｔｏｓｃｈｏｏｌ → 1140001119163（東京都江東区有明）
1220001033604  株式会社それいず           → 8122001033604（大阪府八尾市東町）
3314002022819  有限会社ライフ             → 3140002022819（大阪市西区西本町）
実測：3つとも 9-(下12桁の重み付き和 mod 9) が先頭桁と一致する＝★検査数字では見つからない
```

- **★「検査数字が通る」は「存在する」の証拠にならない。** 存在の確認は
  **全件データに実在するか**の1点でしかできない。桁数と検査数字は入口の足切りにすぎない。
- **★2件は「同じ法人が2行に立つ」原因になっていた**（同名・同電話の別行が正しい番号を持っていた）。
  番号を正すと、名寄せが自動的に1行へ束ねる。**重複の一部は、番号の誤りが原因。**
- 直し方は上の経路Aと同じ ── **商号の完全一致で全国1社に絞れたときだけ採る。**
  絞れなければ空にする。今回は3件とも全国1社だった。
- **★住所が食い違っても、商号が全国1社なら採ってよい場合がある。** それいずは国税庁が
  八尾市・シートが東大阪市で違ったが、2024-12-25 に変更登記があり移転と読める。
  **ただし「移転した」と断定はしない。**食い違いは修正ログの根拠欄へそのまま書く。

## ★名寄せの正規化に「ー」（カタカナ長音符）を入れてはいけない（2026-09-06 実測）

ダッシュの揺れ（`Ｔ-ボンド` の `-` U+002D と `Ｔ−ボンド` の `−` U+2212）を吸収するため
記号を `-` へ寄せる表を作ったところ、**`ー` を入れた版でカタカナ名が20件壊れた。**

```
悪い  DASH = '-‐‑‒–—―−ー－'  → 「ライズロード」が「ライズロ-ド」になり、別法人に見える
良い  DASH = '-‐‑‒–—―−－'    → 記号のダッシュだけ。'ー' は日本語の文字なので触らない
```

**★NFKC は U+2212（−）を `-` に直さない。** 全角英数は直るので「正規化した」と思い込みやすい。
**正規化を1つ足したら、足す前と後で件数を数えて差の中身を1件ずつ見ること**（今回は
20件の差を見て気づいた。件数だけ見ていたら「1件減った」で通していた）。
