## いま何が起きているか（★資産になっていない）

```
恒久ルール①〜⑥は ★LIFE STAND UP 案件の中にだけ在る
  置き場   project_lifestandup_website_wordpress.md ／ 担当への指示文（毎回書き写している）
  結果     ★案件が終わると失われる ／ ★別案件で1から作り直す
           ★指示文へ毎回コピペしており、写し間違いが起きる余地がある
```

**★2026-09-10 時点の①〜⑥（確定版）**

```
① 右端の限界    [見学・お問い合わせ]ボタンの外へ出さない（★3本線があるときは3本線が最外側）
② 上端の限界    パンくずリストより上へ出さない
③ テープの定位置 マスキングテープは一番右端が基本。他を動かす
④ 対象外        背景と分かるもの（星・葉・雲・丸い小イラスト）★だけ
                ＝ ★それ以外は全部①②③の対象（「判断がつかない」分類は廃止）
⑤ ヘッダー⇄パンくず  WEB 40px ／ タブレット 35px ／ スマホ 24px（★比率で再計算した）
⑥ ボックスの位置  ★WEB版のみ：[見学]の右端から60px左手（★スマホ・タブレットには適用しない）
```
