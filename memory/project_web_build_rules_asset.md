## 🔴2026-09-10 有璽氏の真因診断 ── ★崩れるのはオートレイアウトの設計不足

> 「理由としては、**この特にオートレイアウトの部分**かな、が**うまく設計できてないが故に崩れてしまう**。
>  また今**タブレット版、スマホ版も見てる**けど、**やっぱり崩れてしまっています**。
>  特にトップ、**ファーストビューの部分に入ってくるやつ**なんやけど、**箱がむちゃくちゃ崩れてる**。
>  それをどういうふうに解消したらいいかなと。**今考えておいた方がいい**んじゃないかな。
>  特に**上の部分、今日何回も修正してるやつ**に関してはあったらいいと思います。
>  なんかそれが**Figmaのように可視化してわかるとよりいい**なと思うんだけどね。」
