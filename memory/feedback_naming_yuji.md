**ユーザーの呼称は「有璽」または「有璽氏」に統一する。**（2026-08-13 指示）

**Why:** 「本人」は誰を指すのか読み手に伝わらない。特に**複数セッション・複数エージェントが並行して動く体制では、"本人" が有璽氏なのか他の当事者なのか判別できなくなる**（実際、別セッションへの申し送りで「本人指示」とだけ書いた記述が、出典の曖昧な伝聞として扱われた）。

**How to apply:**

| 使わない | 使う |
|---|---|
| 本人 / ご本人 | **有璽氏**（記録・申し送り・Notion）／**有璽**（会話中の軽い言及） |
| 田村さん | 同上 |

- **適用範囲は出力すべて**：チャット応答／Notionページ・DB／memory／他セッションへのメッセージ／スクリプト内のコメント。
- 既存ファイルの一括置換はしない（今後書くものから統一）。ただし**編集で触れた箇所は直す**。
- 議事録DBの名寄せで確定済みの「田村有璽＝田村天佑＝田村佑司＝田村裕二は同一人物」は別の話（データ上の正規表記）。データの値としては `田村有璽` を使う。

## 対外の名義・肩書き（2026-08-25 有璽氏）

**社内の呼称とは別の話。外へ出す文章では、こう書く。**

```
肩書き    ★「代表」。「代表取締役」は使わない
所属      ふくち。グループの代表である田村が、同グループの株式会社ILIFEとして登壇した
          ── グループが先、個社が後。個社だけを主語にしない
```

**Why:** 個社名だけで出すと、グループの取り組みが個社の活動に見える。逆にグループ名だけで
出すと、実際に登壇した法人格が消える。**両方を、この順番で書く。**

**How to apply:**

| 場面 | 書き方 |
|---|---|
| プレスリリース・ブログ・SNS | ふくち。グループ代表の田村が、同グループの株式会社ILIFEとして |
| 開催概要の1行 | 登壇｜ふくち。グループ 代表 田村有璽（株式会社ILIFE） |
| 使わない | 株式会社ILIFE 代表取締役 田村有璽 ／ ILIFE単独の主語 |

- **★制作物に実物があっても、そちらを自動的に正としない。** 2026-08-25、告知バナーの実物に
  「株式会社ILIFE 代表取締役 田村有璽」とあり、こちらは実物を正として全原稿を揃えた。
  **有璽氏の判断で覆った。** 実物は「先方が作った版」であって、こちらの名義方針ではない。
  → 実物と方針が食い違ったら、揃える前に並べて聞く（[[feedback_dont_call_it_a_typo]] と同じ型）。

- **★2回目（2026-09-03・オレンジワークス ポートフォリオサイト）。** 掲載中のタイトルと
  ローカル台帳が2件食い違い、こちらは**作品画像に焼き込まれた文字**（「マネーシンギュラリ
  ティータウンの子どもたち」「ハッピーアワーチラシ A5・片面」）を根拠に「台帳が正・掲載を直す」
  と判定した。**有璽氏の判断は逆で「いま掲載している方が正しい。台帳を直せ」。**
  さらに作品内の長音（シンギュラリ**ティー**）自体が誤記だった。

```
実物にある文字   その作品を作ったときの版。誤記も、途中の版も、先方の都合も含む
掲載する名前     いま何と呼んで見せるかの判断。作品名とは別に決まる
                 ★前者から後者を導かない。並べて聞く
```

  **判定の材料としては使ってよい。判定そのものを実物に肩代わりさせない。**
