## 何が起きたか（2026-09-05 実測・テレアポリスト）

**★要判断_同一法人の候補タブの上287行は、行番号を辿れた279件のうち277件が別の法人を指していた。**

```
つるの実測   要判断2行目「株式会社ジーエル」→ 法人単位_就労移行支援 の21行目 は「株式会社エンカレッジ」
             要判断6行目「ＮＰＯ法人ＲＩＴＡＲＭ」→ 法人単位_就労継続支援Ａ型 の2行目 は「合同会社ケアサービス」
             さらに8行は、実物のタブ行数を超える行を指している（Ｂ型1,433行目・実物は1,394行）
同じ型が2枚目に  ★修正ログ_法人番号と電話 の法人単位分155行も 152/155 が別法人を指す
                 ★しかもこちらには注記が1行も無い
```

作った側に落ち度は無い ── **287行を書いた時点では正しかった。**そのあとで有璽氏の決定が変わり、
法人単位6タブを事業所単位から組み直したので、行番号だけが取り残された。

## なぜ注記では守れなかったか

区切り行「★上の287行は組み直し前の行番号を指しています」は **289行目**、
つまり**無効になった287行より下**に置かれている。

```
1行目     見出し
2〜288行  G001〜G130（★この行番号は全部無効）   ← 人は上から読む。ここで開いてしまう
289行目   「上の287行の行番号は無効です」        ← 読むころには手遅れ
290行〜   H001〜（新しく出た候補・行番号は有効）
```

- **★さらにフィルタが付いている。**並べ替えた瞬間、注記行は候補行から離れて意味を失う。
- **注記は「無効な行の上」か、無効な行**そのもの**に置く**（列を1本足して全行へ「参照は無効」と書く）。

## 型（次に同じことをする人へ）

- **★人へ渡す一覧の参照キーに「行番号」を使わない。**行番号は表を作り直せば必ず腐る。
  代わりに **法人番号・事業所番号のような、行が動いても変わらない値**を書く。
  行番号を併記するなら「2026-09-05 16:20 時点」と**版を添える**。
- **★元表を組み直したら、その表を指している一覧を全部数え直す。**
  今回は要判断タブと修正ログの2枚が同時に腐った。片方にだけ注記が付いた。
- **注記で守るのは最後の手段。**上から読む人に届く位置か、並べ替えても壊れないか、を先に見る。

## この一覧が救われている点（公平に書く）

- **★同じ相手へ2回かける12組は、法人名で照合すると12組とも要判断タブに載っている**（つる実測）。
  つまり**判断の材料としては生きている。**壊れているのは「どこを見ればいいか」の道案内だけ。

## どう直したか（2026-09-06 実測・ピタゴラス）

**行番号を参照キーにするのをやめた。** 注記で守るのではなく、**列の中身を替えた。**

```
I列  「法人単位_就労移行支援 の 21行目」   ← 腐る
  ↓
I列  「法人単位_複数サービス ／ 法人番号 4120001192804 で検索」   ← 行が動いても変わらない
K列  「57行目（★2026-09-06 時点。並べ替え・作り直しで変わる。これで指さない）」
L列  「（旧）法人単位_就労移行支援 の 21行目 ★無効」  ← 消さずに残す
```

- **★参照キーは 法人番号 →（無ければ）法人名＋電話 →（無ければ）法人名 の順で引く。**
  同名が2行以上なら「★同名がN行ある。法人番号か電話で絞ってください」と正直に書く。
- **★列で持つと並べ替えでも壊れない。**注記行は並べ替えで候補から離れるが、列は行についてくる。
- 実測：★要判断1,144行・★修正ログ155行を貼り直し、**I列に「行目」が残った行 0件。**

### ★ここで自分が踏んだ地雷 ── 「解決済み」は全行が見つかったときだけ書く

同じグループの行が同じ1行を指したら「★組み直しで束ねられた＝判断は不要」と書く実装にした。
**片方の行が見つからなかったグループにも、この文言が付いた**（実測4件・G080/G097/G101/G119）。

- 「見つかった先が1つ」と「全行が見つかった」は別。**片方が行方不明なだけで1つに見える。**
- **人が確認をやめる文言を書くときは、条件を「全部そろったか」で締める。**
  書く前に対象を数えて実物で確かめたので、シートへは出ていない。
