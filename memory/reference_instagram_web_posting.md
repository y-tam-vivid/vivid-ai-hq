**2026-10-13 こどもステーション（stationkodomo）で実測**

| やりたいこと | ウェブ版（instagram.com） |
|---|---|
| カルーセル投稿（10枚まで） | ✅ できる。★切り取りの既定は1:1＝必ず「切り取りを選択」→4:5 に替える |
| 予約投稿 | ✅ できる。キャプション画面の「コンテンツを日時指定」→日付（カレンダー）・時・分。一覧は `/scheduled_content/` |
| プロフィールのリンク（ウェブサイト）変更 | ❌ 「リンクはモバイルデバイスからのみ編集できます」＝スマホのアプリで人が変える（10/14 有璽氏が手で直した） |
| ストーリーズ | ❌ 10/14 実測：PC の「作成」メニューは「投稿／ライブ動画／広告」の3つだけ＝スマホのアプリで出す（画像は `~/kodomo-photo-work/story_maker.py` で 1080x1920 を作り Drive `07_Instagram活動レポート/ストーリーズ/` へ） |

- ★**Meta Business Suite（business.facebook.com）はオレンジワークス（orange.works.fj）が選ばれていた**。こどもSの投稿先は出てこない＝こどもSの投稿・予約に Business Suite を使わない（別法人へ誤投稿する）。
- 自動操作のタブは裏（hidden）でクリックが効かない＝ボタンは JS の click()、本文は `ClipboardEvent('paste')`（Lexical のエディタ）、時・分は欄に focus してからキー入力（値の setter は効かない）。
- ★本文は貼った後に**元ファイルと完全一致を照合してから**押す（10/13 先頭に改行が1つ紛れた・削除は cmd+a→Backspace のキー操作でしか消えなかった）。
- ★Drive の日本語ファイル名はそのまま上げられない＝scratchpad へ英数名で写して上げる。
- ★同じ Chrome を有璽氏も使う：10/14 タブが別アカウント（個人）のページに移っていた＝投稿前に毎回「stationkodomo」で開いているかを見る。

- 調査の結論（★子育て層に限った Instagram の時間帯データは公的にも調査会社にも見つからず＝推論）：第1候補 平日 18:30〜21:00（子どもを寝かせた後）、第2候補 平日昼 12時台。9:00 は在宅の保護者・シニア・近隣に届くがワーママには弱いと推測。18:00 は夕食・入浴の家事時間に当たりやすい。

**2026-11-05 個人IG（yuji_tam3.0_2026）で複数本を続けて予約した実測**
- ★Chrome が別アカウント（stationkodomo）のまま開いていた＝予約前に作成画面のプロフ名を毎回見る。切り替えはパスワード不要。終わったら元へ戻す。
- ★1本予約したら `/scheduled_content/` を読み込み直す（同じ画面で続けると作成画面が閉じる）。
- 切り取りは座標でなく JS（`svg[aria-label*="切り取り"]` の親を click→innerText `4:5` を click）。座標だと 1:1 のまま・時刻 14:08 になって確定前に破棄した回がある。
- 時刻の欄だけは画面座標で click→キー入力→zoom で「日付／時間」を目で見てから「投稿日時を指定」。
- カレンダーの「>」は読み込み直後だと効かない・週を飛ばすことがある＝見出しの日付を見て確かめる。
- ★確定後の「日時指定中」が10秒で終わらず、読み込み直したら枠が空に見えた回がある（11/27）。もう一度読み込むと入っていた＝★空に見えても作り直さない（二重予約になる）。少し置いて読み直してから判断。
