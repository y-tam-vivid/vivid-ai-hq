**Mac mini のターミナル（このチャット画面）からは、テキストをコピーできない。**

> 「二度と言わせるなよ。Mac miniはコピペできないっつってんねん。
>   だからここにコード貼っても俺は触れないんだよ。コピーできないんだよ。
>   これほんま何回も言ってるから、二度と言わせん」（2026-08-20 有璽氏）

**Why:** 有璽氏は MacBook で作業しており、mini のターミナル出力は「見えるが触れない」。
SSH越しだと Terminal.app のクリップボード（OSC52）も効かない
（→ [[project_macmini_remote_workhorse]]）。
**チャットに出した時点で「渡した」と思い込むのが誤り。** 見せただけ。

## How to apply ── 渡し方は3つだけ

```
✗  チャットにコードを貼る                触れない。渡していない
✗  チャットに長いURLを貼る                同上
✗  「◯◯の画面を開いて…を探して」        押す場所が特定できていない

✓  Slack DM へ送る                      MacBookのSlackからタップ・コピーできる
✓  Drive / Notion に置いてリンクを渡す    リンクはSlack経由でタップできる
✓  ★そもそも人の手を要らなくする          いちばん良い。下記
```

### ★最善は「渡さない」

人に何かを貼らせる時点で設計が負けている。自動で届く経路を先に探す。

| やりたいこと | 人に貼らせる（✗） | 自動で届く（✓） |
|---|---|---|
| 他機へフックを入れる | 「この1行を貼って」 | `bin/vivid-sync.sh` が15分ごとに走るので、そこで自動導入する |
| 他機へ設定を配る | 手順書を渡す | git に入れて `setup` を同期処理から呼ぶ |
| 他セッションへ申し送り | 「伝えておいて」 | `WORKING.md` に書く（毎ターン全機へ届く） |

## ★返事は「出した経路」へ返ってくる（2026-08-20 有璽氏）

> 「**Slackから私の回答は既に行っている。**1で進めて。」（2026-08-20 09:07）

**Slack へ問いを出したら、答えも Slack に来る。** ターミナルのチャットに返事が無いことを
「未回答」と読むと、**既に答えたことをもう一度聞く**ことになる。

```
問いを出した先      答えが届く先
Slack DM        →  Slack DM（★ターミナルには出ない）
📮AI指示箱       →  指示箱のページ（inbox_runner が */5 で拾う）
ターミナル       →  ターミナル
```

- **★待つ前に、自分が出した経路を確認する。** 経路をまたいで問い直さない
- **問いを複数経路へ同時に出さない。** どこに答えが来るか決まらなくなる
- 選択肢を出すときは**番号を振る**（「1で進めて」と1語で返せる）。
  有璽氏はコピーできないので、**返答が短く済む形にしておくこと自体が渡し方の一部**

## ★構造の報告は Slack にも送る（2026-08-29 有璽氏）

> 「二度と発生しないような根本的解決策を、今の原因とともに突き止め提示しろ。
>  **同じ内容をSlackにも通知しろ。**」

**ターミナルの報告は残らない。** 有璽氏はコピーできず、後から読み返せず、
別の面（スマホ・MacBook）からは見えない。**構造にかかわる報告は Slack DM へも送る。**

```
送る            構造の原因と対策／判断を仰ぐ事項／今日決まったこと
送らない        作業の途中経過／ツールの出力／こちらの内省
宛先            有璽氏へのDM（★チャンネルへ投げない）
長さ            読み切れる量に畳む。全文はターミナル側に残す
```

★「報告した」はターミナルに書いた時点では成立しない。**届く場所に置いて初めて成立する。**


## ★縦に長い画像は転送で弾かれる ── 分割して渡す（2026-09-03 実測）

ページ全体のスクリーンショットを有璽氏へ送ろうとして、4枚中3枚が `server returned 400` で落ちた。

```
届いた    1440 × 7,208 px（1.18 MiB）
落ちた    1440 × 8,446 px（1.4 MiB）／ 390 × 12,271 px（1.1 MiB）／ 390 × 10,798 px（0.9 MiB）
★0.9MiBが落ちて1.18MiBが通った＝容量ではない。★縦の長さが効いている
```

- **対処＝縮小ではなく分割。** 縦6,500px程度で上下に割る。
  **★縮小すると文字が読めなくなり、レビューの用を成さない**（見せる目的が「デザインの確認」なので）。
  → [[feedback_artifact_accumulate_dont_replace]]（縮小版を渡すなら必ずそう言う、の裏返し）
- **★落ちたら黙って諦めない。** 「送れませんでした」で止めず、割ってでも届ける。
  ページ全体の絵は、分割しても連続して見れば用を成す。
- 分割したら**何分割の何枚目かをキャプションに書く**（順番が分からないと読めない）。
