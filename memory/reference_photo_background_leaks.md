# 写真は被写体でなく「背景」で事故る

**2026-09-03 実地。** LIFE STAND UP サイトの掲載写真266枚を検分中に発見。

```
見ていたもの   誰が写っているか（顔・後ろ姿・手元）＝掲載同意の話
見落とすもの   ★その人の後ろに何が書いてあるか
実物          ホワイトボードに児童の名前が書かれており、拡大すると読める
              （Photo-211・212・222・236 ほか。板書が写るカットは他に40枚以上ある）
```

**★掲載同意を取っても、これは解決しない。** 同意は「あなたを写してよいか」であって、
**背景に写り込んだ別の児童の名前**は同意の範囲外。福祉施設では個人情報の漏えいそのもの。

## ★縮小版では見えない。原寸で読む

```
400px の縮小版   文字がつぶれて読めない → 「問題なし」に見える
原寸             読める
```
**縮小版で一覧して選び、そのまま公開すると必ず抜ける。**
選定は縮小版でよいが、**採用が決まった枚は必ず原寸で1枚ずつ読む。**
→ [[feedback_one_route_is_not_verification]]（縮小版だけは1経路）

## 背景で見るもの（チェックの順）

```
1  文字が書かれた面    ホワイトボード・黒板・模造紙・掲示物
2  紙                 名簿・記録用紙・個別支援計画・出席表・机上の書類
3  画面               PC・タブレットに個人情報が表示されていないか
4  持ち物             名前が書かれた道具・靴・カバン・ロッカーの名札
5  ★内容の正しさ       書いてある中身が間違っていないか（下記）
```

## ★5番目 ── 書いてある内容が間違っていることがある

同じ回に見つかった2件目。英語療育の証拠として使う板書のカットに**英文の誤りがあった**。

```
Photo-100  板書 "Question: Do you going to school?"（正しくは Are you going to）
★英語療育を売りにするページに載せると、証拠のつもりが逆効果になる
```
**専門性を示すために撮った写真ほど、写っている中身の正しさを見る。**
判定できるのはその領域の人（この件なら英語スタッフ）。**こちらで直さない。差し替えるか外す。**

## 誰が決めるか

```
背景の写り込み     施設。★原寸での洗い出しは施設と一緒にやる（AIの縮小版検分では足りない）
顔の掲載可否       本人・保護者・施設
写っている中身     その領域の担当（英語なら英語スタッフ）
```
**AIは判断材料を作る役。可否は決めない。** → [[feedback_write_for_the_reader]]
