**有璽氏の指示文は音声入力のことがある。人名の漢字は当てにならない。**
2026-10-07、スタッフ台帳の更新で「中村美里」と来たが、メール・面談記録の表記は「中村実里」。
こちらは記録の表記で登録して確認を求め、有璽氏は「書いてある名前で合っている」と返した
（返信も音声入力で「美里」と出ていた＝★返信の漢字でも判定できない）。

**Why:** 音声入力は同音の別字を当てる（美里／実里、「書いてある」→「抱いてある」）。
日付も言い直しが起きる（柴田の退職は最初「9月末」→ 訂正で「9月4日付」）。

**How to apply:**
- 人名を台帳へ書くときは、メール・Slack・議事録など★別の出どころの表記を先に探し、そちらを正とする。指示文の表記は「別名・表記名」に残す。
- 返信の漢字で確定しない。「どちらの字で登録したか」を言葉で返し、違えば直すと書く。
- 日付は書いたあと、何日で入れたかを返事に必ず出す（言い直しに気づけるように）。
