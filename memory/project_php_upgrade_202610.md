★ホスト側が版番号を変えずに直している場合がある（表示が 8.3.35 でも修正済みのことがある）＝版番号だけで判断しない。
さくら：10/23「提供しているPHP（サポート終了版を含む）に必要な修正を適用・対応完了」／最新のサポート対象版を推奨。
