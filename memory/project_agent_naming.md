ふくち。グループで今後作るAIエージェントは、**ONE PIECEの登場人物名**で統一する。中核のCXO/サポート役は**麦わらの一味**の“職種”を経営機能に対応させる。開発ラインは別系統として**ドクターベガパンク(本体ステラ＋分身サテライト)**の名を使う。

**確定済み(構築済み)**
- 秘書 / チーフ・オブ・スタッフ → **ビビ**(ネフェルタリ・ビビ。CXOとは別枠のサポート役)。詳細は [[project-secretary-agent]]。
- **CFO** → **ナミ**(2026-07-02 構築済み)。詳細は [[project-cfo-agent]]。
- **開発ライン(ベガパンク系)**(2026-07-03 構築済み)。詳細は [[project-dev-agents]]。
  - 開発統括PD/ディレクター → **ステラ**(ベガパンク本体) / アプリ開発 → **エジソン** / システム開発 → **ピタゴラス** / ウェブ制作 → **リリス**。
  - 未割当のサテライト(**枠は温存する方針**): ショック / アトラス / ヨーク。予約マップ案=QA→ショック / 運用SRE→アトラス / データAI→ヨーク(今は作らない。詳細 [[project-dev-agents]])。
- **外部CCO(外部委託の最高広報責任者 / 広報PR)** → **モルガンズ**(2026-07-03 構築済み、定義のみ)。世界経済新聞社社長由来。一味とは別枠の“メディア界の大物”枠、外部から参画する第三者視点の立て付け。詳細は [[project-pr-agent]]。
- **CKO(ナレッジ情報統括)** → **ロビン**(2026-07-06 構築済み)。調べた情報の読み解き・保全・引き出し。会議準備を担当(裏方でビビへ受け渡し)。詳細は [[project-cko-agent]]。
- **CLO(法務・渉外)** → **センゴク**(2026-07-08 構築済み)。元海軍元帥センゴク由来。契約リーガルチェック/危険・欠落条項/レッドライン案/日本法コンプラ。Claude for Legalプラグイン(commercial/privacy/corporate)をエンジンに二層構成。詳細は [[project-legal-agent]]。
- **研究調査担当(産学連携 / CRO相当)** → **クローバー博士**(2026-07-06 名記のみ)。オハラの考古学者クローバー博士由来。実在の産学連携研究(大学の先生と進行中)の社内担当。一味とは別枠の"学者"枠。本体エージェント未構築(名鑑登録のみ)。

**麦わらの一味以外の特別枠**: モルガンズ(外部CCO)、クローバー博士(研究)のように、役割に合えば一味以外のONE PIECEキャラも採用する。

**CXOマッピング案(残り=名鑑に予約枠として登録済み 2026-07-06)**
- CEO → ルフィ / COO → ゾロ / CTO → フランキー / CMO → ウソップ / CHRO → サンジ / 健康・監視 → チョッパー / **CSO(戦略) → ジンベエ**(名鑑にステータス「予約」・本体未構築)。CLO(法務・渉外)=センゴクは上記のとおり2026-07-08構築済みに移行。
- 注: 当初CSO想定だったロビンは**CKO(ナレッジ統括)**に確定。**CSO(戦略)=ジンベエ**(当初ジンベエはCLO案→戦略へ変更)。**CLO(法務・渉外)=センゴク**(仏のセンゴク由来。2026-07-06確定)。
- 注: 開発領域はベガパンク系で立てたため、CTO(フランキー)は技術戦略/経営レイヤーの役割として整理し、実開発はステラ配下に置く想定。

**Why**: 群像劇として世界観が統一され愛着が湧く。麦わらの一味は専門職集団のためCXO役割にきれいに対応する(スラムダンク等は財務/技術/マーケ役が不足するため見送り)。
