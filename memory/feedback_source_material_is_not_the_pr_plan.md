**配布物に書いていないことを「書かない」で済ませない**（2026-10-03 有璽氏）。

```
こちらの判断   チラシに「40年以上の歴史」が無い → 原稿に入れない → 確認事項へ送った
有璽氏の指示   「40年以上の歴史は、チラシではうまくPRできていない。
                ★そのあたりも出したい」
```

- **★チラシは団体が作った素材であって、広報の設計図ではない。**
  現場が毎年刷っているものには、現場にとって当たり前すぎて落ちる価値がある。
  **落ちているからこそ、外の人には効く。**
- **★「一次資料に無い」は、諦める理由ではなく聞きに行く合図。**
  事実の裏取りが要るのは変わらない。**違うのは、聞かずに落とすか、聞いてから決めるか。**

## 混同しないための線引き

```
数字・日時・固有名詞・URL   ★推測で埋めない。裏取りが要る
                            → [[feedback_never_write_an_unmeasured_number]]
価値づけ・文脈・歴史        ★団体は持っているがチラシに書いていないだけ。
                            こちらが落とすのでなく、★候補として挙げて人に選ばせる
```

**出し方** ── 確認事項へ「無いので書きませんでした」と並べるのは不足。
**「出すならこう書けます」という1文を添えて出す。**人は見れば判断できるが、
無い文章は判断できない。

## この案件での実例（第37回こどもまつり）

```
チラシが打ち出していなかったもの
  前身「羽曳野おやこ劇場」から40年以上の継続   ★有璽氏が「出したい」と明示
  実行委員の年齢層（★小学生から高校生まで）    チラシは「小学校高学年、中学生」と狭く書いていた
  規模（例年 延べ500名・20店・実行委員8名）    チラシに数字が1つも無い
```

★**チラシの記述より有璽氏の情報が新しい・広いことがある。**
食い違ったら実物を正とせず、**並べて聞く** → [[feedback_dont_call_it_a_typo]]

## ★配布物をそのままメインビジュアルにしない（2026-10-03 有璽氏・同日2件目）

**チラシをプレスリリースの画像欄へ入れたら、有璽氏から
「チラシはあんまりデザインとして優れていないので、なんか別のものを作る方がいい」。**

```
こちらの判断   チラシは一次情報で内容も正しい → ★そのまま紙面の画像に使った
実物           ★白黒コピーをスキャンしたもの。手書き文字・粗い網点
有璽氏の指示   ★別に作る。生成AIで作れないか
```

- **★「中身が正しい」と「人前に出せる見た目」は別の判定。**
  一次情報として正しいことは、そのまま配信物に載せてよい理由にならない。
- **★記事に転載されるのはこの1枚。**リリースの画像は媒体がそのまま使う。
  配布用に刷った白黒のチラシが、全国に出る唯一の絵になる。
- **★載せる前に「拡大して1枚だけ見る」。**縮小表示では粗さが分からない
  → [[reference_supplied_material_needs_screening]]（同じ型の3例目）

```
チラシの使い道      ★補足の資料として小さく添える／内部の事実確認に使う
メインビジュアル    ①現場の写真（様子が伝わる・★有璽氏はこれを優先）
                   ②生成AIで作る（鍵は ~/.vivid-relay/config.env の OPENAI_API_KEY・
                     道具は bin/gen_images_openai.py）
```

**★写真が先、生成画像は補助。**「様子で掲載したい」が有璽氏の言葉。
実際の現場が写っているものが最も強く、生成画像はそれを置けない枠を埋めるためのもの。
