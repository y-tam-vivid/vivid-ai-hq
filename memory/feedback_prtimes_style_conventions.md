**2026-08-25、当方が入稿した本文を有璽氏が手で直した。その差分＝これが正の型。**
（release_id=4「親子向けAI体験イベント 開催報告」で実測）

```
タイトル    ★内容を先頭に置き、団体名は末尾へ「／」で回す
            before  NPO法人南河内こどもステーション、親子向け無料AI体験イベントに共催として…
            after   親子向け無料AI体験イベントに共催として参画し、大阪・京都の2ヶ所で計4日間開催
                    ／NPO法人南河内こどもステーション
太字        ★「■ 見出し」だけ。本文中の強調は使わない
見出しの飾り  「■ 開催の背景 〜 AIに触れる機会の差を、地域で埋める 〜」
            ★ダッシュ（――）は使わない。副題は 〜 〜 で挟む
本文の――    句点で切る。「隣に座って一緒に体験する ―― その当たり前を」
            → 「隣に座って一緒に体験する。その当たり前を」
番号        ①②③ ではなく (1)(2)(3)。手順は STEP1／STEP2／STEP3
固有名詞     ★スペースを詰める。「田原 均」→「田原均」／「たはら ひとし」→「たはらひとし」
            「NPO法人 南河内こどもステーション」→「NPO法人南河内こどもステーション」
改行        1項目1行。開催概要は「第1回：日付」と「会場」を別行に割る
            実績も「7月の実績：」で改行してから内訳を並べる
語          「事前予約なし」→「事前予約不要」
```
