**Roblox は非公式利用での名称・ロゴ使用を厳しく制限している。**
出典＝Roblox Terms of Use ／ Roblox Name and Logo - Community Usage Guidelines
（社内資料「AIコンテンツイベント開催事例」p.12-13 に要点整理あり。★法的助言ではない）

```
名称     ★イベント名・タイトル・見出しに「Roblox」を含めない
         タイトルは「AIでゲームを作る体験」等。詳細欄にテキストで
         「使用ツール：Roblox Studio／Roblox Corporationとは無関係の非公式イベント」と明記
ロゴ     看板・チラシ・サイネージ等でのロゴ／バッジ使用は不可（オフライン販促は事前承認制）
         「Roblox公式」「Roblox×◯◯」など提携・後援を示唆する表現も禁止
商用     参加無料ならライセンス契約は不要。★参加費・物販・チケット販売を伴うなら事前確認が要る
操作     Studioの利用権は貸せない＝スタッフが操作主体。参加者にアカウントを作らせない
運用     イベント専用アカウント（資産ゼロ・1端末1アカウント）／チャットとTeam Createはオフ
公開     ★Publishすると制作物の広範な利用権がRoblox側に発生する。公開・データ配布はしない
         「制作データの持ち帰り不可」を事前告知し、完成画面の写真撮影で代替する
持込     AIプロンプトに氏名・学校名を入れない旨を冒頭でアナウンス。既存IPはテンプレ側で排除
```

- **事故が最も起きやすいのは主催側・施設側が作る告知物とサイネージ。** 企画段階で関係者へ共有する。
- **プレスリリースも告知物と同じ扱い。** 2026-08-21、当方が見出しへ「Roblox」を入れて作成し、
  資料を読んで是正した。**見出しから外し、注記でツール名として書くのが正しい形。**
- 受付時に参加同意・写真撮影・SNS掲載の可否をあわせて取得する運用になっている。
