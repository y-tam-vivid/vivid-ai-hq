**自動処理が止まる型は2つある。プログラムが落ちる型と、人が一度押した却下が永続化する型。**
後者はエラーを出さず、処理としては成功しているので [[project_automation_register]] の心拍でも検知できない。

```
却下 → 登録しない・ファイルも動かさない → だが「処理済み」として記録される → 二度と拾われない
```

2026-08-14実測: 議事録GASで87件がこの状態にあり、23日間の空白を作っていた。
**復旧直後・移行直後に大量の承認要求が一度に出る設計は、この型を必ず生む。**
量が多ければ人はまとめて却下する。そしてそれは記録上「処理した」ことになる。

**見つけ方** ── エラーログではなく**結果の側**を数える。日付別の件数を出し、
連続して0件の日を探す。土日以外の0が並んだら疑う。

**直し方** ── 処理済み記録から該当行を消せば未処理に戻る。原本は無事。
ただし**消す前に必ずシートのコピーを取る**。
