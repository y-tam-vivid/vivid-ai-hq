判断を有璽氏に求めるときは、**対象を名前（件名）で並べてから聞く**。件数や「今回登録した分」「保留の3件」だけで聞かない。

**Why:** 2026-10-03、棚卸し登録の公開可否を「今回登録した分を社外秘でそろえてよいか」と聞いたら「今回登録した分てどれに当たる？」、保留3件を名前だけで出したら「もう少し教えて」と返された。作業した側には自明でも、受け取る側には中身が見えない。

**How to apply:** ①対象を名前で列挙（多ければ表）②1件ずつ「何と何が同じかもしれないのか」を具体物（ファイル名・DB名）で書く ③選択肢と推奨を添える。→ [[feedback_stop_asking_just_do_it]]

## ★2026-10-08 続き ── 渡すときの列挙は「上限」になる

有璽氏の指示（表示名の置換）を実装担当へ渡すとき、含める場所を
**「タブの題・ログイン画面・共通の見出し」の3つで列挙した。**
実装担当は**4か所目＝招待の受け付け画面**を自分で見つけて直した。

```
🔴 列挙は「ここもやれ」だけでなく「ここまででよい」とも読める
   → 相手が几帳面でなければ、★列挙に無い場所は漏れる
★正しい渡し方
   ① 原則を先に書く   「★画面に文字として出る所は全部」
   ② 列挙は例として    「例：タブの題・ログイン画面・共通の見出し（★これで全部とは限らない）」
   ③ ★数え方を渡す     「置換後、描画された文字で『家計台帳』が0件を確かめる」
```

★**③があれば、列挙が不完全でも相手が気づける。** 今回それで4か所目が出た。
→ 件数と同じ構え：[[feedback_never_write_an_unmeasured_number]]（数え方を添える）
