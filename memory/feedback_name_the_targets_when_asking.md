判断を有璽氏に求めるときは、**対象を名前（件名）で並べてから聞く**。件数や「今回登録した分」「保留の3件」だけで聞かない。

**Why:** 2026-10-03、棚卸し登録の公開可否を「今回登録した分を社外秘でそろえてよいか」と聞いたら「今回登録した分てどれに当たる？」、保留3件を名前だけで出したら「もう少し教えて」と返された。作業した側には自明でも、受け取る側には中身が見えない。

**How to apply:** ①対象を名前で列挙（多ければ表）②1件ずつ「何と何が同じかもしれないのか」を具体物（ファイル名・DB名）で書く ③選択肢と推奨を添える。→ [[feedback_stop_asking_just_do_it]]
