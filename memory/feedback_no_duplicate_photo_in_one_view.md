**同じ画面に並ぶカードで、同じ写真を2枚使わない。** カードを1枚足したら、その一覧の写真の重複を数えてから公開する。

**実例（2026-10-04 有璽氏）**：こどもステーション団体サイトのトップ「活動レポート」で、
新しく足した「第37回こどもまつりを開催します」と、隣の「第36回こどもまつりを開催しました」が
同じ写真（photo-kodomo-ichi.jpg）だった。有璽氏が画面で見つけて指摘した。
→ 第37回の側を「会場いっぱいの来場者」（fg-2016-crowd.jpg）へ差し替え（v33）。

**Why:** 隣り合うカードが同じ写真だと、別の記事に見えず「作りかけ」に見える。
足した側は「関連する写真」を選んだつもりでも、既存カードと同じ候補に行き着きやすい
（同じ題材＝同じ代表写真になる）。

**How to apply:**
- カードを追加・差し替えたら、同じ一覧の `img:` を数える（`grep -o "img: '[^']*'" | sort | uniq -c`）
- 2以上があれば、同じ一覧の中かを見て、片方を別の写真へ
- ★別セクション（例：注目の取り組みと活動レポート）にまたがる重複は、有璽氏の指摘が無い限り今回は直していない
  （10/4 実測でトップに2回ずつ出る写真が他に3枚：photo-shuji / photo-shokudo / photo-craft）
