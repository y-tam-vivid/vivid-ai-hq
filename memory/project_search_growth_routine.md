**2026-10-13 有璽氏の指示（全文の要点）**
「SEO・MEO・AIO の担当がいれば、そこにすべてログとして残す。会社として成功事例を積み上げ、失敗事例を防ぐ。
改善した部分・やった結果で良くなったことをログにし、担当が見られるようにする。それをサイト作成の際に活かす。
そういう改善のルーティンを作る。基本はお任せ。実装できるように、流れを作り込んで。」

**Why:** 10/12 の週次で有璽氏が「AIに任せる（実施）」と答えた打ち手2件が、誰にも拾われず「候補」のまま止まっていた（→ [[feedback_seo_standard_kit]] の 10/13 🔴）。有璽氏「こちらから働きかけないといけないのか」＝★人が押さなくても回る形が要件。

**How to apply（作るもの・2026-10-13 着手）:**
```
週次レポート（月7:00）── 打ち手を起票（候補）→ Slack で採否
        ↓ 回答
橋（mini・毎日）── 回答を改善ログへ（採用／見送り）。AIに任された未実施を数えて担当の作業一覧へ
        ↓
担当（SEO・MEO・AIO）── 直す前／直した後を有璽氏に見せて公開 → 実施日・根拠の数字
        ↓ 2〜4週後
効果確認 ── 週次の数字で「良くなった／変わらない／悪くなった」を記録 = 成功・失敗の事例
        ↓
サイト制作 ── 新しいサイト・LPを作る前に、事例（成功・失敗）を読んで最初から入れる
```
