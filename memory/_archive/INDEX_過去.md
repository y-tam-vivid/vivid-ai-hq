# 索引から降ろしたもの ── 履歴

**★ファイルは消していない。`memory/` にそのまま在る。** 降ろしたのは「毎ターン届く索引に載せること」だけ。
ここを見れば、いつ・何を・なぜ降ろしたかを追える。

> **降ろしてよい線**（[[reference_notion_archive_line]] と同じ考え方）
> 終わった案件 ／ 後継に置き換わった規範 ／ 一度きりで再発しない事故。
> **★配った・リンクされた・他から参照されている ものは降ろさない。**
> **★降ろす判断はAIが独断でしない。有璽氏へ一覧を出して承認を得る。**

## 降ろすときの手順

```
1  そのファイルが他のメモリから [[リンク]] されていないか grep する
2  降ろす候補の一覧を有璽氏へ出す（1行ずつ・降ろす理由つき）
3  承認が出たら、索引行を該当の INDEX_*.md か MEMORY.md から外す
4  ★同時に この表へ1行足す（日付・名前・元の索引・理由）
5  check.sh を通す（どの索引にも載っていないファイルは孤児として赤になる）
```
