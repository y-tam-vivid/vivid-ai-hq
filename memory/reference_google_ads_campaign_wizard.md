  モーダル「本人確認」→「確認」で別窓が開き、パスワード／2段階認証をする（★有璽氏の手。こちらは入力しない）。
  別窓が出ないときはアドレスバー右のポップアップブロックを ads.google.com に許可する。
- 🔴**本人確認は「7日後にもう一度お試しください」で止まった**（10/7 22:22）。理由＝アカウントに★最近電話番号が追加された（Ad Grants の準備で足したもの）＝追加から7日は保護期間。

- **保存に失敗している間、確認画面は古い値を出す**（地域は入力欄に6市町が残っているのに、確認画面は「すべての国と地域」）。

- **AI 最大化設定は既定で「テキストのカスタマイズ」「最終ページ URL の拡張」が有効。** 決めた語と文面で出すならオフにする。
- 地域の候補のボタンは「含める」ではなく **「一致」「除外」「付近」**。「一致」を押す。地域オプションの既定は「所在地やインタレスト」→「所在地」へ。
- 拡張コンバージョンは既定でチェック済み → 外す（プライバシーポリシーで説明していない使い方になる）。
- 予算の推奨額（$77.85 等）は無視して、カスタムで 329（Ad Grants の日割り上限）。

- ✅10/8 GA4（G-9LG5GYJENJ）で tel_click・line_click・contact_submit を★キーイベント化済み（有璽氏・画面で☆3つを確認）。
  ★2026年のGA4には「新しいキーイベント」ボタンが無い＝管理→データの表示→イベント→「最近のイベント」タブで☆を押す形だけ（一度発火して一覧に出ている必要あり）。
