Notion/資料のデザイン方針(2026-07-16ユーザー指示、フランキー[[project_design_agent]]初仕事のレビューで確定)。

**① 図解ファースト**: 流れ・遷移・関係・階層・比較は、**言葉の羅列でなく図式(矢印フロー・分岐・マトリクス・ツリー・ビフォーアフター)で主に見せ、言葉は補足フォロー**に回す。「イメージや言葉より図式、その上で言葉でフォローする設計が分かりやすい」。図解を増やすことが歓迎される。

**Why**: ユーザーは視覚的な図式のほうが早く正確に把握できる。言語だけの縦積みは埋もれる。

**How to apply**:
- 流れ・状態遷移は矢印フローで分岐まで見せる(例: 📥Inbox → 🔥Next → 🚀InProgress → ✅Done → 📦Archive、⏸Waiting分岐)。**この型を1行テキストに潰すのは改悪**(フランキーがアフターで潰して不評だった)。ビフォーの枠＋矢印フロー型が見やすいと明言された→継承。
- 単純な図はNotion内の枠(コールアウト)＋矢印テキストで十分。リッチな図はFigma/embed/Artifact(mermaid)で。
- 図の後に言葉で補足する二段構え。

**② 絵文字は抑制**: 過剰な絵文字は望ましくない。意味を持つ最小限(機能的な種別・信号・状態)だけに絞り、装飾目的の多用はしない。無くてよい見出しには付けない。

デザインガイドライン本体([[project_design_agent]])とテンプレ類はこの2方針に沿って改訂する。関連: [[feedback_notion_latest_version_top]]
