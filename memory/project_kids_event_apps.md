ふくち。グループの開発第二ライン(第一号は[[project-irodori-app]])。イベント(主に小学生・親子連れ)で数分で遊べる、ウェブ完結・キオスク設置(会場のタブレット/スマホに置き子どもが1人で触る)のミニAIアプリを複数展開する。中核テーマは「お金のリテラシーを高める知育」。既存の診断アプリ money-shindanapp.vercel.app(お金の才能診断・🪙カジュアル・ひらがなトーン)と世界観を揃える。統括ステラ+担当エジソン([[project-dev-agents]])。

**プロジェクト**: `~/fukuchi-kids-apps`(Next.js 16 App Router / TS / Tailwind v4 / Vercel前提)。IRODORI(`fukuchi-task`=Expo/RN)とは別ディレクトリ。
- `src/shared/` = シリーズ共通キット(4択配色・特大タップボタン・Web Audio自前効果音・canvas自前紙吹雪・ふりがなRubyText・アイドルリセット・ミュート・NaviProvider)。外部ライブラリ非依存でオフライン確実動作。
- `src/apps/<app>/` = アプリ固有。`src/app/` = ルーティング(/がシリーズホーム)。
- **量産の型**: 新アプリは src/apps/ に追加+ホーム一覧に1行、で増やせる。

**共通ルール**: 3分以内・端末内完結(個人情報を残さない)・ひらがな+ふりがな+絵文字・結果カードで持ち帰り(印刷/スクショ)・無操作で自動リセット。

**AI差し替え口**: `src/shared/navi/types.ts` の NaviProvider が境界。今はルールベース(createLineBasedProvider)。第2段階で createClaudeNaviProvider に1行差し替えでClaude API動的化できる設計。
