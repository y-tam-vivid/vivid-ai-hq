**デザイン制作物の置き場は、共有ドライブ `11-000_事業開発部門/03_デザイン制作プロジェクト/` の法人別フォルダ。**（2026-10-06 有璽氏）

```
03_デザイン制作プロジェクト/            （★10/6 有璽氏が番号を振り直した）
├─ 00_制作物一式/                    社外のお客様の制作物（様 付き）
├─ 01_ふくち。グループ/   id 1yY7z5jOo6Ok5ygOcRan5kUZFP6WcBpDO
├─ 02_株式会社ILIFE/      id 110Qm6SSE4v7pcfsj0ZVU-4QvIRAaImzq
├─ 03_株式会社ビビッド/   id 1SkNGX6hL51z__opH5GobZYEJd0Qth7xu
├─ 04_NPO法人南河内こどもステーション/
├─ 05_ラーナーズ株式会社_ジコカツ案件/
└─ 06_かわちばなし_イベントポータルサイト案件/   id 1NEM1174DBdmKc8l7UEwi8ZouUMovDI0F
```

- 対象：Webサイト制作・ロゴ・名刺・チラシ・リーフレット・年賀状・バナーなど「デザインに関連するもの」
- 移送元：デスクトップ／ダウンロード／マイドライブ／他の共有ドライブ
- **★あえて別の置き場を作って置いているもの（案件フォルダ等）は、どちらを正本にするか決め、
  もう片方にはショートカット（エイリアス）を置く。** 二重に実体を持たない
- 法人フォルダの中は `01_〇〇WEBサイト` のように番号付きの制作物ごとのフォルダ（有璽氏が作った形）

**How to apply:** デザイン制作物を新しく作った・受け取ったら、Downloads やマイドライブではなく上の法人フォルダへ置く。
関連：[[reference_backups_in_volatile_places]]（渡し物は Drive 案件フォルダ・番号を振る）

**★移すときはリネームもする（2026-10-06 有璽氏）。** 規約の正本は Notion「📛【正本】ファイル命名規約」
（3a47b1568b57818f8259c8e92ff9c107）＝ `YYYY-MM-DD【種類】対象_要点_vN.拡張子`。明示指定なので過去の手動命名も対象（モード②）。
旧名→新名のログを残す（~/.vivid-relay/design_consolidation_log_20261006.jsonl・mini）。
★ただしWebサイトの書き出し・テーマ・コードの**中身**（index.html・assets 等）は改名しない（リンクが切れる）。改名は法人フォルダ直下の制作物の単位まで。

**★名刺フォルダの罠**：「有璽名刺」「松本共有名刺」は★受け取った名刺の写真＋kintone反映CSV＝顧客情報。デザイン物ではない（10/6 一度移して戻した）。

**★番号を振り直すと、古いパスへ書くセッションが旧フォルダを作り直す（2026-10-06 実測）。**
有璽氏が「03_かわちばなし」→「06_」へ変えた後も、担当セッションが古いパスへ書き続け、空の「03_かわちばなし/05_公開と計測」が新しくでき、
新しい版の文書がそこに溜まった（06 側は古い版のまま）。→ 06 へ統合し、06 の古い版は `_旧版_時分` を付けて残した。
**How to apply:** フォルダ名を変えたら、記録（memory・WORKING.md）に残っているパスも同時に書き換える。書く側は ID かいまの名前で書く。

**「就労支援_制作事例」（マイドライブ 00_部門軸アーカイブ/13_営業/13-100_法人コンサル部）はそのまま置く（2026-10-06 有璽氏「ステイで良い」）。**
営業が見せる制作事例の束として残す。法人フォルダと同じ中身の重複8点（ILIFE年賀状・リーフレット・求人バナー）も消さない。
