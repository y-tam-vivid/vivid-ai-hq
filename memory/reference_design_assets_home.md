- 対象：Webサイト制作・ロゴ・名刺・チラシ・リーフレット・年賀状・バナーなど「デザインに関連するもの」

- 法人フォルダの中は `01_〇〇WEBサイト` のように番号付きの制作物ごとのフォルダ（有璽氏が作った形）

**How to apply:** デザイン制作物を新しく作った・受け取ったら、Downloads やマイドライブではなく上の法人フォルダへ置く。

**★移すときはリネームもする（2026-10-06 有璽氏）。** 規約の正本は Notion「📛【正本】ファイル命名規約」

★ただしWebサイトの書き出し・テーマ・コードの**中身**（index.html・assets 等）は改名しない（リンクが切れる）。改名は法人フォルダ直下の制作物の単位まで。

## ★デザイン側への依頼文は「案件フォルダ直下の `0X_デザイン側への指示文/`」へ番号順に置く（2026-10-06 有璽氏）

```
「今回格納したやつも、このデザインの修正依頼文みたいなものも、
  何かフォルダを作ってそこに格納していってください。今後も発生すると思うので。」
```

**★置き方（かわちばなしの形を全案件の標準にする）**

```
<案件フォルダ>/0X_デザイン側への指示文/
  01_YYYYMMDD_修正依頼_内容_★これを渡す.txt     ← いま渡すもの。★印は1本だけ
  02_YYYYMMDD_修正依頼_内容_旧版.txt            ← 渡し終えたら _旧版 に改名（消さない）
```

- **★連番は渡した順。** 中身でなく「いつ渡したか」で並べる。
- **★`★これを渡す` は常に1本だけ。** 新しいものを置いたら、前のを `_旧版` へ改名する
  （かわちばなしで v1・v2 を旧版にした実績。**どれを渡すか迷わせない**）。
- **★消さない。** 旧版は残す。何を依頼したかが案件の履歴になる。

**🔴 2026-10-06 実測 ── 捨ててはいないが、置き方がバラバラで二重になっていた**

```

こどもステーション ★3か所に散在。しかも★同じ指示文が2か所に（sha256 一致 2bbbf6c73859）
                 04_写真・イラスト素材/…_20260929/01_ClaudeDesignへの指示文.txt
                 2026-09-29【写真素材】…/01_ClaudeDesignへの指示文.txt  ← ★同一ファイル
チラシ系        制作物フォルダの奥（クライアントから届いた修正依頼。これは別物＝受け取ったもの）
```

★**「こちらが出す依頼文」と「先方から届いた修正依頼」は分けて置く。**混ぜると、どちらが指示か分からなくなる。
