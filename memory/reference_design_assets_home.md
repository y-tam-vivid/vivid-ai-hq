**デザイン制作物の置き場は、共有ドライブ `11-000_事業開発部門/03_デザイン制作プロジェクト/` の法人別フォルダ。**（2026-10-06 有璽氏）

```
03_デザイン制作プロジェクト/
├─ 01_制作物一式/                    社外のお客様の制作物（様 付き）
├─ 02_ラーナーズ株式会社_ジコカツ案件/
├─ 03_かわちばなし_イベントポータルサイト案件/
├─ 04_NPO法人南河内こどもステーション/
├─ 05_株式会社ILIFE/      id 110Qm6SSE4v7pcfsj0ZVU-4QvIRAaImzq   ★10/5 新設
└─ 06_ふくち。グループ/   id 1yY7z5jOo6Ok5ygOcRan5kUZFP6WcBpDO   ★10/5 新設
```

- 対象：Webサイト制作・ロゴ・名刺・チラシ・リーフレット・年賀状・バナーなど「デザインに関連するもの」
- 移送元：デスクトップ／ダウンロード／マイドライブ／他の共有ドライブ
- **★あえて別の置き場を作って置いているもの（案件フォルダ等）は、どちらを正本にするか決め、
  もう片方にはショートカット（エイリアス）を置く。** 二重に実体を持たない
- 法人フォルダの中は `01_〇〇WEBサイト` のように番号付きの制作物ごとのフォルダ（有璽氏が作った形）

**How to apply:** デザイン制作物を新しく作った・受け取ったら、Downloads やマイドライブではなく上の法人フォルダへ置く。
