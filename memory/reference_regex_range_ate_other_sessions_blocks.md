# 正規表現の範囲指定が、他セッションのブロックまで食った

**2026-10-11・WORKING.md を 15,168B → 6,770B にした（進行中10本のうち9本が消えた）。**

かわちばなしの1ブロックだけを差し替えようとして、こう書いた。

```python
m = re.search(r"- \*\*【ビビ / 10/05〜】かわちばなし\*\*.*?(?=\n- \*\*)", s, re.S)
s = s[:m.start()] + new + s[m.end():]
```

**★`- **【ビビ / 10/05〜】` は実物に無かった**（実物は `- **【ビビ / 2026-10-05〜】`）。
`re.search` は None を返すはずだが、`assert m` を書いていたのに**別のブロックに当たって**
`.*?` が次の `\n- **` まで伸び、**他セッションの行を含む8,398Bを飲み込んだ**。

```
★気づけた理由   書いた直後に os.path.getsize() を出していた（6,770B と見えた）
★戻せた理由     直前に commit していた（git show <sha>:WORKING.md で復元）
```

## やること

```
★毎ターン届くMD（WORKING.md・MEMORY.md・Current_Focus）の一部を
  「ここから次の見出しまで」の範囲指定で置換しない
  → 行を特定して Edit で1行ずつ置き換える（old_string が一意でなければ失敗してくれる）

★置換の前後でサイズと「数えられるもの」を必ず出す
  WORKING.md なら進行中の行数（grep -c "^- \*\*【"）。減っていたら事故

★大きく書き換える前に commit する（戻せる状態を先に作る）
```

★`.*?` と `(?=...)` の組み合わせは、**目印が1文字違うだけで範囲が暴走する**。
範囲で消すのではなく、**置き換える対象を一意に特定してから**触る。
