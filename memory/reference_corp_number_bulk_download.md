**法人番号の取得経路は2つある。片方は申請が要らない。**

```
経路A  Web-API          1社ずつ即時に引ける
                        ★アプリケーションIDの発行に 2週間〜1か月かかる
                        申込 https://www.invoice-kohyo.nta.go.jp/web-api/index.html#cmsprereg
                        入力は 氏名／メールアドレス のみ（3分）

経路B  全件ダウンロード  ★申請が要らない。今日から使える
                        https://www.houjin-bangou.nta.go.jp/download/
                        前月末時点の全件（CSV／XML）＋日別の差分
                        全国分・都道府県別のどちらでも落とせる
```

**2026-08-20 実測** ── 経路Bのダウンロードページはログイン無しで200を返し、
フォームのCSRFトークンも取れた。アプリケーションIDの入力欄は無い。
選択肢（`selDlFileNo`）はJSで動的に入るため、HTMLの静的解析だけでは出てこない。

## 自動化するときの形（2026-08-20 実測。まだ実装していない）

```
更新の頻度   毎月末に作り直され、翌日0時までに公開される（月末が休日なら直前の平日）
             ★いまローカルにある 2026-07-31 版が最新。次は8月末
落とし方     GET  /download/zenken/  でページを取る
               ├ CSRFトークン  name="…CNSFWTokenProcessor.request.token"
               └ doDownload(NNNNN) の NNNNN ＝ ファイル番号
             POST 同URL に event=download / selDlFileNo=NNNNN / トークン
★ファイル番号は毎月変わる（2026-07版は全国CSV-Unicodeが 27660）。
  固定値で書くと翌月から静かに別のファイルを落とす。★毎回ページから取り直すこと
見出しのid   csv-sjis / csv-unicode / xml-sjis / xml-unicode（各見出しの直後が全国分）
```

- **★「更新されている」と「使われている」は別。**取得を自動化しても、読む側が固定名なら
  永久に初回の版を見る。**心拍は緑のまま**（取得は成功しているため）。
- **★直し方はディレクトリの中で最も新しい `00_zenkoku_all_*.csv` を選ぶ形にする**（2026-09-06 時点で未実施）。
  ★同じ値を2ファイルに持っているので、片方だけ直すと食い違う → [[reference_stale_copy_of_kintone_columns]]
- **★版が違えば結果も違いうる。**照合の件数を報告するときは**どの版で数えたかを必ず書く**
  → [[feedback_never_write_an_unmeasured_number]]
- ★`ledger_report.py` の文言「全件データの月次更新はまだ自動化していない」も
  **8/27 に自動化済みで古い**（毎朝の出力に載り続けている）→ [[reference_stale_premise_daily]]

## なぜこれが要るか

「法人番号の自動取得」を経路Aだけで設計していたため、**アプリケーションIDの申請が
有璽氏の操作待ちとなり、⑤のステップが止まっていた。** 申請は1か月かかるので、
待つ設計にした時点で1か月の停止が確定していた。

**片方の経路しか見ずに「人の操作待ち」と判定していた。**
→ [[feedback_one_route_is_not_verification]] と同じ形。

## 使い分け

| | どちらを使うか |
|---|---|
| 台帳の既存行を埋める（一括） | **経路B**。月1回まとめて落として突合すれば足りる |
| 受付フォームから入った瞬間に埋める | 経路A。即時性が要る |

## ★注意

- 利用規約に**取得元の明示義務**がある。ただし**社外へ公開する画面を作る場合のみ**。
  台帳の中で使う分には関係ない
- 突合して1社に絞れたときだけ確定してよい。
  → [[reference_recover_exponential_corp_number]]（計算で復元してはいけない）
- 法人番号が違えば別法人。統合してはいけない
  → [[project_sales_workbook_read_first]]
