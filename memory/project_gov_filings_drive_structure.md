**有璽氏の依頼（2026-10-16・音声入力）**
- ILIFE・オレンジワークスを含めて、★行政へ届け出た書類は1か所に固めたい
- 一方で、各法人・施設の場所にも原本を置く形、またはその逆（どちらかを原本にし、もう一方から引く）を想定している
- 手元の `~/Documents/[IL]㈱ILIFE/[001]生活基盤推進` がその形になっている。それを Google ドライブに作りたい
- 既存の施設（オレンジワークス・STAND UP）は、過去の分も今後の分も、発生した書類を施設ごとにはっきり分けたい。届出以外の書類も含めて分け方を検討してほしい
- ★「反対もしくは反対」は音声の崩れとみて、「原本は片方、もう片方からはショートカットで引く。どちらを原本にするかは決めていない」と読んだ

**実測（10/16）**
- 手元の `[001]生活基盤推進`：1,655ファイル。年度（R3〜R8）の下に「YY.MM.DD 届出の種類(事業所)」のフォルダ。68件のうち、事業所の印は UP 13＋STAND UP 7／スタディ 10／SWELL 2／リアンライフ 1／HALE 2 ほか。研修関係・処遇改善・支援金は年度の外
  - 事業所をまたぐ届出もある（処遇改善計画書_オレンジ・ILIFE）
  - 法人が替わっても事業所は続く（オレンジワークス：SWELL → リアンライフ、スタディ → HALE へ譲渡）
- 共有ドライブ `15-000_施設運営部門/施設管理部/[001]行政申請等届出書`：335ファイル。ほぼ 26.10.01 オレンジワークス新規指定申請だけ（R5.09.01 は入れ子）。同じ所に「支払決定額通知書」「大阪府福祉施設申請完了番号」もある
- マイドライブ `00_部門軸アーカイブ/15_施設運営/15-300_LIFE STAND UP` は9件、`15-400_オレンジワークス藤井寺` は0件。共有ドライブ側に `LIFE STAND UP`、`STAND UP(本部管理用)/加算申請書類` もある
- Desktop `STAND UP 最新届出書類26.07`（2件）など、散らばっている物もある
- ★共有ドライブでは `_機微` で権限を狭められない（[[reference_shared_drive_permission_floor]]）

**How to apply:** 着手前にここと [[reference_drive_placement_rules]]・Core_Brain `18_ファイルの置き場と名前` を読む。`00_部門軸アーカイブ` はドライブ整理担当（かわちばなし session）の持ち場なので、作る前に相談する。

## 2026-10-16 17:00 有璽氏の2回目（設計の前提が変わった）
- 自社の流れ（届出の原本は1か所・施設からはショートカット）は了解。法人単位（処遇改善など）、旧SWELL・旧いきいき・タチバナの置き場があるのも了解
- ★届出は同じ時期に似た書類を複数の施設で出すので、★全施設を時系列で見られる方がよい → 案だった「事業所→年度」はやめ、★年度→「YY.MM.DD 種別(事業所)」（手元の形）にする。ボタン `#ef6bd9` は閉じた
- STAND UP の現場用の分け方（国保連・運営・職員・広報・設備）は「一旦これで問題ない」
- ★別に社内で、行政の★運営指導に向けて必要な書類を分類・番号付きで格納し、★行政が来たらすぐ出せる形を検討している。フォルダはその設計に合わせる（変わりうる）
- ★「運営指導で求められる・行政手続きで必要なもの」と「現場で使うもの」は分ける。両方に要るものはショートカットで示す
- 土台の候補：Drive『実地指導監査』の「関係書類一覧_児童福祉サービス事業者 運営指導(自己点検表)」（110項目・26区分）。社内の検討＝8/23 吉川さんとの「実地指導対策システム」（児童と就労B型から）。オレンジワークス（就労B型）は別の表が要る
- 3層案：①届出の時系列（原本）②施設ごとの運営指導の綴り（番号付き。届出はショートカット）③現場用。番号の土台はボタン `#a88b65` で確認中。①の作る場所は `#e52129`、原本の向きは `#98203f` で確認中
