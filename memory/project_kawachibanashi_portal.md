## ★写真のトーンが本体と合っていない（2026-09-08 実測）

**有璽氏「今入っている写真も最適なものでないと理解している」。実測すると原因は1つに絞れた。**

サイト本体が約束しているトーンと、写真のトーンが**逆**。3経路で一致した。

| 見た場所 | 出ている色・雰囲気 |
|---|---|
| ロゴ（uploads/C87337A4…png） | 水彩イラスト・青空・新緑・ぶどう紫・菜の花黄・桜ピンク・虹の縁＝**ハイキー** |
| CSSの配色（v4.dc.html） | `#FBF3DC` クリーム／`#FFFFFF`／丸ゴシック Kiwi Maru／破線の丸・波線＝**やわらかい** |
| 参考サイト まつもトコトコ | 順光・高彩度・主題ドアップ（トマト・松本城・おやき）＝**明るいカタログ写真** |
| ★いまの写真5枚 | 逆光・低彩度・黒/茶に沈む・引きの構図＝**大人のフォトエッセイ** |

**＝「良い写真か」ではなく「役割が違う」。** いまの5枚は *読ませる写真*。必要なのは *探させる写真*。

### ★有璽氏の言葉は「暗い」でなく「**異なっている**」（2026-09-08・本人が承認）

> 「素材写真の**明るさとかが異なっている**ように思います」

**★私は「暗い」と診断したが、本人の見え方は「揃っていない」だった。こちらが本質。**
「暗い」だと1枚ずつ明るくして終わる。「揃っていない」なら**基準値を1つ決めて全枠を合わせる**
話になり、対処がまったく違う。→ [[feedback_uniform_unless_reason]] と同型（明るさ版）。

**実測（平均輝度0-100／彩度0-100／明るさ25未満の画素の割合）**

```

いちじく                35.4   38.3   47.4%   ← 5枚で最も明るい
イベント特集(夜の縁日)    33.7   47.9   53.8%
hero 川辺マルシェ        24.1   46.2   65.4%

     かわちばなし ロゴ     81.8   24.6    0.5%
```

**問題は2つ重なっている。**
① 写真の平均 **24.6** に対し**地色は 95**。落差70＝**写真の場所だけ穴が開いて見える**
② **5枚どうしも揃っていない**（10.9 と 35.4 が同じ画面に並ぶ）

**★目標値（これが選定・生成の合否線）**

```

暗部    15% 未満      ★これを超えたら順光で撮り直し／生成し直し
```
**目視で決めない。ただし数値だけでも決めない（下記）。**

### ★補正では直らない ── 数値は合格したが目視で不合格（2026-09-08 実測）

明るさ65・彩度40へ寄せる補正（ガンマ＋彩度復元）を5枚に当てた結果：

```
数値   L65 / S40 / 暗部0〜4%     ★5枚とも合格
目視   暗部から緑と青のノイズが浮く／古墳は全体が青緑に転ぶ／
       夜の縁日は「夜のまま明るい」で不自然   ★4枚が不合格
例外   いちじく のみ破綻しない（元が L35.4 と最も明るかった）
必要だった補正量  γ0.15〜0.30・彩度×2.5〜3.3 ＝ ★無理な持ち上げ
```

**★元の写真に光の情報が無ければ、後処理では作れない。**
**★そして「合否線を数値で置く」だけでは足りない。数値の合格は目視の合格を意味しない。**
判定は必ず **数値 → 目視** の2経路。→ [[feedback_one_route_is_not_verification]]

## 差し替えと確認の道具（2026-09-08 新設）

```
bin/swap_image_slots.py   .dc.html の image-slot の src を手元の画像へ差し替える（既定dry-run）
bin/contact_sheet.py      画像を1枚に並べる。★揃いは並べたときにしか見えない＝目視の2経路目
```

  2026-09-08 は有璽氏に一度閉じてもらってから実行した。
- **★中途半端に差し込まない。** 8/18 の時点で入れると、残りを入れるためにもう一度
  閉じてもらうことになる（人の手が2回）。**そろってから1回で入れる。**

## ★差し替え後を見せる方法（2026-09-08 確立）

**`.dc.html` は Claude Design 専用タグ（x-dc / sc-for / image-slot / style-hover）で、
そのままではブラウザで開けない。** 有璽氏へ渡すには静的化して Artifact にする。

```
① node で値を取り出す   末尾の <script type="text/x-dc"> を eval して renderVals() を JSON へ
                        ★React.createElement は SVG文字列を返すスタブに差し替える
② Python で展開         sc-for を回し {{ }} を置換／image-slot を <img data-uri> へ／
                        style-hover を捨てる／helmet を head へ
③ Artifact で公開       ★画像は data URI。幅900・JPEG78 まで縮小して 2.32MB に収めた
道具                    scratchpad/{extract_vals.js, render_dc.py}
実測                    独自タグ0・未解決の {{ }} 0・画像17枠埋め込み・未設定1（insta-6）
```

**公開先（積む・作り替えない）** → https://claude.ai/code/artifact/8423f99c-6ba2-4292-b6aa-6cfab19b2952

## 2026-09-09 ロゴを主役にする改修（案D＝hero＋全体の部品）

有璽氏「**せっかくロゴマーク素敵なのに、そのロゴマークをうまく活かせてない**。
もうちょっとロゴマークを前面に出しながら、こちらの意図、思いを伝えられるようなものにしたい」。

**★真因：サイトの言葉は全部ロゴから取られているのに、そのロゴを潰していた。**

