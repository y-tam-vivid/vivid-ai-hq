**2026-10-14 有璽氏**
「マイドライブの直下にあるかわちばなし関連は、**かわちばなしの共有ドライブ側に全て移動させるもの**」
「ものによってはリネームが必要。かわちばなしは不要やと思うけど、**それ以外はリネームすべきものも多い**」

```
正本      案件の成果物・指示文・素材 ＝ 共有ドライブの案件フォルダ
置かない  マイドライブ直下（個人の作業場。案件のものは置きっぱなしにしない）
残すもの  個人のもの／仕組みが読み書きしているもの／Googleが勝手に作るもの
```

```

   移すときに名前も整える前提で、規約が決まるまでは★元の名前を残したまま移す

## ★固有名詞で部門を決めてはいけない（2026-10-14・試して分かった）

同じ ILIFE 宛でも、契約書は法務・請求書は経理・支援記録は施設運営。

  段2（Haiku） 書類の性格（契約書／請求書／議事録…）から部門を決める。手がかりとして固有名詞を渡す

              ★無理に当てなくなった＝正しい動き（迷いは人へ返す）

## 仕分けの道具で踏んだ実装の誤り（2026-10-14・全部その場で直した）

                                   説明を足したら 24件→要判断6件 に減った
```

**★「要判断」が多いときは、人が迷っているのではなく★選択肢の説明が足りない。**

```

   ★直すのは営業 → 13_営業

   ★直すのは申請実務をする人 → 14_管理（労務系助成金は 14-100_労務部／
     設備・経費系は 14-200_経理部）。★特定の労働局・自治体名が付いているものはこちら
```

- **★見分け方は1つ：「次に中身を書き換えるのは誰か」。**
  制度の案内は誰も書き換えない→追う人の所。申請書は申請者が書く→申請実務の所。
- ★迷う典型 ──「厚労省の助成金案内」は①／「業務改善助成金 実績報告の必要書類一覧

  **出どころが公的機関でも、自社の申請に紐づいていれば③。**
