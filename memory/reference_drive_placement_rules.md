# ドライブの置き場 ── 案件のものはマイドライブに置かない

**2026-10-14 有璽氏**
「マイドライブの直下にあるかわちばなし関連は、**かわちばなしの共有ドライブ側に全て移動させるもの**」
「ものによってはリネームが必要。かわちばなしは不要やと思うけど、**それ以外はリネームすべきものも多い**」

```
正本      案件の成果物・指示文・素材 ＝ 共有ドライブの案件フォルダ
置かない  マイドライブ直下（個人の作業場。案件のものは置きっぱなしにしない）
残すもの  個人のもの／仕組みが読み書きしているもの／Googleが勝手に作るもの
```

## やること

```
★案件のファイルを作ったら、その場で共有ドライブの案件フォルダへ置く（後で移すと忘れる）
★AIが人に渡すために作った中間物も同じ。マイドライブ直下に落とさない
★「全部移す」と言われても、★稼働中の仕組みが読み書きしているものは別に数えて確認する
   （Googleフォームと回答先のスプレッドシートは、共有ドライブへ移すと繋がりが切れることがある）
★リネームの規約は未定（2026-10-14 時点）。有璽氏が「それ以外は多い」と言っている＝
   移すときに名前も整える前提で、規約が決まるまでは★元の名前を残したまま移す
```

### ★数え方の誤りを2つ踏んだ（同じターン内）

```
①「マイドライブ直下168件」と報告した
   → API検索のページを足した数。ページ間で重複があり、実数と違った。
   ★ローカル実測（マウント）では、移動後135件。★件数はマウント越しに数える方が確実
② ls | grep 'かわちばなし' が0件になった
   → ★macOSのファイル名はNFD（濁点が分解）。「ば」が「は＋濁点」で、NFCの検索語と一致しない
   ★ファイル名を数えるときは python で unicodedata.normalize('NFC', …) を通す
     （grep で部分一致させるなら、濁点を含まない部分＝「かわち」で引く）
```

## ★AIが消せないものは「1か所にまとめてから」渡す（2026-10-14 有璽氏）

捨てる候補を**一覧で**出したら、有璽氏から
**「これはどこに格納されていますか？ バラバラでしたっけ？ 今まとめてくれてたりしますか？」**

```
こちらが渡したもの   「捨てる候補 約20件」の一覧（名前と理由）
実際の置き場         マイドライブ直下にバラバラ ＝ ★20回さがして20回選ぶ作業が人に残る
正しい渡し方         ★1つのフォルダへまとめてから渡す（人はフォルダごと1回で捨てられる）
```

**★「押す場所まで特定する」は、場所を書くことではない。押す回数を1回にすることまで。**

```
★AIが実行できない操作（この端末ではDriveの削除）は、
   人の手数が最小になる形（1フォルダ・1操作）を作ってから渡す
★まとめるフォルダには「なぜ捨ててよいか」を書いた紙を1枚入れる（後で見て判断できる）
★迷うものは入れない。入れると、フォルダごと捨てられたときに事故になる
   → 確信のあるものだけ `_捨てる候補_` へ。迷うものは別フォルダか、その場に残す
```

関連 [[feedback_verify_before_declining]]（押す場所まで特定してから渡す）
