**★動いているのに間違っている、という壊れ方をする。** 例外も警告も出ない。
だから心拍は緑、構文チェックも通り、誰も気づかない。**気づくのは実物を描いたときだけ。**

## 実測で踏んだもの（2件・別の案件・同じ形）

```
2026-09-12  かわちばなし   when === '今月' → s.getFullYear()===2026 && s.getMonth()===8
            ★2026年10月になった瞬間、「今月」は9月を指したまま
            ★既定の絞り込みが「今月」なので、トップから来た人は空の一覧を見る

2026-09-06  営業台帳       corp_lookup.py:30  ZENKEN = '…/00_zenkoku_all_20260731.csv'
            ★月次更新は動いていて 08-31版（+11,236行）も落ちている。読む側が固定名
            ★取得は成功しているので心拍は緑。「更新されている」と「使われている」は別
            ★同じ値が corp_number_fill.py:41 にもある＝片方だけ直すと食い違う
            ★2026-09-13 現在まだ未修正
```

**★「増える」方向の同じ型は [[feedback_categories_always_grow]] に既にある**
（区分を固定値で書かず taxonomy で持つ）。こちらは**「過ぎる」方向**。

## 腐る値の見分け方 ── 「1か月後も同じ値か」を1回だけ自問する

| 腐る | 書き方 |
|---|---|
| 年・月・日・期（今月／来月／今年度） | ★`new Date()` から導く。絶対値を書かない |
| データファイル名・版番号・ファイル番号 | ★ディレクトリを見て**最新を選ぶ**（glob→sort→末尾） |
| 区分・選択肢・市町村 | ★マスタを1つ置いて全部そこを見る → [[feedback_categories_always_grow]] |
| 件数・閾値を文章に書いた数字 | → [[feedback_never_write_an_unmeasured_number]] |

## How to apply

- **★「いま」を含む語（今月・今週・今年度・最新）を実装するときは、必ず時計から導く。**
  固定値を書いていいのは「2026年9月に開催したイベント」のような**過去の事実**だけ。
- **★同じ値を2箇所に持たない。** 片方だけ直すと食い違い、どちらが正か分からなくなる
  （corp_lookup と corp_number_fill で実際に起きた）。
- **★見つけ方は静的な読みではなく実物。** 2件とも**描画・実行して件数が合わないのを
  追いかけて**初めて出た。コードを眺めても出ない。
  ```
  日付が絡む   ★時計を進めて1回描く（来月の日付で判定関数を呼ぶ）
  データが絡む ★入力を最新版に差し替えて、件数が変わるか見る
  ```
- **★心拍・構文チェック・「0件でした」を根拠にしない。** どれもこの型を素通りする
  → [[feedback_one_route_is_not_verification]]。
- 定期処理に載せるなら、**遡れるか・最新を選べるかを載せる前に決める**
  → [[reference_overwriting_containers_have_no_past]]。
