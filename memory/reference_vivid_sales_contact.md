
**資料側が古い疑いがある**が、確認していないので断定しない。**119番の資料を触る機会があれば併せて確かめる。**

## 「119番」は誤記ではない

`福祉施設の119番` はサービスブランド名。**110番ではない。** タグラインは
「その困りごと、すぐ駆けつけます。」 → [[feedback_dont_call_it_a_typo]]

**★新しい商材の営業文面を作るときは、まず既存サービス（119番）の署名・受け口を見る。**
入口をサービスごとにバラバラに作ると、反応がどこに落ちたか追えなくなる。
→ [[project_gamebull_form_sales]]

- **ロゴは PDF から透過PNGで書き出す**（`get_pixmap(dpi=300, alpha=True)` → アルファでトリム）。
  JPGは白／赤の背景矩形が付いているので、色の付いた面に置くと四角く浮く
- **ロゴの色を CSS の filter で変えない。** 白地用・赤地用が最初から用意されている
- タグライン込みのロゴは小さく置くと潰れる。**Webヘッダなら高さ38px以上**（実測して決めた）
