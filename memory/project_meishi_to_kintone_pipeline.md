松本共有名刺の定型作業（2026-07-10に初回完遂）。名刺画像OCRデータをkintone顧客フォーマットへ起こし、WEB調査で企業属性を厚く補完する。

**入力**（Google Drive: `.../Downloads書類アーカイブ/02_デザイン・制作/松本共有名刺/`）
- `名刺情報/名刺_全画像raw.csv`（表裏・JP/EN別の生OCRデータ。二次加工の`名刺一覧.csv`より高解像度=これを主軸にする）
- `松本取得名刺情報/` 名刺JPEG群（ファイル名UUID=rawの「ファイル名」列と対応。名寄せ確認用）
- `[松本]顧客情報kintone反映csv.xlsx`（雛形。シート: README運用手順/マスター62列/追記_YYYYMMDD雛形61列）

**手順**
1. rawを1顧客1レコードへ統合（表面JP主・裏EN補完、会社名の英語併記分離、住所から郵便番号分離）
2. kintone61列へ機械転記→運用手順どおり`追記_YYYYMMDD`シートを雛形複製で作成＋マスター追記(kintone反映=未)
3. 会社ユニークを10社刻みバッチでgeneral-purpose並列WEB調査。主力=**GBizINFO(info.gbiz.go.jp)を法人番号で引く**＋国税庁法人番号(houjin-bangou)＋インボイス(invoice-kohyo, T+13桁)＋各社HP。まず10社パイロットで精度検証してから全展開
4. 顧客名を**NFKC正規化＋㈱→株式会社**で名寄せしマージ（全角/㈱の表記ゆれ注意）
5. openpyxlで書き出し。カナ3列(自動確定不可)とWEB確度low/midは黄色fill＋コメント。元ファイルは上書きせず別名でDrive反映

**要点/学び**
- 資本金・従業員数・設立・法人番号は**名刺に載らない=WEB(特にGBizINFO)必須**。GBiz＋ネットで資本金68%/従業員58%/設立77%/法人番号97%取れたので**登記簿の全社取得は不要**。不足社のみ登記簿フォロー候補CSVを出す（法人番号あり=取得可）
- 登記事項証明書の有料取得(登記情報提供サービス)は決済/ログイン伴い**Claudeは自動実行不可**。候補リスト提示→ユーザー取得→反映の分担
- カナ(漢字→読み)は自動確定せず空欄+黄色で人手回し
- 自社取引担当者は案件ごとに指定される（松本共有名刺の回=**松本秋紀**で統一。既定で田村有璽にしない）
- 正本は[[reference_kintone_customer_master]]のkintone（結合キー=法人番号）
