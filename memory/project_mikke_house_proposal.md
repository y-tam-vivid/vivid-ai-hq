# 11/18 定例（鈴木・吉川・有璽氏）で動いたこと

- ★**11/21(土)13:00 訪問**（吉川さん・有璽氏）。目的は金額と12月以降の形を決めること。決まらなければ撤退（3人の意見が一致）。

- ★11/20 有璽氏の決定（1枚資料）：**月20万＝業務委託のみ／40万＝中に入る（士業の独占業務以外は全部やる）／50万＝人員配置にも入り深く関わる**。人員配置の危険や注記は資料に書かない（資料は提案として残すもの）。軸は「福祉の守り（ルールどおり）と攻め（オーナーと協業して報酬を最大に）」。医療連携など個別の加算名は伏せる。
