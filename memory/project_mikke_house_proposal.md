# 11/18 定例（鈴木・吉川・有璽氏）で動いたこと

- ★**11/21(土)13:00 訪問**（吉川さん・有璽氏）。目的は金額と12月以降の形を決めること。決まらなければ撤退（3人の意見が一致）。
- ★プラン表：吉川さんは「選択肢は2つまで。やる／やらないでなく、どれにするかで聞く」。ライト＝業務委託15万／ハード＝中に入る・管理者相当30万（有璽氏は25〜30万）。部分的な業務だけなら今の10万でよい。
- ★人員配置の危険：吉川さんの指摘は、やっていない研修などを「やった」と報告したときの責任の所在。行政処分の対象になりにくいのは業務委託（人員配置に入らないため）。人員配置は新法人を前提にして、今すぐ入るとは言わない（有璽氏）。
- ★11/20 有璽氏の決定（1枚資料）：**月20万＝業務委託のみ／40万＝中に入る（士業の独占業務以外は全部やる）／50万＝人員配置にも入り深く関わる**。人員配置の危険や注記は資料に書かない（資料は提案として残すもの）。軸は「福祉の守り（ルールどおり）と攻め（オーナーと協業して報酬を最大に）」。医療連携など個別の加算名は伏せる。
- ★11/20 2回目：20万も「外で手を動かす」（必要書類の作成・請求業務・助言）。差は「中でないとできない業務」と新藤さんが面倒がる対応＝40万から。50万は「人員配置」と書かず「直接／代わりに」の表現に留め、人員配置は口頭で伝える。人員配置の内容を見せること自体はOK（センゴクの事前確認は求めなかった）。
- ✅11/20 有璽氏OK「それで良いです」：`scratchpad/mikke_proposal_20261113/deck/MIKKE_HOUSE_ご提案_1枚.{html,pdf}`（A4横1枚・20/40/50万・税別）。11/21 訪問で使う。
