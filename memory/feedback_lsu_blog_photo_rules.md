# STAND UP 活動ブログの写真ルール（恒久・2026-11-18 有璽氏）

**対象は STAND UP（i-life-fukushi.com の活動ブログ）だけ。** 他の施設・サイトへ広げない。

## 顔の扱い

| 人 | 扱い |
|---|---|
| 子ども（利用児） | ★黄色い笑顔スタンプ（既存ブログと同じ見た目）。モザイクにしない |
| スタッフ（大人） | ★顔出し。隠さない |
| 一般の方（店員・他のお客さん・施設の係） | ★モザイク |
| 外部の講師・受入先の担当者 | 有璽氏の判断で顔出しにした例あり（陶芸講師・クラフトパークの男性）。★迷ったら聞く |
| 判別しきれない人 | ★スタンプ（隠す側に倒す）→ 有璽氏が見て「この人はスタッフ」と言えば外す |

- ★最初の指示が「モザイク」でも、既存記事がスタンプなら★揃える方を先に確かめる（11/18 一度モザイクで作り直した）。
- ★顔検出は漏れる（横顔・マスク・眼鏡・手で覆う）＝★全枚を目で見る。ポスターの絵・作品の模様に誤検出も出る。
- ★子どもを大人と見誤った例：青い服の女の子、ピンクの服・マスクの人、白いピン帽子の人（11/18 有璽氏が指摘）。
- ★差し替えたら、旧画像はメディアから消す（顔の出た画像がURLで残る）。

## 並べ方（WordPress のギャラリー）

| 枚数 | 並び |
|---|---|
| 4枚 | ★2枚×2段（columns 2） |
| 2枚 | ★横並び2枚（縦1列にしない） |
| スマホ | テーマの設定で1枚ずつ縦＝そのままでよい（有璽氏） |

## 見出しと本文

- 見出しは左寄せ。小見出し（GAME TIME 等）は20px。本文は中央寄せ（既存記事に合わせる）。

## 道具と置き場

- `~/lifestandup-wp/blog-review/`：stamp_faces.py（顔の処理）・face_roles.json（誰を出す/隠す）・wp/post_drafts.py（下書き投入）・wp/apply_layout_rule.py（並びを全記事へ・--dry で数えるだけ）
- ★XサーバーはREST APIを国外IPから止めている＝投入の間だけ有璽氏が「国外IPアクセス制限」のREST APIをOFF→終わったらON。
- ★/wp/v2/users はセキュリティプラグインが403にする。ログイン確認は posts?status=draft で行う。
