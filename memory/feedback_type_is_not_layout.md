**「型を使い分けろ」と指示しても、構図は変わらない。**

## 何が起きたか（2026-08-20〜21）

投稿画像が単調にならないよう、当方は「正本の型を使い分けろ／同じ型を連続させるな」と指示した。
Manus は忠実に実行し、型の割当表まで作った。**それでも有璽氏から同じ指摘が2回出た。**

> 金曜「イラスト群はおおむね問題ない。1点、**レイアウトが構図、レイアウトが似通ってしまっている**ので、
>       もう少し**動きを持ったデザイン**を検討してください」
> 水曜「**レイアウトが構図、レイアウトが同じパターン**になってしまっているので、
>       **文字の配置や動きなど**、もう少しバリエーションのあるものにしてほしい」

## なぜ型を分けても同じに見えたか

**枚の役割が固定されていたから。**

```
1枚目  表紙（止める）
2枚目  活用イメージ（理解させる）
3枚目  期待値（成果を示す）
```

この3枚構成は正本で固定されている。**型が変えていたのは「中の図解の題材」だけ**で、
見出しの位置・文字量・余白の取り方・要素の大小・視線の流れは全部同じだった。
だから並べると同じ絵に見える。

```
型（A/B/C/D）        何を描くか        ← 変わっていた
レイアウト・構図      どう置くか        ← ★変わっていなかった
```

## どう指示すべきだったか

型の使い分けを頼むときは、**構図の変化も別項目として明示する**。

**構図を変える具体的なレバー**
- **文字の配置**：中央 / 左寄せ / 右寄せ / 上下に振る / 縦組みを混ぜる
- **主役の位置**：中央 / 対角 / 片側に寄せて余白を大きく取る
- **要素の大小の緩急**：1点を極端に大きく / 均等に並べる
- **余白の量**：詰める回とゆったりさせる回を作る
- **視線の流れ**：Z型 / F型 / 円環 / 上から下へ落とす
- **枚の役割自体を変える**（正本が許すなら）：3枚目をCTAでなく問いで終える等

**★「単調だ」と言われたら、型の数を増やすのではなく、構図のレバーを増やす。**
型を10個作っても、置き方が同じなら10個とも同じに見える。

## 検算のしかた

**★1枚ずつ見ない。全部を並べて縮小して見る。**
1枚ずつ見ていると「それぞれ違う」と感じるが、並べた瞬間に同じさが分かる。
Manus に出させるときも「**全点を並べたコンタクトシート**」を必ず付けさせる。
