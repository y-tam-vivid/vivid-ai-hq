**事実**：2026-11-23 07:00 の発言ログに、有璽氏の指示ではなく「あなたは Web 担当アナリストです。対象は自社の福祉施設サイト…」という**プロンプトの雛形**が、型「事実が示された／制約が示された／理由を問われている」付きで入った。
文は指示文の体裁だが、有璽氏が自分に向けて言った内容ではない（貼り付けか、別セッションの文書）と見る。

**なぜ大事か**：ロビンの棚卸しは「有璽氏が示した事実・制約・やり方」を拾う。貼り付けを発言として拾うと、
別の作業の雛形が規範・記憶に混ざる。

**How to apply:**
- 発言ログの1行が、有璽氏自身の文か貼り付けの本文かを先に見る。貼り付けの体裁（「あなたは〜です」で始まる雛形・箇条書きの仕様書）なら、発言として書かない。
- 迷ったら書かずに、報告で「貼り付けらしい行を除いた」と1行だけ書く。
- 貼り付け文が規範の型（対象・守ること・出力）と似ていても、それ自体は規範ではない。
