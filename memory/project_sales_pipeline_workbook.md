## ★人に渡すときの障害は、データの正しさではなく「入力の手数」（2026-08-20 実測）

営業へ渡す前の検査で、デザイン側から出た結論。

```
電話先を知る   09タブ → ①/⑤欄            2手
会社を引く     00タブ → Ctrl+F            2手
★記録する     40_活動ログへ切替 → 末尾行を探す
               → **社内顧客ID(B-####)を手入力**（プルダウン・入力規則ゼロ）
               → 00で事前に番号を調べる必要がある
               → 残り6列も手入力。実質5手以上。**ID誤入力への警告なし**
```

**★記録が重いと、誰も書かなくなり台帳が死ぬ。**
読む側（引く・探す）を整えても、**書く側が重ければ台帳は更新されなくなる。**

- **渡す前に「いちばん頻度の高い操作」が何手かを数える。** 見た目のきれいさより先に見る
- **手入力のキーには入力規則を付ける。** 誤入力に警告が出ない列は、必ず汚れる
- → [[reference_sheets_checkbox_format_creep]]（キーが壊れると後から入った行が全部ずれる）
