# 請求書を起こすときに毎回いるもの（2026-08-28 ナミ）

## 適格請求書の必須記載事項6つ

```
① 発行事業者の名称 ＋ ★登録番号（Tから始まる13桁）
② 取引年月日
③ 取引内容（軽減税率対象があればその旨）
④ 税率ごとに区分した対価の額 ＋ 適用税率
⑤ 税率ごとに区分した消費税額等
⑥ 交付を受ける事業者の名称
```

**★①以外は契約書の値から確定できる。毎回止まるのは①だけ。**

## ★当社で毎回詰まる4点

- **登録番号**：株式会社ビビッド＝**T5120101065033**（2026-11-04 発行済み請求書 INV-2608000039 で実物確認・1経路）。
  控えの置き場 `~/Documents/[all]全社共通/[all]03会計・経理関連/[002]請求支払い関連/請求書・見積書_自社発行/`
- **★消費税の端数処理は「税率ごとに1回」まで。** 行ごとに計算して端数処理してから
  合算すると制度違反になり得る。**税抜の小計に対して1回だけ**計算する。
  基本料金と追加工数のように行が複数あっても、同じ10%区分なら合算してから1回。
- **★対象月は必ず書く。** 月額固定・日割精算なしの契約では、対象月が無いと
  「どの月の分か」が請求書だけで追えない。
- **★振込手数料が先方負担なら、請求書にも1行書く。** インボイスの必須項目ではないが、
  **手数料分の入金不足という実害**が出る。

## 請求書番号の採番規則

**実物の形は `INV-YYMM＋連番`**（例 INV-2608000039・INV-2609000040。2026-11-04 控えフォルダで確認）。
旧案の `WAKOKU-MIKKE-202610` は使わない。

## ★前払契約では、発行日と対象月がずれる

```
前払   発行日は 対象月の前月     ★ここが逆になりやすい
       支払期日＝当該月の前月末日（休業日なら前営業日）
初回   効力発生日から5営業日以内 かつ 有効期間の初日の前日まで（早い方が締切）
```

**★契約書に出てくる日付を混同しない。** 「基準日」（点検対象の範囲を区切る線）と
「対象月」（何月分の委託料か）は**別物**。→ [[project_facility_inspection_contract]]
