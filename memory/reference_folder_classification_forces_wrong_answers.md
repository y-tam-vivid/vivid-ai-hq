**分類は「空欄を許せる場所」に置く。フォルダは1つしか選べないので、判断の置き場に向かない。**

2026-08-15実測（議事録のDrive振り分け）。

```
Drive     必ず10フォルダのどれかに入る      分類率 100%  ← 誰も使っていなかった
Notion    部門・プロジェクトは空のまま       分類率 0%   ← 多軸で持てるのに空
```

AIの選定理由に原因が出ていた ――「話者不明のため福祉施設コンサル部門を選定」。
**分からなくても選ばざるを得ないので、特定の1つへ集中する**（実測36%）。
[[reference_ai_output_blamed_before_inputs]] の「不明なら◯◯」と同じ型が、
フォルダ構造という形で埋まっていた。

**判断の置き場を選ぶときの問い**

```
その項目は「分からない」と言えるか？
  言えない（フォルダ・必須select）  → そこへ判断を置かない。機械的な規則だけを置く
  言える（relation・テキスト・空欄可） → ここへ判断を置く。後から人が埋められる
```

**「分類しているつもり」を疑う手順** ―― 分類先の分布を数える。1つに3割以上寄っていたら、
それは分類ではなく既定値。あわせて**その分類を誰がどう使っているかを聞く**
（今回は「フォルダを開いて探すことはほぼ無い／検索とNotionリンクとカレンダー添付」だった）。

**決着（2026-08-15 有璽氏承認）**: Driveは `2026/2026-08/` の年月平置き＝判断させない。
部門はNotionが持つ。既存の部門別10フォルダは**動かさず凍結**（旧側は書き込みが止まるので
二重管理にならない）。マスターのIDはGASに埋めず、バッチが毎回読み直す。
