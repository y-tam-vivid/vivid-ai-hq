**共有ドライブ内のGoogleフォームは「ファイルのアップロード」質問タイプが使えない。** 編集画面で選択肢がグレーアウトする。エラーは出ないので原因が分かりにくい。Google側の仕様で、設定や権限では解除できない。

判定方法：Drive APIでフォームの親フォルダを辿り、ルートのIDが `0A` で始まれば共有ドライブ（マイドライブなら `root`）。

対処：**フォーム本体だけをマイドライブへ移す**（Drive で右クリック → 整理 → 移動）。回答先スプレッドシートは共有ドライブに残したままでよい ── 連携はファイルIDで保たれる。

移したあとの副作用：
- アップロードされたファイルはフォーム所有者の**個人ドライブ容量**を消費する
- ファイルの所有者も個人になるため、回答シートを見る他メンバーは添付リンクを開けないことがある
- **アップロード項目のあるフォームを後から共有ドライブへ戻すと、回答の受付自体が壊れる**。戻さない

GAS側の注意：`Form` クラスに `addFileUploadItem()` は**存在しない**（2026-08-08に公式リファレンスで確認）。アップロード項目だけは編集画面から手で追加するしかない。スクリプトで作る他の項目より先に手で足しておくと、回答シートの列がずれる回数を1回に抑えられる。

他にグレーアウトする原因：組織のDLP設定、1フォームに10個以上のアップロード項目、ブラウザのセッション不整合。
