# 「一旦」「確認中だが」の承認は、恒久の承認ではない（2026-10-13 有璽氏）

有璽氏の回答（JFBI 協力団体・南河内こどもステーション）

```
①紹介文と肩書き行   「★確認中だが問題なし」   → 団体の確認結果はまだ来ていない
②こちらで起こしたロゴ「★一旦こちらで公開で良し」→ 団体の正式なロゴが出たら差し替える前提
③写真               「現状で問題ない」          → これは条件が付いていない＝確定
```

**★①②は「出してよい」であって「これで決まり」ではない。**
出す判断だけを受け取って、**差し替える条件を落とすと、暫定が恒久になる。**

## やること

- **承認を記録するときは、3つを必ず一緒に書く。**
  ```
  いま出してよいか   ／ ★何が来たら変わるか ／ ★そのとき誰が動くか
  ```
- **条件が付いた承認は、進行中の欄（WORKING.md）から消さない。**
  「✅出した」で閉じると、差し替える機会が来たときに誰も気づかない。
  ✅と▶を1行に併記する（例：✅公開した ／ ▶正式なロゴが届いたら差し替える）。
- **条件なしの承認（「現状で問題ない」）とは、書き分ける。** 混ぜると後から見分けられない。
- ★有璽氏は条件を1語で示す（「一旦」「確認中だが」「当面」「いまは」）。**この語を落として要約しない。**
