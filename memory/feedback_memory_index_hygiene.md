**`memory/MEMORY.md` には読み込み上限（約24.4KB）がある。超えた分は黙って落ちる。**
2026-08-21 実測 ── **61,671バイト・132行**まで肥大し、システムから
「Only part of it was loaded」の警告が出ていた。**索引が全部は届いていない状態が続いていた。**

**Why:** 索引行は追記で育つ。1件の学びを足すたびに既存行へ「／★…」を継ぎ足していくと、
1行が1,000バイトを超える。**索引は「どこに何があるか」を運ぶもので、内容を運ぶものではない。**
索引が届かなくなると、**そのメモリは存在しないのと同じ**になる（本文がどれだけ充実していても、
索引に載っていなければ誰も引きに行かない）。届く経路が壊れる＝いちばん高くつく壊れ方。

**How to apply:**

```
1行の上限     180バイト（日本語で約55字＋リンク部）。全体で 24.4KB を超えない
              ★130行なら1行あたり平均188バイトしか使えない。行を増やすほど各行は短くなる
書き方        - [名前](file.md) — 現在地を1文
              「Xプロジェクト — 概要」ではなく「Xプロジェクト — いまYの状態。Zは未実装」
足すとき      既存行へ継ぎ足さない。詳細は**そのファイルの本文**へ書き、索引は現在地だけ差し替える
重複          同じファイルを指す索引行を2本作らない（2026-08-21 時点で3組の重複を統合した）
数え方        `wc -c ~/vivid-ai-hq/memory/MEMORY.md` で見る。20KBを超えたら棚卸しの合図
```

- **削るときは必ず全文を残す。** 2026-08-21 の棚卸しでは、圧縮前の132行を
  `memory/_archive/MEMORY_full_20260821.md` へ保存してから置き換えた（git管理下）。
  **索引にしか書かれていなかった記述は、順次それぞれのファイル本文へ戻す。**
- 実体は1つ。`~/.claude/projects/-Users-yujimac/memory` は `~/vivid-ai-hq/memory` への symlink
  （2026-08-21 実測）。**索引が2か所にあるように見えても二重管理ではない。**
