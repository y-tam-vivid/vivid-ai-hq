**★実行したことを「済んだ」の印にしない。成功したことを印にする。**

2026-08-20、日次ジョブのディスパッチャが `intake_register` を起動し、
Google Sheets API が **503 The service is currently unavailable** を返して失敗した。
**それなのに `intake_register.done` に当日の日付が書かれた。**

```
いまの挙動   実行した   → done を書く   → その日はもう走らない
あるべき     成功した   → done を書く
             失敗した   → done を書かない。次の周期で再試行する
```

503 は一時的な障害で、15分後に叩けば通る。
**たまたま503を引いた日は、その日の処理が丸ごと飛ぶ。しかも「済んだ」と記録される。**
→ [[reference_silent_rejection_backlog]]（却下＝処理済み扱いで二度と拾われない）と同じ形。

## 一時エラーと恒久エラーを分ける

```
一時（再試行する）    503 / 429 / 500 / タイムアウト / ネットワーク
恒久（即あきらめる）  認証切れ / 権限なし / スクリプトの構文エラー
```

恒久エラーを15分ごとに叩き続けても意味がない。すぐ人へ出す。

**★「諦めた」を「済んだ」と同じ印にしない。** 別の状態として持ち、Slack と心拍へ出す。
同じ印にすると、諦めたことすら分からなくなる。
