**揃うまで待つ設計にしない。届いた分から1つずつ差し替えられる形にする。**

**Why:** 2026-09-08、LIFE STAND UP デモサイトの「スタッフの声」実装で、有璽氏が
「何人か分は届く。4人分そろうのは今日中は難しい」と明言。全員分が揃うのを前提にした
実装（配列を一括で差し替える・4件セットでのみ意味を持つレイアウト等）だと、
1名分の回答が届いても何も反映できない状態になる。

**How to apply:**
- 複数人・複数件のコンテンツ（スタッフの声、保護者の声、写真枠など）は、
  **1件ごとに独立して差し替えられる構造**にする（枠ごとにnull許容・個別上書き可）。
- 残りが未着手（枠のまま）でも、レイアウトやデザインが崩れないことを実装時に確認する
  （1件だけ実データを入れて崩れないかテストする）。
- 「全部揃ってから一気に反映」は手戻りが少なく見えるが、実際には**部分的な進捗を
  無駄にする**（届いた1件がそのまま塩漬けになる）。
