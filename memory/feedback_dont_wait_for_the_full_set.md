**揃うまで待つ設計にしない。届いた分から1つずつ差し替えられる形にする。**

**Why:** 2026-09-08、LIFE STAND UP デモサイトの「スタッフの声」実装で、有璽氏が
「何人か分は届く。4人分そろうのは今日中は難しい」と明言。全員分が揃うのを前提にした
実装（配列を一括で差し替える・4件セットでのみ意味を持つレイアウト等）だと、
1名分の回答が届いても何も反映できない状態になる。

**How to apply:**
- 複数人・複数件のコンテンツ（スタッフの声、保護者の声、写真枠など）は、
  **1件ごとに独立して差し替えられる構造**にする（枠ごとにnull許容・個別上書き可）。
- 残りが未着手（枠のまま）でも、レイアウトやデザインが崩れないことを実装時に確認する
  （1件だけ実データを入れて崩れないかテストする）。
- 「全部揃ってから一気に反映」は手戻りが少なく見えるが、実際には**部分的な進捗を
  無駄にする**（届いた1件がそのまま塩漬けになる）。

関連: [[project_lifestandup_website_wordpress]]（2026-09-08 スタッフの声4名の実装で適用）

## ★2026-09-12 穴が埋まるときの答えは3種類ある（JFBI調査研究サイト）

未確定のまま `{{ }}` で公開していた4か所について、有璽氏から回答が来た。
**「値を教える」という答えは1つだけだった。** 残り3つは種類が違った。

| 有璽氏の回答 | 種類 | 実装での正しい扱い |
|---|---|---|
| 報告会は「2027年2月予定」 | **値が決まった** | 埋める |
| 倫理審査の承認番号は「ない」 | **★「無い」と決まった＝確定** | プレースホルダを**消す** |
| アクセス解析の記載は「なし」 | 同上 | 同上 |
| 同意書の取得は「要相談」 | **まだ決まらない** | 公開面からは消し、コメントと引き継ぎ書へ退避 |

**★「無い」を「未確定」と同じ箱に入れない。** 「無い」は確定の一種で、
`{{ }}` を出し続ける理由にならない。埋めるものが無いのだから、消すのが正解。

**★消すときは、残った文だけで意味が通るかを実物で読む。**
「〜実施しています。{{ 承認番号を記載する場合はここに }}」から `{{ }}` を消すと
句点で自然に終わるが、文の途中に埋め込まれている場合は前後が繋がらなくなる。
**消した直後に、その一文を声に出して読める形か確かめる。**

**★消したものは消えたままにしない。** HTMLコメントと引き継ぎ書の両方へ退避する。
「要相談」は決まる可能性があるもので、決まったときに戻せなければ穴が消えたのと同じ。

```
✕ 「4か所とも回答をいただいたので埋めました」  ← 3つは埋めていない。消している
○ 「1つ埋め、2つは"無い"が確定したので消し、1つは相談中として退避しました。
    消した3か所はコメントと引き継ぎ書に残してあります」
```
