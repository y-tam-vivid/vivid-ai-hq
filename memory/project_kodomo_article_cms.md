**2026-10-13 有璽氏の想定**
- 記事は団体側でも使えるようにしたい。ただし WordPress に直接打つのではなく、Claude で記事を作り、アップロード等だけ WordPress 経由。スプレッドシートでも可。
- 記事を書く Claude は★両方を想定：
  ①Claude の Team プランで★団体に Claude アカウントを付与・発行し、こちらがやり方を定めた★プロジェクトを作って、団体がそこで記事を作る
  ②これまでどおり、こちらがメモと写真を受け取って書く
- 「毎回こちらがやるのは難しい可能性がある。★タイムリーなものは団体側のオペレーションで出せる形を作りたい」

**Why:** こちら経由だけだと速報性が出ない（行事の当日・翌日に出したい記事が遅れる）。

**How to apply（設計の骨・ビビ案 10/13）**
```
①団体（claude.ai プロジェクト）──┐  同じ「記事の型」（書き方・写真の注意・顔と名前のルール）
②こちら（Claude Code）─────────┤
                                 ↓
              WordPress の「下書き」（記事の置き場としてだけ使う）
                                 ↓  団体が見て「公開」
              ko-station.org（静的のまま・公開済みの記事を読んで表示）
```
- ★記事の型は1本（正本）にして、団体のプロジェクトの指示とこちらのスキルの両方がそれを使う（二重管理にしない）
- ★顔・名前：②はこちらで自動ぼかし。①の claude.ai では確実なぼかしを保証できない＝プロジェクトの指示で「顔が分かる写真は使わない／同意済みのものだけ」を徹底し、下書きに入った写真をこちらの仕組みで後から点検する案
- 未決：WordPress をどこに置くか（費用）／Team プランの席の発行（有璽氏）／①のプロジェクトで写真をどこまで扱えるかの実測
- 関連 [[reference_group_blogs_and_cms]] [[project_minamikawachi_kodomo_station_site]]
