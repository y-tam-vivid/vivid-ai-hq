有璽氏は一覧だけ見ればよい。Slack の判断依頼も、押し忘れると埋もれる（2026-09-30 時点で未回答6件・最古9/15）。

**How to apply:**
- 作業の区切りで、有璽氏の手が要る次の一手（確認・判断・連絡・人の操作）があれば、
  **Current_Focus `## 今週` に1行ずつ足す**：`- [ ] 動詞で終わる具体的な行動 @期日 #次`（返事待ちは `#待機`）

```

                      → ★有璽氏の手が要る行が★埋もれる（10/8 は報告の途中に2件置いていた）
✅ これから（★恒久）  ★返答の★最後に必ず「## ★有璽氏がすること」の節を置く
```

### 形（★毎回これ）

```markdown
## ★有璽氏がすること（n件）

1. **〈動詞で始める一行〉**
   ・どこを開くか（URL・画面名・コマンドを1行で）
   ・★誰が待っているか／急ぐか
2. …
```

- **★0件のときも節ごと書く**（「★今回ありません」）。★節が無いと「見落としたのか無いのか」が分からない
- **★件数を見出しに入れる**（n件）。★数が合っているかを人が確かめられる
- **★色や記号で散らすのではなく、★場所を固定する。** 行頭の印だけだと★本文の中を探すことになる

### 3つの場所の使い分け（★混ぜない）

```
会話の「## ★有璽氏がすること」   ★いますぐ・このターンで動くもの
Slack の ask_hub ボタン           ★判断（押すだけで返せる・離席中でも届く）
Current_Focus のタスク行          ★後で見返す一覧（★Notionへ15分で自動同期）
→ ★同じ用件を3か所に書かない。★判断はSlack、作業は会話、残るものはCurrent_Focus
```
