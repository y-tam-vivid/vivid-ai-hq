# ★ ⑥はセッション単位で拾う（ページ単位にすると必ず枯れる）

⑥は **1スレッド＝1ページ**へ `📅 YYYY-MM-DD セッション` を追記していく構造。
重複排除を**ページURL**で行うと、1度拾ったページは以後何十回追記されても永久に対象外になる。
初回巡回で13件中1件しか⑥から拾えなかったのはこれが原因（しきい値でも読みの浅さでもない）。
**中身の濃い長期スレッドほど損をする**。重複排除のキーは **「ページURL＋セッションの日付」**。
