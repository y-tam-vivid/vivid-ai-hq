## STUDIO の制約（実測・公式ヘルプで確認済み）

- **CSVインポート非対応。** インポートできるのは WordPress XML のみ。無料プランはAPI連携も不可
  → CMSアイテムは**手入力**。CSVは入力台帳として使う
- **CMSモデルは3つまで。** WORKS / ILLUSTRATION / カテゴリ（NEWSは作らない）
- カテゴリ絞り込みには**参照プロパティ（シングルセレクト）が必須**。テキスト型では絞り込めない
- ダイナミックフィルターは**動的ページ内でしか使えない**
- 小さいボックスへ要素を入れるには **Shift を押しながらドラッグ**（オレンジの影が目印）
- **CMSアイテムは1件ずつ公開ステータスを持つ。** 入力しただけでは公開サイトに出ない

## 踏んだ地雷

- **透過PNGをRGB化すると透明部分が黒く潰れる。** `tools/export_hires.py` で一度やらかし、
  白地合成へ修正済み（37点を再書き出し）。**イラスト素材を書き出すときは必ず背景を確認する**
- **MDファイルにBOMを付けないとmacOSのテキストエディットが文字化けさせる。** CSVは最初から
  BOM付きだったが、MDで踏んだ。人へ渡すMDはBOM付きUTF-8にする
- 画像を `cover` で表示するとA4縦のチラシが上下で切れる。**ポートフォリオは `contain` ＋薄い背景色**
  が正解（作品の全体が見えることが価値）
