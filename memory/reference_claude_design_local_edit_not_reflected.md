**★`.dc.html` の `src` を書き換えても、Claude Design の画面がそう表示するとは限らない。**

2026-09-09（作業は9/8）、かわちばなしの画像18枠を差し替えたあと、有璽氏
**「Claude Design の方を見てるんですけど、なんかね、写真が差し替わってないんだよね」**。

## こちらが見落としていたもの

```
かわちばなし トップページ v4.dc.html      ★これしか見ていなかった。src を書き換えた
.image-slots.state.json  (119KB・隠しファイル)  ★見ていなかった
  中身 = { "v2-hero": { s, x, y, u } }
        u = data:image/webp;base64,…  ← ★画像そのものを抱えている
        s / x / y = 拡大率と位置（スロット内でのトリミング）
.thumbnail                                 ギャラリー用のサムネイル（これも古いまま）
```

**★隠しファイル（ドット始まり）は `ls` の既定で出ない。** 最初にフォルダを見たときは
`ls -la` で出ていたのに、**「画像は image-slot タグにある」と決めつけて中身を開かなかった。**

## ⛔結論：B で確定（2026-09-09 有璽氏の目視）

有璽氏「**トップ画像だけでなく、全ての画像、インスタの投稿、サムネイル等も含めて全てできていません**」。
state.json にあるのは v2-hero の1枠だけなので、**全部が変わらない＝state.json の問題ではない。**

```
Claude Design（クラウド側）   ★ここが正本
      │  書き出し（★一方向）
      ▼
~/Downloads/<プロジェクト名>/  ★ただのコピー。ここを直しても戻らない
```

**★裏付け**：19時ごろ向こうがフォルダを作り直した（v2/v3/無印の .dc.html・22MBの書き出し版・
控えが消えた）のに、`v4.dc.html` の mtime は **18:03 のまま**＝
**向こうはこのファイルを読みも書きもしていない。**

**★このフォルダを編集対象にしない。** 読む（構造を知る・静的化して見せる）のは有効。
**書いても無駄で、しかも「直った」と誤認する。**

## 型として

- **★「ファイルを書き換えた」は「画面が変わった」ではない。**
  相手のツールが持つ状態ファイルを見ないまま「差し替え完了」と報告した。
  → [[feedback_write_for_the_reader]]「反映した と書くな。どこで見えるかを1行で言う」
- **★実測は全部こちら側で閉じていた**（cdn参照0件／uploads参照12種／Artifact側21枚）。
  **どれも「ファイルの中身」の実測で、「画面の表示」を1度も見ていない。**
  ★人のツールの画面が出口なら、そこを見るまで完了と書かない。
- **★フォルダを開いたら隠しファイルの中身も1回開く。** 名前に `state` が入っていれば特に。

## ★2026-09-09 指示文に「前提」を書かず、相手に無駄な仕事をさせた

18枚は**もう手元にできていた**のに、Claude Design へ渡した指示文には
「下の指定で全部作り直してください」＋プロンプト18本しか書かなかった。
**向こうは自分で生成しようとして、Gamma のクレジット切れ（402）で止まった。**

```
書くべきだった   ★18枚は既にある。生成は不要。★各スロットへ配置してほしい
                 どのファイルがどの枠かの対応表
実際に書いた     「作り直してください」＋生成用プロンプト18本
相手の答え       「クレジットが尽きています。画像を添付いただければ配置します」
                 ★答えは向こうの回答の中にあった
```

- **★依頼文の冒頭は「何をしてほしいか」ではなく「いまどこまで出来ているか」から書く。**
  出来ているものを言わないと、相手は最初からやり直す。
- **★こちらの誤った見立て**：「元の画像が design-anything ＝ Claude Design 自身が作れる」
  と判断した。**作れるが、その先は Gamma のクレジットで、そこが尽きていた。**
  **★「そのツールが作れるか」と「いま作れるか」は別。** 残量を確かめずに経路を選んだ。
- 渡すのは画像そのもの。**ファイル名を「枠id＋画面の言葉」にすると相手が対応づけできる。**

## ✅2026-09-09 解決 ── これが唯一通った経路

有璽氏「クロードデザイン側に無事に反映されました」。

```
✕ 通らない   Downloadsのフォルダの .dc.html を書き換える（18枠やって全部無効）
✕ 通らない   生成プロンプトを渡して向こうに作らせる（Gammaのクレジット切れ402で停止）
○ 通った     ★画像ファイルをチャットに添付 ＋「生成不要・配置だけ」の指示を貼る
```

**★渡し方のコツ（これで一発で通った）**
- ファイル名を `01_v2-hero_トップの大きい写真.png` の形にする。
  **番号（配置順）＋スロットid＋画面の言葉** の3つを入れると、向こうが対応づけできる。
- 指示文の**1行目を「★画像の生成は不要です。18枚とも添付済みです」にする。**
  ここを書かないと、相手は最初から作り直そうとする（実際に1回させた）。
- 「レイアウト・配色・書体・文言には手を入れない。変えるのは写真だけ」を明記する。
- 置き場 `~/kb_images/配置用/`（18枚・38.8MB）。Finder で開いて ⌘A → ドラッグ。

**★次に Claude Design の画像を差し替えるときは、この節だけ読めば足りる。**

## ★役割の確定（2026-09-09 有璽氏）

**「作るのそのものは、Claude Design 側で作ってもらうので、その指示を出せるような状況にしたい」**

```
こちら（Claude Code）    ①実物を読んで診断する ②Claude Design へ渡す★指示文を作る
                        ③返ってきたものを検査する ④社外へ出す形（PNG＋Drive）を作る
Claude Design           ★作る側。デザインの実装はここ
```

**★こちらでデザインを作り込まない。** 2026-09-08 はローカルの `.dc.html` を18枠書き換えて
全部無効になった。**作るのは向こう、こちらは指示と検査。**
指示文の書き方（前提を1行目に書く・ファイル名に枠idを入れる）はこのファイルの上の節にある。

## ★2026-09-09 分かった制約3つ（Claude Design 側の回答）

```
① ★Google Drive のリンクを開けない
   こちらは指示文をDriveへ上げてリンクで渡していたが、向こうは開けない。
   ★通っていたのは有璽氏が本文をコピペしていたから。
   → 指示文は「そのまま貼れる本文」で渡す。リンクは有璽氏が読む用であって、
     Claude Design へ渡す経路ではない。

② ★ロゴPNG1枚から絵の要素は切り出せない
   「周囲のクリーム地・隣の絵の一部が混ざり、拡大でぼやける」（向こうの回答）。
   ★こちらの指示「ロゴの中の 寺の門・ぶどう・石橋 が使えます」は無理を言っていた。
   → 元がベクター（SVG/AI）でなければ、パーツ流用は最初から選択肢に入れない。

③ ★画像生成のクレジットは「向こうの財布」
   Claude Design の画像生成は Gamma 経由で、そこが 402（残0）。
   ★こちらの OpenAI API（残あり）とは別の財布。
   → ★絵が要る作業は、こちらで作って添付する方が速い。向こうに作らせない。
```

**★CSSで再現できるものは、絵を作らずに済む。** 今回の実例：
虹色の波線（ロゴ外周の色をCSSグラデーションで）／3つの丸（ロゴの配色・水彩風の質感をCSSで）
／4市のピル ── **この3つはクレジット0で実施できると向こうが回答した。**
絵が本当に要るのは「6つのアイコン」だけだった。**★「絵が要る」と「CSSで足りる」を先に分ける。**

## ★こちらから Claude Design へ送る口は無い（2026-09-09 実測）

「貼ってください」と人に頼む前に探した結果。**次に同じことを聞かれたら探し直さなくてよい。**

```
① memory を検索   Claude Design に触れたファイル10本 → ★「投稿・送信できる」記録 0行
② ツールを検索     Slack送信 / Gmail送信 / Notionセッションへの送信 はある
                  → ★Claude Design へ送るツールは無い
```

**＝渡す口は有璽氏の画面にしかない。** こちらができるのは
①指示文を「そのまま貼れる本文」で用意する ②画像を Finder で選べる形に並べる、まで。
**★人に手を動かしてもらうのは正しい。探さずに頼むのだけが問題。**
