## ★テストは「ターゲット別」ではなく「訴求別」でやる（2026-08-22 有璽氏）

```
訴求A  無料で始められる         初期0円・月額0円・景品原資0円
訴求B  リピートにつながる       値引きで粗利を削らずに再来店をつくる
訴求C  新しい手段を試せる       ゲーミフィケーションという打ち手そのもの
```

- **3本を同じセグメント構成へ均等に割り付ける。**業種の偏りが訴求の差に化けないようにする
- 変えるのは件名と前半（訴求）だけ。URL・締め・署名は3本とも同一にする
- **ターゲット別の言い回し（大型施設版・代理店版）は第2軸。**勝った訴求が決まってから作る
- 判定は**クリック率**（返信は母数が小さく差が出ない）
- **★送信の実行は当方から直接できない。** SalesBreaker の APIキーは GAS の ScriptProperties にしか
  無く、送信の口も未実測。**管理画面での操作は人の手が要る**（文面・リスト条件・NGリストまでが当方の範囲）
- **★既存顧客・既存商談先をNGリストへ入れること。** 台帳 `00_企業マスタ` の会社名/URLを
  吐いて渡す（読むだけ・台帳へは書かない）→ [[feedback_sales_workbook_hands_off]]
