**型・フォーマットを「新しく作る」前に、過去の実物を数える。**

## 何が起きたか（2026-08-20）

Manus の発信ラインを個人IGから他アカウントへ広げる作業で、Drive の
`Instagram_Manus MDファイル` に**デザイン正本（MD）があるのは個人IGだけ**と分かった。
そこで「他3アカウントには型が無い」と判断し、Manus に**ゼロから4案を提案させた**。

有璽氏の指摘 ── **「Vividの投稿は過去のアーカイブを確認し、そのデザインフォーマットで作成してください」**

ビビッド法人IGには過去の投稿が積まれていた。
- Notion **「法人Instagram 投稿アーカイブ」DB**（`collection://d28b812e-0b3a-4f2f-8916-cf3c471250c2`）
- Drive **「ビビッドInstagram投稿」**（`1m6Ezw15h7LOBBNWe10xJo8z4H42j_Qp6`）に
  `Instagram投稿031`〜`050`＋`修正版` の番号フォルダ群

**しかも当方は、その Drive フォルダを検索結果で見ていた。** 見たうえで使わなかった。

## なぜ間違えたか

**「正本ファイルが無い」＝「フォーマットが無い」だと読んだ。** これが誤り。

```
正本（MD・ガイドライン）が無い    ＝ 明文化されていないだけ
過去の投稿が積まれている          ＝ ★事実上の正本がある
```

実績が1本でもあれば、それが型。明文化されていないなら**アーカイブから型を起こす**のが順序で、
ゼロから提案させるのは、既にあるブランドを捨てて作り直すのと同じ。

## どうするか

**新しい型を作らせる前に、必ず2つ数える。**

| 数えるもの | 場所 |
|---|---|
| ① その媒体のアーカイブ件数 | Notion「情報発信 コンテンツ管理DB」配下の各投稿アーカイブDB |
| ② 実ファイル（画像・動画）の置き場と件数 | Drive（アカウントごとにフォルダがある） |

```
0件            → 新規に型を作ってよい
1件でもある    → ★まずアーカイブから型を起こす。ゼロから提案させない
                  そのうえで「変える点」だけを提案させる
```

- 提案させるときも「ゼロから4案」ではなく「**現行フォーマットを基準に、変える点の案**」と書く
- 個人IGのように正本MDがあるものは、正本 + アーカイブの両方を見る
