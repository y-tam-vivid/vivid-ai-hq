**毎朝の要対応に「もう要らない」と言う口が無い。だから死なない。**
2026-08-21 の朝ブリーフィングで、要対応22行のうち16行が14日超、最古が47日。
うち9行が複業クラウド（Another works）の新規エントリー。**本当に急ぐもの
（ネットプロテクションズ2日・Drive共有4日）が下に埋もれていた。**

**Why:** 継承方式（前日の親ページを読んで持ち越す）は、AIの近似判定
（未読か／スレッド最新が相手か）でしか落ちない。**有璽氏が「終わった」
「私は対応しない」と言っても、それがどこにも残らない。**翌朝また同じ行が出る。
規範2-2と同じ型 ── 届く経路はあったが、**人が書き込む場所が無かった**。

**How to apply:**

```
拾う → ★捨てる（除外ルール） → 起票（タスクDB） → 毎朝は鏡として映すだけ
                                     ▲
                        人はここでStatusを変える＝唯一の口
```

- **要対応の正本を「毎朝のページ」から「✅ビビッドタスク管理DB（全社）」へ移す。**
  `collection://62c7fadf-3fb1-409d-bc90-238fdce29b0f`。`オーナー区分=有璽氏個人`／
  `Status`／`Due Date`／`🚦信号`（Formula）が既にある。器を新設しない。
- **毎朝の本文は器ではなく鏡。** DBの未完了だけを映す。人がDBで閉じれば翌朝消える。
- **★14日で「消す」のではなく「畳む」。** 有璽氏の要望は「2週間以上は通知しない」だが、
  そのまま消すと **MARK N 山口様（42日・提出期限9/10）・リセ様の督促・Margin未払い・
  中村実里様（19日／有璽氏が名指しで対応要と言った件）** まで落ちる。
  → 本文からは畳んでDBに残す。**期限があるもの・督促は日数に関わらず出す**。
- **複業クラウド（Another works）の線引き（2026-08-21 有璽氏）**

| 状態 | 扱い |
|---|---|
| 新規エントリー・興味表示だけ | **出さない**（有璽氏は対応しない） |
| 相手から個別メッセージが来ている／往復が始まっている | **出す**（例：中村実里様・8/2〜） |

- **「不要」の伝え方は3つとも用意する。** ①その1件＝DBで🗄アーカイブ＋理由
  ②その種類＝除外ルールのページに1行 ③会話で言う＝こちらが②へ書く。
  ★①だけだと同種が翌週また出る。**種類で止める口を必ず持たせる。**
