**触ってよい。ただし変更する前に「戻せる状態」を先に作る。**
（2026-08-13 本人指示。同日の「勝手に触らない」から本人が転換した。理由＝「原本を触ってそれが違う形で使えなくなると困る」「誤操作があっても復帰できる状況にしてほしい」）

**Why:** 禁止は作業を止めるだけで、事故そのものは防げない。防ぎたいのは「壊れて戻せないこと」であって「触ること」ではない。ただし本人が同時に釘を刺している——**バックアップを取り違えたら本末転倒／大量に作って分からなくなるのも困る**。だから復帰経路は「作る」だけでなく**見分けがつき、本数が管理できる形**で作る。

## How to apply

### 操作ごとの扱い

| 操作 | 扱い |
|---|---|
| シートへの書き込み・列や選択肢の変更 | **①バックアップ → ②diff提示 → ③承認 → ④実行** の順。順番を飛ばさない |
| GASコード（原本テキスト・Apps Script）の変更 | 同上。既存ファイルを書き換えず**新版を別ファイルで足す**のがこのフォルダの既存流儀 |
| `buildWorkbook()` / `applySchemaV3()` の実行 | **禁止のまま。** バックアップがあっても復旧コストが高すぎ、実行する理由がない（→ [[reference_dangerous_entrypoints]]） |
| `matchKintoneRun()` の実行 | 書き込み側。**確認なしで回さない**（バックアップ＋承認が要る） |
| `matchKintoneDryRun` / `Report` / `Orphans` | 書かない。事前確認は不要 |
| 読み取り（`.gs.txt`・シート・メタデータ） | **自由。** バックアップ不要。ただし**読んだことは報告する** |
| 新規ファイルの作成 | 既存を壊さないのでバックアップ不要 |

### バックアップの取り方（取り違えと増殖を防ぐ）

```
置き場   99_バックアップ 1120…（フォルダID 1sa2NlGeYeX4zgSdlAqfaEGI09xVVyKhr）
         原本の隣には絶対に置かない。同じフォルダに並ぶと見分けがつかなくなる

命名     <元の名前>_バックアップ_YYYYMMDD-HHMM
         「Copy of …」のまま放置しない。日時が無いものはバックアップと呼ばない
         原本には日時を付けない ＝ 名前に日時があれば必ず複製

本数     1作業につき1本。変更のたびに取り直さない
         同じ作業の途中で2本目を作らない（どれが起点か分からなくなる）
```

**原本の見分けは名前でなくIDで行う。** 名前は似せられるがIDは一意。

| 対象 | ID |
|---|---|
| 営業案件管理ワークブック（**原本**） | `1lcSexlRLHtV2zzBm0Te_KKmR2uzCawQLzkyY50nPoNY` |
| `99_バックアップ` フォルダ | `1sa2NlGeYeX4zgSdlAqfaEGI09xVVyKhr` |
| `スクリプト原本` フォルダ | `1phKsApqIzTYmNTeMewUGFfkDjMz8He7V` |

**古い世代の削除は人の手に残す**（[[reference_dangerous_entrypoints]] と同じく破壊的操作はAI側でやらない）。AI側の責任は「無闇に増やさない」こと。増えすぎたと感じたら、消すのではなく**本人へ report して判断を仰ぐ**。

### 稼働確認は「最後にいつ」と「次はいつ」の両方で見る

**2026-08-13 実測**：`99_バックアップ` は自動2本（**2026-08-02(日) 19:54** / **2026-08-09(日) 19:54**）＋手動2本。手順書の「日 19:50 自動」と一致し、**週次トリガーは正常に動いている**。ワークブック作成が7/30のため、それ以降の日曜は8/02と8/09の2回だけ＝**取りこぼしゼロ**。次回は8/16(日)。

※ 手順書に残る「`setupBackupTrigger()` を実行した記録がない＝トリガー未設置の可能性」は**実データで否定された**。設置されている。手順書側の記録漏れだった。

> ⚠️ **この節は当初「8/10分が無い＝自動バックアップ停止」と書いていたが誤り（2026-08-13 訂正）。** 8/10は月曜。直近の日曜を数え違えた。**在庫の一覧だけを見て「止まっている」と判断した**のが原因。
>
> **教訓：稼働確認は「最後にいつ動いたか」と「次はいつ動くはずか」を必ずセットで見る。** 片方だけだと、動いているものを止まっていると誤判定する（今回）。逆に、間隔を持たないと止まっているものを見逃す。
