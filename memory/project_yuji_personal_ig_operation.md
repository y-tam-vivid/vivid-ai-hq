# ★キャプションの分量（2026-08-25 有璽氏）

**「少し簡易簡素なので、もう少しボリュームをしてほしい。ただし長文にならないように、
一文一文も長すぎないように。今の1.5倍から2倍ぐらい」**

```
元の原稿   本文3段落・約120〜150字（ハッシュタグ除く）
これから   本文 200〜215字。段落は5つ。一文は25字以内
一文       短く切る。読点でつながずに文を分ける
やらない   長文化・一文の長文化・情報の詰め込み
```

**★見本は 2026-08-28（金）の本文211字**（2026-08-25 有璽氏「28日の投稿ぐらいがちょうどいい」）。
迷ったらその実物と並べて長さを合わせる。**字数だけ合わせない。段落5つ・一文25字以内も一緒に。**

**厚くするのは真ん中の段落**。画像2枚目に描いてある①②③を、本文でも一つずつ言い直す。
そこに身近な例を1つずつ足すと、水増しにならずに増える。

**★公開済み・予約済みの本文も、あとから差し替えることがある**（2026-08-25、8/24 投稿済みと
8/26 予約済みの2本を新しい分量へ書き直した）。**出したら終わりにしない。**

- **増やすのは段落数と具体。1文を長くして水増ししない。**
- 元の原稿（`キャプションと根拠_1か月分.md`）の3段落構成は骨として残し、
  **画像に描いてある要素**（3つの箱・3ステップなど）を本文でも拾って厚みを出す
- 「制作根拠」節は社内用。出典や自社実践は**投稿文に混ぜない**
- 原稿に `**太字**` の記号が混ざっていることがある。**Instagram ではそのまま表示される**ので外す
- **適用は 2026-08-28 分から。**8/24 と 8/26 は原稿のまま出した（過去分は触らない）

# ★投稿時刻 ── 正本には無い。実績で埋めていく

**曜日は決まっているのに、時刻は正本4本のどこにも指定が無い**（2026-08-25 実測。
過去成果物・棚卸し台帳を grep しても出てこない）。**分からない回は有璽氏に確認する。推測で置かない。**

```
2026-08-28（金）  12:00        有璽氏の指定
2026-08-31（月）  14:10        有璽氏が予約画面で選んだ実績
2026-09-02（水）   9:00        ★こちらが14:10で置いたのを有璽氏が9:00へ変更
```

上に無い曜日は未確定。**確認したらこの表に足す。**
**★こちらが置いた既定は採用されるとは限らない。**9/2 は 14:10 → 9:00 へ変えられた。
既定は「前回と同じ」で置き、**変えられたら実績として上書きする**。
**★実績は「予約済みコンテンツ」画面で読める**（instagram.com/scheduled_content/）。
週表示のカードに時刻が出るので、聞かずに前回の時刻が分かる。

- **★Instagram Web に「下書き保存」は無い**（2026-08-25 実測）。投稿画面を閉じようとすると
  出るのは「**破棄**」か「**キャンセル**」の2択だけで、保存の選択肢が無い。
  モバイルアプリの下書きとは別物。**＝ 組んだ投稿を保持したまま次の回を組むことはできない。**
  複数日分を同時に進めたいなら、**先の回を予約にして画面を空ける**しかない
- **★ファイル入力が `find` で見つからない回がある**（2026-08-31 実測）。「ファイル入力
  （input type=file）」で聞くと**ボタンの方**が返り、`file_upload` が
  「Element is not a file input」で落ちる。**「写真をアップロードする隠れた入力欄 file」**
  のように**隠れている入力**だと言い換えると `(file)` が返る。諦めて別の手を探さない
- **★モーダルを開き直すと ref は無効になる**（`Element is no longer in the document`）。
  開き直したら **find からやり直す**
- **★「次へ」を連打しない**（2026-08-25 実地）。モーダルの幅は段階ごとに変わり、回によっても違う。
  前回と同じ座標で押すと**モーダルの外に当たり「投稿を破棄しますか？」が出る**。
  1回押すごとにスクリーンショットで位置を確かめる。出てしまったら**キャンセル**（破棄を押さない）
- **★時刻欄は `input[type=time]`。「1200」と一気に打つと 00:02 になる**（2026-08-25 実測）。
  正しくは **時の位置をクリック → `12` → `Right` キー → `00`**。打ったあと必ず拡大して読む
- **★予約するなら「予約済みコンテンツ」画面から作るのが速い**（2026-08-31 実測）。
  `instagram.com/scheduled_content/` → 右上「コンテンツを日時指定」で新規投稿を開くと、
  **「コンテンツを日時指定」が最初からON**の状態で始まり、右上も「投稿日時を指定」になっている。
  同じ画面で**既に入っている予約の日時も見える**ので、前回の時刻を確かめてから組める
- 予約は Instagram Web の投稿画面「**コンテンツを日時指定**」トグルから設定する。
  オンにすると日付と時間の欄が出て、右上が「シェア」→「**投稿日時を指定**」に変わる。
  **既定値は「今日・いまの時刻」**。運用上の既定ではないので、そのまま押さない
- **予約は「外へ出る」に当たる。** ただし後から変更・取消ができるので、
  日時さえ有璽氏に確認できていれば、設定そのものは進めてよい
- 有璽氏は「下書き」と「予約」を**言い分ける**（2026-08-25）。
  近い日＝下書きにして自分で押す／先の日＝予約で確定させる。**まとめない**
