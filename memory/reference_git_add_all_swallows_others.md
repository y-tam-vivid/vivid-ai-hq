**★`git add -A` は、いま自分が変えたものだけを拾わない。作業ツリー全部を拾う。**

2026-08-20、mini 上で **ビビ本体＋サブエージェント3〜4体が同時に `~/vivid-ai-hq/` を編集**していた。
その状態で `git add -A && git commit` を繰り返した結果、
**他のエージェントが書きかけのファイルが、無関係なコミットメッセージで入った**（実測2回）。

```
起きたこと   内容そのものは壊れていない
             だが「どのコミットが何をしたか」が混線する
なぜ困るか   あとで戻すとき、1コミットに複数の作業が混ざっていると切り離せない
             ★不具合の原因を git log から追えなくなる
```

## どうするか

```
書くとき     git add <触ったファイルを明示>    ★-A を既定にしない
             複数体が走っている間はとくに
確かめる     git status --short で、自分が触っていないものが混じっていないかを見る
それでも     完全な分離はできない（同じ作業ツリーを共有しているため）
             ＝ **混ざる前提で、コミットメッセージに何をしたかを具体的に書く**
```

**★サブエージェントに commit させない。** 束ねる側（ビビ）が、
何をしたかを把握したうえで、触ったファイルを明示して commit する。

## 併発しやすい状況

- 1つのセッションから `Agent` を3体以上、並列で起動しているとき
- そのうち複数が `~/vivid-ai-hq/` 配下（memory・bin・.claude）を書くとき
- ★`~/.vivid-relay/` は git 管理外なので、この問題は起きない
  （代わりに他機へ配られないという別の問題がある → [[reference_hooks_enforce_what_discipline_cannot]]）
