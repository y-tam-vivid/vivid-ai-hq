## ★これはリストを作る仕事ではない。チームを組む仕事（有璽氏 2026-09-08）

```
困りごとを可視化する
   ▼
それを解けるプロ（専門家・人材）を特定する   ← ★リストの使いみちはここ
   ▼
集めてチームにする
```

**「困りごと」ごとに「これを解けるのは誰か」まで書けないと成果物として使えない。**
抽象的な課題名の羅列は不可。専門性は**資格名・職種名**で書く（「コンサル」等の曖昧語は禁止）。
議事録で既に挙がっている連携候補＝社労士・弁護士・税理士・行政書士／諸橋氏の可能性アカデミー
（脳傾向性診断・脳科学コンテンツ）／内申点向上の専門家。**社労士は諸橋氏が紹介の意向。**

## 有璽氏が指定した成果物の形（2026-09-08）

```
第1段  網羅的な困りごとリスト        ★「網羅的に」を3回言っている。切り口の枠を先に作って埋める
第2段  重要度（順位）を入れる
第3段  自社サービスでどこを補えているか
```

**分類は3層で持つ**（有璽氏の明示指示）。

| ラベル | 範囲 |
|---|---|
| A | 福祉・介護 全般に共通 |
| B | 障害福祉のみ |
| C | 介護のみ |
| D | 特定のサービス種別のみ（放デイ／A型／訪問介護 等・種別名を明記） |

**★Dを落とさない。**「どのサービスの施設に何を売るか」が決まらなくなる。
議事録でも「福祉・介護では課題領域が異なるので、チームやサービス設計を分ける必要がある」と出ている。

**重要度は3軸＋総合ランク**：①発生率（調査の実数・出典つき）②経営インパクト（廃業・指定取消・
減算・赤字化に繋がるか）③緊急度（報酬改定・法改正など待ったなしか）。**推測で数字を埋めない。**

## 切り口の枠（10分類・両担当で番号を揃えている）

```
1 人（採用・定着・離職・育成・管理者不足・処遇改善・ハラスメント・メンタル）
2 利用者の獲得（集客・稼働率・営業・紹介元・空き定員）
3 お金（資金繰り・報酬改定・加算の取りこぼし・請求事務・国保連返戻）
4 制度・法令（実地指導/運営指導・監査・指定基準・記録の不備・法定研修・BCP・虐待防止）
5 現場運営（シフト・記録業務・書類・ICT化・送迎・事故/ヒヤリハット・感染症）
6 利用者・家族対応（クレーム・虐待疑い・保護者面談・支援の質・個別支援計画）
7 経営・組織（後継・多店舗展開・M&A・理念浸透・経営者の孤独・数字が読めない）
8 外部連携（相談支援専門員・ケアマネ・医療機関・学校・行政・他事業所）
9 IT・情報（システム乱立・情報漏えい・個人情報・記録システム）
10 その他
```

★有璽氏の見立て（議事録611行付近）は「**集客・採用・運営**が中心」＝ 2・1・5。
ただしこれは見立てであって実測ではない。**枠で網羅してから、実測で順位を付ける。**

## 自社の手札は3段階で分ける（★混ぜない）

```
①提供中    売った/納品した実績がある。★実績の証拠（案件名・時期・相手）を書く
②できる    道具も人も揃っており依頼が来れば出せる。外販実績はまだ無い
③構想のみ  議事録や記録に案として出ているだけ
```
**★①と②を混ぜると、営業が実績の無いものを「提供中」として言ってしまう。**
議事録に出ている構想＝採用支援／定着支援（第三者相談窓口・定期面談・カウンセラー）／
業務代行／施設経営支援／脳科学コンテンツ（職員・利用者・保護者の3対象）／保護者向け講座／
福祉事業者コミュニティ（匿名性あり）／士業連携。**価格・需要はどれも未確定。**

**★自社が福祉事業者そのもの**（ILIFE の放課後等デイサービス「LIFE STAND UP」・利用者およそ35名）
であることが他社に無い資産。**自社施設で実際に踏んだ困りごとと解決経験も手札に含める。**
