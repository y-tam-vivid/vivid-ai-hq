## ★2026-09-08 実測で見つかった抜け ── 経営者本人の課題が3件しかない

有璽氏の言葉は「福祉施設**の経営者が**抱えている課題」。
118件を機械的に数えたところ、**経営者個人に当たるのは3件だけ**だった
（#5 廃業・#17 相談できる相手がいない孤独・#18 後継者不在）。
118件は**「施設・事業の課題」**が主で、**「経営者という人の課題」**が薄い。

```
足りていない切り口   お金と個人のリスク（個人保証・自宅担保・役員報酬・退職金）／
                     任せられない（幹部が育たない・右腕がいない・現場の穴埋め）／
                     数字が読めない／相談相手がいない（職員に言えない・同業は競合）／
                     時間と健康／制度に振り回される／責任を個人で背負う（事故・訴訟・SNS）／
                     出口と将来（続けるか畳むか・売却・引退）／
                     ★理念と現実の板挟み ／ ★家族・同族経営
                     ★最後の2つは福祉業界に特に強く出る
```

**★経営者の課題は「業務を代行する」では解けないものが多い。**
話を聞く・場を作る・伴走する、という**サポートの形の違い**まで出させている
