**有璽氏（2026-08-20）**
> 「なんで俺が指摘しなきゃ穴を探さないんだ。自分で修正を繰り返していけ」

これまで穴を探す**起点が人の指摘だった**。指摘が来ない日は探さない＝
指摘されない穴は永久に残る。人が見つけた分しか直らない仕組みになっていた。

**Why:** 規範は「検証は作成者と別の主体が行う」と定めるが、
**いつ検証するか**を定めていなかった。起点を人に置くと、人の観測範囲が上限になる。

**How to apply:**

```
毎朝 08:40  self_audit.py（つる）が自分たちの仕組みを検査する
            ★対象は顧客データではなく cron／レジスタ／フック／ログ
            ★人の指摘を待たない。何も言われていない日も走る
```

## ★検査役の「直さない」には例外がある

`data-auditor.md` は「直さない。指摘までが仕事」と定めている。
**この原則は台帳・顧客DB・kintone に対してのもの。**
**対象が自分たちの仕組み（cron登録・レジスタの行・ログ・設定）のときは、
可逆なものはその場で直す。**指摘だけ出して放置すると、
「穴のリストが毎朝増える」だけで何も減らない。

| 対象 | つるの動き |
|---|---|
| 台帳・顧客DB・kintone | **読むだけ。絶対に書かない** |
| cron・レジスタ・ログ・設定 | **可逆なら直す**。直した内容を報告する |
| API申請・フォルダ設置・権限追加 | 直さず「★人が要る」として出す |
| 設計の分岐 | 直さず判断を仰ぐ |

出し方は `■ 直した ： N件 ／ ■ ★人が要る ： N件 ／ ■ 異常なし` の3ブロック。

## ★材料に添えられた数字を、そのまま指摘にしない（2026-09-07 実測・2回目）

**毎朝つるへ渡される材料の「経過日数」が、10件とも誤っていた。**

```
材料の申告   「18日経過(2026-08-20)」が10件
実物         WORKING.md:2786 は【リリス / MacBook 2026-09-03】＝★4日前
真因         self_audit.py:151 の heading_re が `^###` しか読まない。
             MacBook セクションは `- **【担当 / 機 日付】…**` の箇条書きで書かれており、
             日付が拾えず、直前の ### 見出しの日付を全部に貼っていた
```

**★偽の「18日放置」が、本物の18日放置（mini の crontab 問題・2026-08-20）と同じ行に並ぶ。**
区別がつかないので、結果として**どれも読まれなくなる**。
先に記録した「材料の発言欄は38%が偽物」と**同じ型**。材料は入口であって根拠ではない。

**How to apply:** 材料の数字を指摘へ写す前に、**その1件だけ実物で日付を読む。**
1件でも合わなければ、その欄は全部使わない。

## ★自己監査の報告が「書き戻しの言い訳」にすり替わって届いていた（2026-09-11 実測）

**8回中3回（9/5・9/7・9/10）、つるの報告本文が有璽氏へ1文字も届いていない。**

```
流れ   つるが報告を書き終える（9/10 08:50:16）
       → Stopフック hook_session_writeback が「未コミットあり」で差し戻す（08:50:17）
         ★対象は他セッションの書きかけ。つるは触っていない
       → つるの2通目「他セッションの書きかけなので置く」が claude -p の最終出力になる
       → self_audit.py はその2通目だけを受け取る
結果   '人が要る' を含まない → need_human=False → Slackへ出ない → 心拍「成功」🟢
実測   ①self_audit.log の該当日は 648/777/1285B（通常日は2.5〜3.4KB）で本文が無い
       ②hook_writeback.log 09-10 08:50:17 ★差し戻した ＝ transcript の報告時刻の1秒後
       ★9/10の報告は transcript にだけ残っていた（人が要る3件＝Downloads停止・vivi_patrol・同期）
```

**★監視が壊れて緑を出す型（④完走するのに静かに違う）。** 報告が消えた日ほど🟢になる。
memory_sweep（ロビン）など他の `claude -p` 定期実行も同じ構造（8/28に1例）。

**How to apply（今日の回避）:** フックに差し戻されたら、**2通目に報告全文を書き直す**。
「置きます」の1行で終えない。**恒久の直し（コード＝ピタゴラス）は人が要るへ出した**：
①非対話セッションでは自分が触っていないファイルで差し戻さない
②self_audit.py は出力に「■ 直した」が無ければ「失敗」で心拍を打つ。
