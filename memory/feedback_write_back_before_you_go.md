**有璽氏の指示（2026-08-25）**

> セッションの合間に定期的にメモリなり、その他のMDファイルをちゃんと上書きするような形にしたい。
> **僕が離席するような宣言をするようにするので、そうなったら自動的に上書きをするように**してください。
> もしくは、**私からの指示が一定期間ない時**は自動で現状をMDファイルなりメモリなりに
> 最新情報を共有する。**例えば1時間**指示がないみたいな時は、そのような形に。

**Why:** 会話は圧縮される。**要約は手順を残して役割を落とす**（規範2-2）。セッションが終わった瞬間、
MDに書き戻されていない事実は**存在しなかったことになる**。しかも書き戻しを「区切りで思い出す」に
依存させると、規律が切れた回にだけ失われる → [[reference_hooks_enforce_what_discipline_cannot]]。

**How to apply:**

```
合図は3つ。どれが来ても同じことをする

① 離席宣言       「離席する」「落ちる」「今日はここまで」「また後で」など
② 無操作1時間    有璽氏からの入力が1時間途切れた
③ ターンの区切り  一まとまりの作業が終わった

やること（順番も固定）
  1  この会話で分かった事実を memory/ の該当ファイルへ書く（無ければ作る）
  2  索引（MEMORY.md か INDEX_*.md）の現在地を1行だけ差し替える
  3  WORKING.md の自分のブロックを実態に合わせる（終わったものは消す）
  4  ./check.sh を通す
  5  触ったファイルを明示して commit（★git add -A は使わない）
```

- **★「あとでまとめて書く」は禁止。**離席宣言が来たときには、もう会話の前半は圧縮されている。
- **★機械側の担保**: `bin/vivid-sync.sh` が15分ごとに走り、**最終更新から1時間以上放置された
  未コミットのファイルを自動で commit する**（2026-08-25 実装）。書きかけを即座に飲まないよう
  1時間の猶予を置いている。**人が commit を忘れても、1時間後には必ず確定して他機へ届く。**
- **★これは「代わりにやってくれる」ではない。**機械が拾うのはファイルに書かれたものだけ。
  **会話の中にしかない事実は、機械には見えない。**書き戻しはAI側の仕事。

## ★「これ、途中で止まるんだよね」── 有璽氏の指摘は正しい（2026-08-25）

> 「これでオペレーション上は問題ないと思ってるけど、**落ちへんの。ほんまにこれが回るんやったら
>   いいけど、途中で止まったりするんだよね、このオペレーションがね。確実に回るようにしてほしい。**
>   1、2、3、いずれのタイミングでもね、それはいけそうなの？」

**手順を書いただけでは回らない。3つの合図は性質がまったく違う。**混ぜて「入れました」と言わない。

| 合図 | 何に依存しているか | 止まるか |
|---|---|---|
| ① 離席宣言 | **AIの規律**（言われたことに反応する） | **止まる。**長い作業の直後は特に落ちる |
| ② 無操作1時間 | **★セッションは入力が無いと1行も動かない** | **AI側では原理的に不可能** |
| ③ 作業の区切り | **AIの規律**（自分で区切りだと判断する） | **止まる。**区切りの判定自体が主観 |

- **★①③は規律依存。規律に依存する対策は、規律が切れた回にだけ効かない**
  → [[reference_hooks_enforce_what_discipline_cannot]]。**フックで止めるしかない。**
- **★②は「できません」が正しい答え。** Claude Code のセッションは入力が来るまで動かない。
  1時間の沈黙を検知して自分から書き出すことはできない。**機械側で代替する**：
  `bin/autocommit_stale.py`（60分放置の未コミットを確定）＋ `bin/hooks/memory_sweep.py`
  （毎朝ロビンが前日の git log・corrections.log・ログを読んで記録もれを拾う）。
  **ただし機械が拾えるのはファイルに書かれたものだけ。会話の中にしかない事実は永久に失われる。**
- **したがって本命は「①②③のどれでもなく、ターンが終わるたび」に落とすこと。**
  → `Stop` フック（`bin/hooks/hook_session_writeback.py`・2026-08-25 新設）。
  未コミットが残ったまま応答を終えようとしたら**1回だけ差し戻す**。
  2回目は通す（`stop_hook_active` を見る＝無限ループにしない）。
