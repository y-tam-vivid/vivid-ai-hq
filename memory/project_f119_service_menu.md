遡及是正でできるのは「不備の洗い出しと重要度の判定／是正可能な範囲の整理／自主点検報告書の
作成支援／過誤調整・自主返還の判断支援／今後の運用ルールへの反映」まで。
**＝「無いものを作る」系の困りごとは、119番では原理的に解けない。**
