# フォームが繋がった器をコピーすると、フォームのコピーがマイドライブに増える

**2026-10-14 有璽氏「マイドライブにこれがめちゃくちゃいっぱいある。どれを削除していいか全然わからん」**
── 「コピー ～ イベント掲載のお申し込み ｜ かわちばなし」が**51個**（9/12〜10/13）。

## 何が起きていたか

```
sheets_client.backup(file_id, title)
  └→ Drive の files().copy で器を丸ごと複製（99_バックアップへ）
      └→ ★Google は「器に繋がったフォーム」も一緒に複製する
          └→ そのコピーは★フォームの持ち主（有璽氏）のマイドライブ直下に落ちる
```

**器にフォームが2つ繋がっていた**（タブ「フォームの回答 1」「フォームの回答 2」）
＝ **バックアップ1回につきコピーが2つ**。だから数秒差のペアで増えていた。

```
裏取り2経路
  経路1  器のタブを実測 → 「フォームの回答 1」「フォームの回答 2」の2つ
  経路2  コピーの作成時刻 10/13 07:27:28Z ⇄ こちらが器を書く直前の backup() ⇄ 器の更新 07:27:56Z
```

## やること

```
★フォームが繋がった器は backup()（丸ごと複製）を使わない。snapshot()（書く範囲の値だけ退避）にする
   かわちばなしの器は26KB・書くのは1〜数セル＝snapshot で足りる
★新しい器を触る前に meta() でタブを見る。「フォームの回答」があれば、コピーは増えると思うこと
★AIが作ったものを人のマイドライブ直下に落とさない。落ちたら、その場で片付けるか置き場を決める
   ★「どれを消していいか分からない」状態を人に残した時点で、こちらの作り方が悪い
```

**消してよい見分け方（この件）** ── 題名が「コピー ～ …」で始まるものは全部ゴミ。
公開しているフォームは `…/forms/d/e/1FAIpQLSfqy3…/viewform` の1本で、**原本（題名に「コピー」が無い）**。
回答は原本にだけ入る。コピーは誰にも配っていないので、回答は1件も入らない。

関連 [[project_kawachibanashi_portal]] ／ [[feedback_memory_index_hygiene]]（作ったものの寿命を決める）

## 止め方（2026-10-14 実装・実測で止まることを確認）

`sheets_client.backup()` の冒頭でタブを見て、「フォームの回答」で始まるタブがあれば
**RuntimeError で止める**（`force=True` のときだけ複製する）。

```
実測  backup("1mRp6Cx…") → ★止まった
      「この器にはフォームが繋がっている（フォームの回答 2／フォームの回答 1）。…snapshot を使うこと」
控え  ~/.vivid-relay/_backups/sheets_client.py.bak_20261014-1454_formguard（15,910B）
      15,910B → 17,110B（+1,200B）
```

★**捨てる操作はこちらではできない**（この端末では Drive のゴミ箱への移動が禁止・
サービスアカウントは有璽氏が持ち主のファイルを消せない）。**押す場所まで書いて人へ渡す。**

```
ドライブの検索窓に   コピー ～ イベント掲載
1つ目を押す → Command+A → ゴミ箱のマーク（30日は戻せる）
```
