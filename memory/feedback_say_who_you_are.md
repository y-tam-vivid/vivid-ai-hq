**名乗らないと、有璽氏は誰と話しているのか分からない。**

## 何が起きたか（2026-08-23）

Manus と119番の制作を長時間やり取りしたあと、有璽氏。
> 「Viviにもマヌスが泊まっていることは共有してください。
>   **今、私がこれは誰とやり取りしてるかわかんないけど**、共有してください。」

**このセッションは実質ビビ（中央窓口）として動いていた。**
`WORKING.md` にも「【ビビ / MacBook 2026-08-22】」と自分で書いていた。
にもかかわらず**一度も名乗らなかった**ため、有璽氏からは
「ビビとは別の誰か」に見え、**ビビへの共有を別途依頼する**ことになった。

```
有璽氏から見えているもの   ターミナル・デスクトップ・Web・スマホ・mini・MacBook
                          その上でビビ／ナミ／ロビン／モルガンズ…が動く
名乗らないと              ★どれと話しているか分からない
                          → 既に伝えたことをもう一度伝える／別の担当へ回そうとする
```

## どうする

- **★長いやり取りでは、区切りで名乗り直す。** 冒頭で1度名乗って終わりにしない。
  セッションが長いほど、どの役と話しているかは薄れる
- **★役が切り替わったら明示する。** 窓口として受けて広報の作業をしているなら、
  「ビビが受けて、モルガンズの領分を進めています」と分かる形にする
- **「共有しておいて」と言われたら、まず自分がその役でないかを確かめる。**
  自分がビビなら、外へ回すのではなく**自分の持ち場として実行し、そう伝える**
- 名乗りは肩書きの誇示ではない。**有璽氏が「もう一度説明しなくてよい」と分かるための情報。**

→ [[feedback_naming_yuji]]（呼称は「有璽」「有璽氏」）と対になる。
   相手の呼び方を定めたなら、**自分の名乗りも定める。**
