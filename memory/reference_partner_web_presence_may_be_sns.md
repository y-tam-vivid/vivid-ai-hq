**2026-10-16 有璽氏**（JFBI 協力団体の詳細ページに公式サイトのURLを載せた直後）：

> a’s ★入れていません：**「Instaのアカウントになるかと思います」**

こちらは「公式サイト（独自ドメイン）が見つからない＝載せるものが無い」と結論していた。
**探す対象を自分で狭めていた。** 検索3経路（団体名・通称・親団体名）はどれも
「◯◯のサイト」を探す検索で、**SNSのアカウントを探していなかった。**

**Why:** 独自ドメインのサイトを持たない団体は珍しくない。小さな団体・事業単位の活動ほど
Instagram や Facebook が実質の窓口になっている。「WEBサイトのURLを載せて」という依頼は
**「その団体の外向きの窓口を載せて」**という意味であって、ドメインを持つサイトの指定ではない。

**How to apply:**

```
★探す順    ①独自ドメインのサイト ②Instagram ③Facebook ④LINE公式 ⑤親団体サイトの中の事業ページ
           ⑥受領資料（チラシ・パッケージ・名刺）に印刷されたID・QR
★聞き方    「公式サイトはありますか」ではなく★「外に出している窓口はどこですか（サイト／SNS）」
★ラベル    媒体に合わせる（公式サイト ○○.com ／ Instagram @○○）。★位置と枠は同じにする
★推測しない IDの綴りは当てない。候補が出せないときは★URLをそのまま貼ってもらう
           （音で聞くと崩れる → [[feedback_voice_input_name_kanji]]）
```

- **★印刷物に写り込んだQRは当てにならない。** a’s の受領写真10枚にQRが3つ写っていたが、
  cv2 の位置検出＋4〜10倍拡大＋大津/適応二値化まで試して**読めたのは0件**
  （元が 1108x1477 の写真の中で約70px四方＝1モジュール3px弱）。
  **★「資料に写っているから読める」とは限らない。2〜3手で読めなければ人に聞く。**
- この件の本体（どこに何を載せたか）→ [[project_jfbi_research_site]]
- 受領素材そのものの検品の型 → [[reference_supplied_material_needs_screening]]

## ✅同日の結着 ── URLをもらい、★本人のものか2経路で確かめてから載せた

有璽氏から `https://www.instagram.com/okazaki_as/` をそのまま貼ってもらった（★音ではなくURL）。

```
①機械の経路   curl → HTTP 200 ／ og:type=profile ／ og:url が与えられたURLと一致
              （存在しないアカウントなら Instagram は 404 を返す）
②中身の経路   表示名「a’s to the story 制作委員会®〜あなたと私の夢語〜」
              ★受領写真の額に写っていた「a’s Art 〜あなたと私の夢語〜」と同じ言葉＝同一の団体
```

**★SNSのリンクは「200が返った」だけでは足りない。** IDが1字違っても別人のアカウントが
200で返る。**中身（表示名・プロフィール）が団体と結びつくことまで見る。**
ログイン無しでも og:/プロフィール文は取れた（WebFetch）。

載せ方は他3枚と同じ位置・同じ枠で、**ラベルだけ媒体に合わせた**（`Instagram @okazaki_as`）。
本番実測：4枚とも 別タブ＋noopener・各1件・横あふれ0・リンク先4本とも HTTP 200・不合格0。
