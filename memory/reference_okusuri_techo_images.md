# お薬手帳の画像と命名規則（個人領域）

**置き場**: `~/Downloads/お薬手帳/`（2026-08-21 時点 26枚・**人ごとのサブフォルダは無くフラット**）
元のファイル名は LINE/スマホ由来の乱数列（例 `627954320239493328.jpg` / `04EED5E4….jpg`）
＝**名前から人も中身も分からない。全枚を開いて読むしかない。**

**命名規則（2026-08-21 有璽氏）**

```
人名_01.png ／ 人名_02.png …
  人名     姓名の間は詰める（例 吉位侑真）
  連番     ★人ごとに 01 から。1枚だけなら 01 のみ。複数枚あれば 02, 03 と増える
  順序     調剤日の古い順。読めなければファイル更新日時順でよい
  拡張子   ★png に統一する（元が jpg でも変換する）
```

- **リストは網羅とは限らない**（有璽氏の申告）。画像から読んだ氏名がリストに無ければ**追記する**。
- 姓が同じ別人が複数いる（清水3名・竹口2名・苅田2名・濱口2名）。**姓だけで判定しない。名まで一致で見る。**
- 判読できない画像は**推測で名前を付けず** `_要確認/` へ寄せる。

**機微の扱い**

- 中身は**医療情報（患者氏名・処方薬・医療機関・調剤日）**。個人領域の資産。
- **ローカル完結。** Manus 等の社外へは渡さない → [[project_manus_outsourcing]]
- Notion / Drive へ上げるかは有璽氏の判断。**既定は上げない。**

**改名するときの作法**

1. **元フォルダをまるごと複製してから**着手する。ファイル名は上書きすると戻せない
2. `元名 → 新名` の対照表を必ず残す（これが復帰経路）→ [[feedback_sales_workbook_hands_off]] と同じ型
3. 1枚に複数回分の調剤シールが貼られている。**連番の基準にする日付は「その画像の最古の調剤日」**
