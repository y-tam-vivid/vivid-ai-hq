# AIからの確認待ち

> [!info]- 使い方・並び順の説明（クリックで開く）
> AIが足した「有璽氏の確認・判断・操作が要るもの」の一覧です。有璽氏が書く `02_Current_Focus.md` とは分けています。
> 期限が近いもの（期限切れ・今日・3日以内）は、02 の先頭「🔥 優先（自動）」へ移ります（目印は1本のまま。期日が遠のくとここへ戻ります）。
> 上から「答えが要る」（#急ぎ・#今週・期日つき）→ ほかの未完了を【案件】ごと → 「無ければ推奨で進めます」→ 「済み」の順に、同期のたびに自動で並べ直します。案件は期日の近い行を持つものが上、次に新しく発行されたものが上です。【案件】の後ろの「10/13発行・」は同期が付ける表示です（Notion の「作成」日。消しても戻ります）。終わったら `[x]` にしてください（済みの行は翌日以降、90_Archive へ移ります）。
> AIの書き方：`- [ ] 【案件】有璽氏がする行動（担当） @期日 #急ぎ`　区分は `#急ぎ`（相手が待っている・外の期限あり）／`#今週`／`#いつでも`。
> `@期日` は外の期限があるときだけ。区分も日付も無い行は「ほかの未完了（案件ごと）」に入ります。
> 「いつでも」のまま14日間動かない行は、この一覧から外れて Notion にだけ残ります（Notion 側の状態は変えず、消しません）。
> `###` で始まる行は同期が作る見出しなので、メモには使わないでください。
