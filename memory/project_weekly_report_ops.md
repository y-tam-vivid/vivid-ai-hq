## ★★曜日は確定している（2026-08-18 セッション）── 勝手に動かさない

```
対象週        月〜日（土日を含む）
スタッフ提出   日曜 終業まで（各自 金〜日のどこかで。月曜を待たない）
★集約・発信   有璽氏が「週明けの最初の稼働日」に、出揃った分を締めて動画化・全社共有
```

**★金曜案は既に検討して落とされている。**理由＝「金曜提出だと土日の重要商談・稼働が抜ける」。
月曜提出も落ちている（月曜稼働が全員に保証されない／祝日で後ろ倒しが連鎖する）。

**★解決の核心＝「提出」と「集約・発信」を分離する。**
締切を日曜に固定すれば曜日の稼働ムラに依存せず、集約は有璽氏1人の作業なので遅れが伝播しない。

## 分類の要点（ここが2度ひっくり返った）

```
✕ AIが事後に取り組みを部署へ振り分ける   →★外す（X投稿50件を総務部と誤る等・実証済み）
✕ 「推測禁止・本人が全部ラベルを付ける」 →★行き過ぎだった（有璽氏が調整）
◎ AIが仕分け案を出す → 本人が確認・修正して確定
```

**★粒度は「取り組み1件＝1ラベル」。**人単位の集合（チェックボックス）では兼務を表せない。
**★出力に個人名を出さない。**部署＋プロジェクト単位の取り組みとして発信する。
**★報告軸は「所属」でなく「今週活動した部署」。**兼務・複数またがりが多いため。
