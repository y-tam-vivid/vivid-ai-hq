**SNSの画像加工はManus（または同等の生成系）に任せる**（2026-08-25 有璽氏）。
**あわせて、アカウントごとにデザインを使い分ける。** 同じ写真を使ってもよいが、
見た目は分ける。

**Why:** こちらがPILで組む画像は「読める」止まりで、アカウントの顔にならない。
発信先が増えるほど、全部が同じ見た目になる方が損になる。

## ★画像を2つに割る。全部を外へ出さない

```
写真の切り出し・トリミング      ← こちら（Claude Code）
  規約と肖像の判断が要るため。2026-08-25、会場ポスターとイーゼル看板が
  大きく写る2カットを Roblox の表記規約に沿って画角から外した。
  この判断は規範（[[reference_roblox_event_naming_rules]]）を読んでいる側でないとできない

表紙カード・数字カード・バナー  ← Manus／生成系（外）
  アカウントごとの世界観をつくる仕事。こちらの守備範囲ではない
```

**渡すときは「素材＋制約」で渡す。**「いい感じに」では規約判断が外へ流出する。
出してよい数字・注記（n=37 等）・使ってはいけないロゴを、指示文に必ず書く
→ [[project_manus_outsourcing]]（Manusは社外＝情報ファイアウォールの適用先）。

## 使い分けの正本は 📱発信アカウント台帳。新しい器を作らない

**既に3列ある。**`視覚トーン` ／ `デザイン正本`（Driveへのリンク）／ `作り手`。
アカウント別のデザインを決めたら、**ここを埋める**。別表を作ると二重管理になる。

## ★モックアップ（写真のように見せる見本画像）は PIL で描かない（2026-10-28 有璽氏）

芽育ラボの作品集の試作で、壁・机・端末・紙袋を Pillow で描いて作品をはめ込んだ →
有璽氏「モックアップの出来がめっちゃイマイチ」「特に紙バッグ（ショッパー）はダサすぎて人には見せられない」
「ChatGPTにやってもらえますか」。
- ★写真らしさが要るもの（紙袋・Tシャツ・端末を置いた部屋）は画像生成（OpenAI gpt-image の編集）で作る
- ★作品そのもの（ロゴ・文字）は生成に描き直させると崩れる → 生成後に元の作品と見比べて、崩れたら採らない
- PILで良いのは「作品を平らに並べる・枠に収める」まで（9/15 の4:3の見本は採用されている）
- ✅10/28 実測（gpt-image-1.5 の画像編集・input_fidelity=high・1536×1024・high）：紙袋4枚中3枚はロゴがそのまま刷られた
  ★芽育ロゴは「プロジェクト」が「ブOシェクト」に崩れた＝細い日本語の小さい文字は崩れる
  → ★崩れたら「ロゴなしの場面だけ生成 → 本物のロゴを乗算で刷り込む」に切り替える（正面の平らな面なら自然に見える）
  道具は scratchpad の creator/gen_mockups_ai.py（鍵は ~/.vivid-relay/config.env の OPENAI_API_KEY）
- ✅10/28 有璽氏「（画像生成の紙袋）めっちゃいい感じ」→「紙袋にこだわらず他の種類も。★ロゴをうまく展開したような図（展開図）」
  ＝★ロゴ作品の見せ方の本命は「ブランドの展開図」（名刺・封筒・便箋・トート・マグ・看板などに同じロゴが並ぶ平置き）。Web作品は対象外
- ✅10/28 展開図の実測（6枚＋作り直し3枚）：★採れたのは英字・幾何学のロゴ（マネーシンギュラリティ・太陽と月・デイズ）
  ★崩れた：スワン（小さい英字の円弧・小物の文字）／こどもまつり（1文字ずつの風船＝「つ」が抜ける・缶バッジに1字ずつ割る）／芽育（2回とも暗い周辺減光）
  → ★日本語の細い字・1文字ずつ並ぶロゴは展開図にしない。紙袋（大きく1か所）か「場面だけ生成→刷り込み」で
