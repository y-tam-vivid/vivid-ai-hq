## 確定した5枚の構成

```
1 表紙        人物イラスト主役・文字は上部。ビジュアルとテキストの主従を守る
2 図解        見出し＋説明文＋図解。★見出しの数字と図解の要素数を必ず一致させる
3 3点         俯瞰の机上構図。資料の中身まで描く
4 問い        後ろ姿＋ノードの図。動きのある構図
5 CTA         「無料診断はプロフィールリンクから」★この文言で確定（有璽氏確認済み）
```

- 画風は **E リアル人物イラスト**。人物は**有璽氏の写真に寄せた別バージョン**
  （参照写真7枚 → Drive `03_ブランド・テンプレート素材/人物イラスト参照_有璽氏/`）
- ブランド：濃紺 `#0E2A47` ／ アクセント `#E2733B` ／ 実物のロゴ**1か所**

  ただしテキストボックスを主役に戻さない
- 2枚目以降の型は3種 ── **図解主役／編集コラージュ／写真ベース静物（人物なし）**

## ★この型に至るまでに潰した失敗（同じ道を繰り返さない）

```
第1便    採用案の画像を表紙へ貼り込み・見切れ／内部コード「A×E」が印字
         2枚目以降にイラストが無い          → [[feedback_taste_is_not_a_sticker]]
第2便    「5領域」と書いて図解カード3枚／ロゴが上下2回／写真パターンが無い
第3版a   写真案のパネルが全部空白（★制作設計には「注釈を重ねる」とあった＝設計と実物の食い違い）
         人物の手が破綻／「書類だけの整理になりにくくなります」＝日本語のねじれ
第3版b   ★全部解消。承認
```

- **★手の破綻は直そうとしない。「2回試して直らなければ手が映らない構図へ変える」と先に伝える。**
  画像生成で手は最も破綻しやすい。第3版bは Manus 自身が構図変更を選んで解決した
- **★数字と絵の数は必ず突き合わせる。**「5領域」と書いて5個描かれているか
- **★説明文は声に出して読ませる。** 文字量を増やすと係り受けのねじれが増える
- **★制作設計MDと実物を突き合わせる。** 設計に書いてあることが実物に無いことがある

## ★「写真に寄せる」には強さがある。基準を実物1枚で決める（2026-08-23 有璽氏）

> 「**私の画像が写真に近いものになっている**ので、テイストはイラストのテイストにしてくれていい。
>   イメージとしては **I-03の01のイラストくらい**のイメージです。」
> 「イラストそのものも**私に寄せているものもあれば、そうでないものもある**ため、
>   **全てを私の素材写真に寄せる**ように、素材写真をベースにしたイラストに寄せるように」

```
指示の意味   顔立ち・雰囲気は寄せる ／ ★絵の質感は寄せない（実写化しない）
起きたこと   ①寄せすぎて写真に見える回が出た
             ②同じ依頼の中で、寄せた回と寄せていない回が混在した
```

- **「写真に寄せて」だけでは強さが伝わらない。** 寄せる対象（顔立ち）と
  寄せない対象（絵のタッチ）を分けて言う
- **★基準は言葉でなく実物で指定する。** 有璽氏は「I-03の01くらい」、続けて
  「**I-04の05でも良い**」と、**実物2枚**で示した。以後もこの決め方を使う。
  **★見本は1枚より2枚がよい。** 1枚だとその構図まで真似る。2枚あると
  「共通しているもの＝画風」が伝わり、構図は自由に振れる

```
見本  I-03/01_cover      デスクの引き・イラスト感が強め
      I-04/05_cta_next   バストアップ切り抜き・やや精緻
共通  顔立ちが参照写真の人物／明確にイラストで、写真には見えない
```
- **★まとめて作らせると寄せ方がばらつく。** 型は揃っても画風の寄せ具合は揃わない。
  一括生成のときは「**全点を見本1枚に合わせる**」を必ず添える
- 完成後の検算は**全点を並べて見る**。1本ずつ見ると、ばらつきに気づけない
  → [[feedback_type_is_not_layout]]

## ★「まず1本で確認」は型が決まる前だけ（2026-08-22 有璽氏）

第1便が5本とも作り直しになった反省から、当方は「まず1本作らせて確認」を既定にした。
だが型が確定したあと、有璽氏は **「I-01〜I-06 について、一旦全て作成してください。
その上でこちらで判断します」** と指示した。

```
型が決まっていない   ★1本で確認する（作り直しが5倍になるため）
型が決まっている     ★まとめて作る。判断は有璽氏がまとめて行う
```

**慎重さを既定にし続けると、往復が増えて遅くなる。**
どちらかを勝手に決めず、**型の確定/未確定で切り替える。**
