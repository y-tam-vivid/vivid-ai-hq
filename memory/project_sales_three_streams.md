# 営業まわりは3本が並走している ── 「分ける」が検討に上がった（2026-09-05）

## 有璽氏の発言（原文）

> 「別セッションで進んでいたテレアポリストの作業や、**クロードAIとディスカッションしている
> 営業の数値管理**についても念頭に入れた形で行いたい。
> **もう完全に分かりを分けるなども視野に入れている。**
> ちょっとそこは**オペレーションが変わるかもしれません**ね。
> 理由は**今のこっちの営業台帳の方が思うように進んでいない**ので。別で。
> しかも**数字をちゃんと見えるっていうところも作らないといけない**のでね。」

## いま並走している3本

```
① 営業台帳の整備      顧客台帳(00/01/02/40)の重複・法人番号・受付フローの詰まり
                      → [[project_sales_workbook_read_first]] [[reference_ledger_cleanup_triage]]
                      ★8日連続で同じ3件が鳴り続けている。★これが「進んでいない」の中身

② テレアポリスト      他サービス種別へ広げた13タブ・10,982行。つるが3周目の検査中
                      → [[project_telapo_list_other_services]]

③ 営業の数値管理      ★別の面（claude.ai）でディスカッション中。★ここには記録が無い
                      「数字がちゃんと見える」器を作る話
```

- **★③はこのリポジトリに記録が無い。**別の面での議論なので、こちらからは中身が見えない。
  **議論の場が分かれている＝現在地が1枚にならない**という、既に踏んだ型
  → [[feedback_reading_list_is_not_a_map]]（起点1枚を決める）。
- **★「分ける」の対象がまだ確定していない。**セッションを分けるのか、担当を分けるのか、
  台帳そのものを分けるのかで、やることが全く違う。**決めてから動く。**
  ★ただし [[feedback_one_session_split_by_owner]]（分けるのはセッションでなく担当）が既にある。

