**有璽氏の要望（2026-08-24・原文の要点）**

1. **定例タスクを管理したい。** 日々やるもの／週／月／年 ―― 周期がそれぞれある
2. **メモ書きの癖がある。** 「どうしても癖で入れてしまう」。**やめるのではなく、拾って寄せたい**
3. ビビがそのメモを拾って、Notionのタスクへ反映してほしい

**★2の読み方を間違えないこと。** 「メモを書くのをやめて Notion に直接入れてください」は答えではない。
**癖は変えない前提で設計する。**入口を変えろと言うと運用が死ぬ。
