Macのファイル整理運用（2026-07-05 構築）。**Downloads＝一時受け皿(Inbox)／Google Drive＝整理済みの本棚(正本)** という二層モデル。

- **本棚**: 業務用マイドライブ `~/Library/CloudStorage/GoogleDrive-y_tam@vivid-global.com/マイドライブ/Downloads書類アーカイブ/` に **17分類フォルダ**（01_AI・開発〜17_メモ・下書き）。機微情報（13_個人・09給与・08契約・03財務）も本人のみアクセスのマイドライブへ集約する方針。
- **Downloadsは同期しない**（ゴミが混ざるため）。新規DLはDownloadsに落ち、定期的に本棚へ振り分ける＝振り分け＝クラウド保存。
- **週次自動振り分け**: `~/bin/sort_downloads.py`（キーワードで確信できるものだけ17分類へ移動、不明は残置、~$・.DS_Storeは除去、macOS通知＋`_整理ログ/`にCSV）。ユーザーcronで毎週月曜9:00実行（`crontab -l`）。手動実行は `python3 ~/bin/sort_downloads.py`、判定のみは `--dry-run`。
- **注意**: `~/Library/LaunchAgents`はroot所有でlaunchd不可のためcron採用。cronが機能するには **システム設定→プライバシーとセキュリティ→フルディスクアクセス に `/usr/sbin/cron` を追加**（一度だけ手動）が必要。
- 整理ログ: 本棚内 `_整理ログ/`（_整理ログ*.csv、_動画退避マニフェスト等）。全操作は移動ベースで復元可能。
- 分類の判定ロジックを直すときは `~/bin/sort_downloads.py` の RULES を編集。関連: [[project_secretary_agent]]（ビビはクラウド側なのでローカル整理は不可）。
