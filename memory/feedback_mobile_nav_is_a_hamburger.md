# スマホのナビは「3本線」から開く ── 常時表示にしない（2026-10-13 有璽氏）

有璽氏「ナビゲーションですが**常に出ている状態ではなくて**、スマホ版の時、
横側右手とか左手に**3本線**があって、**そこから現れるような形**の設計に変えてください。」

## 何が起きたか

JFBI 調査研究サイトで「スクロール後もナビ5項目を触れるように」と頼まれ、
**細いバーを出したまま残す形**で実装した（幅390で82px＝画面の9.7%）。
横あふれ0・5リンクとも押せる状態まで実測して出したが、**求められていた形ではなかった。**

```
こちらが出した形   細いバーが常に出ている（リンク5つが2段で見えている）
有璽氏が求める形   ★3本線のボタンだけが出ていて、押すとナビが現れる
```

## 恒久のルール

- **スマホ幅のナビゲーションは、3本線（ハンバーガー）から開く形を既定にする。**
  リンクを並べたまま常時表示にしない。画面の面積は本文に渡す。
- **PC幅は常時表示でよい**（今回の指摘は「スマホ版の時」と限定されている）。
- 左右どちらに置くかは指定されていない（「右手とか左手に」）＝**どちらでもよい**。
  迷ったら右。
- ★「触れるようにする」＝「見えたまま残す」ではない。**押せる経路が1つあればよい。**
