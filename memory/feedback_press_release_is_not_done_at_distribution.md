**★プレスリリースの仕事は「PR TIMESへ配信する」までではない。**
**関係する自社法人のブログ・SNSへ載せる文面と画像を作るところまでが1セット**（2026-08-25 有璽氏）。

```
1  リリース本文を作る          PR TIMESの体裁 → [[feedback_prtimes_style_conventions]]
2  入稿・配信設定             名義の制約 → [[feedback_prtimes_npo_account_scope]]
3  ★対象の発信先を確認する      Notion「📱 発信アカウント台帳」を読む。推測で並べない
   collection://3f0202d1-2352-4695-a399-626705eb9014
4  ★ブログ・SNSの投稿文と画像を作る  法人ごとに読者が違うので使い回さない
```

- **対象法人は毎回リストを出して確認を取る。** 案件によって関係する法人が変わる
  （例：子ども向けイベント＝ふくち。／ビビッド／NPO／オレンジワークス藤井寺、
  福祉×AIのウェビナー＝ILIFE／NPO／ビビッド）。
- **ブログはCMSが3種類ある**（Jimdo／WordPress／STUDIO）。**入稿できる形式に合わせて渡す**。
- **台帳に無い発信先は「作ってから」進める。** 空欄のアカウントへ投げると、
  こちらの推測がそのアカウントの声として世に出る → [[feedback_check_the_archive_first]]
- 投稿の実行者は当面すべて有璽氏（2026-08-25）。★AIは文面と画像を作るところまで。
