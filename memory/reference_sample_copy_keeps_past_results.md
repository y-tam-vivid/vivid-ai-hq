**見本（テンプレート）を複製して新しい成果物を作ると、前の案件の実績が混ざって渡る。**
複製した本人には「器を用意しただけ」に見えるので、申告にも出てこない。

```
起きたこと（2026-09-05・テレアポリストの「活動FB」タブ）
  見本      A1 = '活動FB', '=SUM(B3:B30)', '=SUM(C3:C30)', '=C1/B1', …   ← 数式
  複製した器 A1 = '活動FB', 24, 16, 0.666…, 5, 0.208…, 1, 0.041…          ← ★値
            ＝ 放課後等デイサービスの過去の架電実績が計算済みの数字として残った
            さらに 2行目の見出し（稼働日／コール数／通電数…）が落ちていた
  作った側の申告  「活動FB 0行（見出しだけの器）」 ── ★逆だった。
                  入っていたのは見出しではなく実績値
起きる事故  児発・Ａ型のリストを開いた営業が「この種別で24件かけてアポ1件」と読む
```

- **★`read()` は数式を評価した結果を返す。** 値として読むと数式かどうか分からない。
  **複製した器を検分するときは `read_formulas()` で1回開く。**
- **★参照先が空の集計行は、数字が残っているほど危ない。** 0なら気づくが、
  前案件の実測値はもっともらしく見えるので誰も疑わない。
- **★「器だけ複製した」は中身を見た根拠にならない。** 補助タブ・集計行・注記行は、
  タブ本体の行数を数えても検出できない（本体は正しく0行でも、集計行に値が残る）。

## どうするか

```
複製したタブは  ① read_formulas() で数式か値かを見る
                ② 数式なら参照先が新しい器の中に在るかを見る
                ③ 値なら「前の案件の実績かどうか」を疑う。空にするか見本の数式へ戻す
渡す前に        補助タブ（集計・トーク・メモ）を1枚ずつ開く。本体だけ数えて終わらない
```
