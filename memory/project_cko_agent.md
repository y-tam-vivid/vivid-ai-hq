CKOエージェントは **「ロビン(CKO)」**。ふくち。グループの最高ナレッジ責任者(担当 y_tam@vivid-global.com)。名前は ONE PIECE のニコ・ロビン。冷静・博識、一人称「ロビン」。担当: 会議準備、議事録の保全・読み解き・引き出し、リサーチ・情報整理。命名体系は [[project-agent-naming]]。2026-07-06 構築。

**設計思想(重要)**: ユーザーの窓口は**ビビに一本化**。ロビンは**裏方**として成果を作り、Notion受け渡しページ経由でビビの朝ブリーフィングに集約表示される(ユーザーはロビンと直接やり取りしない)。

**構成部品**
1. **呼び出し型サブエージェント**: `~/.claude/agents/cko.md`(name: `cko`)。「ロビンに〜を調べて/この会議の準備をまとめて」で呼び出し可。
2. **会議準備ルーティン**: routine `trig_01QdUn5SRmP6LS1pPv2zbgce`「ロビン(CKO)本日の会議準備」。**毎朝7:40 JST**(cron `40 22 * * *` UTC、ビビの8:04より前)。接続=Google-Calendar/Gmail/Slack/Notion。本日の商談・重要会議をカレンダーから拾い、直近のメール/Slack文脈から目的/前提/議題/進行/決めるべきこと/準備物/論点を組み立て、受け渡しページを replace_content で上書き。**Phase A(議事録連携なし)**。
3. **受け渡しページ**: 「📅 本日の会議準備(ロビン→ビビ 受け渡し)」page id `3957b156-8b57-81e2-8b25-e98be73250d0`(親=ロビン拠点「🧠 ロビン(CKO)ナレッジ室」page id `3957b156-8b57-81e4-a2a6-cd9e804f580c`)。ビビの朝ブリーフィングが収集6でこれを fetch し「### 本日の会議準備」に集約(ビビ自身は計算しない)。

**次のステップ = Phase B**: 別タブで議事録DBが定まったら、その data source ID をロビンに共有し、会議準備に「前回の決定・宿題・積み残し」を連携。要件は [[project-secretary-agent]] 記載の引き継ぎ書ページ(id `3957b156-8b57-8167-9355-e365a9029e26`)参照。キモ=カレンダーと議事録DBの「相手/会社」表記一致(entity matching)。初回検証は 7/7 朝(ロビン7:40→ビビ8:04)。
