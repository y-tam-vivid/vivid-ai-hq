# 詳細ページの「戻る」は、その項目が載っている★一覧へ返す（2026-10-13 有璽氏）

有璽氏「協力団体詳細ページの下部にある『この調査に関わっている人たちへ戻る』を
**『協力団体一覧へ戻る』に変更し、リンクも協力団体の場所になるように**設定してください」

## 何が起きていたか

JFBI の協力団体の詳細ページ4枚で、下部のボタンがこうなっていた。

```
出していたもの   ラベル「この調査に関わっている人たちへ戻る」  飛び先 /#team
あるべきもの     ラベル「協力団体一覧へ戻る」                  飛び先 /#partners
```

協力団体の一覧（`#partners`）は、`#team` という大きい節の★中にある。
こちらは**実装の入れ子**（親の節）を戻り先にしていた。
有璽氏が見ているのは**読む人の道**で、「協力団体の1件を開いた → 協力団体の並びへ帰る」。

## 恒久のルール

- **詳細ページの戻り先は、その項目が実際に並んでいる場所そのもの。**
  親の節・上位のまとまりへ返さない。入れ子の構造は読む人には見えていない。
- **ラベルと飛び先は同じ言葉にする。**「協力団体一覧へ戻る」なら着く先は協力団体の並び。
  ラベルだけ直して飛び先を残す（またはその逆）は、いちばん分かりにくい形になる。
- **残り続けるものが同じ形になっているかを、同じ種類のページ全部で確かめる。**
  詳細ページは増える。1枚だけ直すと、次に足した1枚がまた古い形になる。
  → [[feedback_uniform_unless_reason]]

★パンくず（`トップ／この調査に関わっている人たち／協力団体`）は別物。
  あちらは**どこにいるか**を示す階層なので、親の節を通ってよい。
  ボタンは**次にどこへ行くか**なので、一覧へ返す。
