**「型 × テイストを組み合わせて」だけでは、採用案の画像が"貼り込まれる"。**

## 何が起きたか（2026-08-22）

119番で、採用した3型（A/B/D）と5つのイラスト案（E/G/H/I/J）を使って投稿5本を作らせた。
当方の指示は「**型とテイストを組み合わせて、実際に投稿できる状態で作ってください**」。

有璽氏の評価 ──
> 「119番の直近で作ったやつが**あまりに微妙**やったんやけど、**これってなんでこれになったん？**
>   F119-001〜F119-005 の**5種類とも**。そもそも、**テキストが一番前に来ている**の。
>   なんでこんな形になってんの？ あと、**2枚目以降があまりに微妙**だな。
>   こう、**見せ方、デザインがイマイチすぎる**わ。」

実物を見た結果（F119-001）──

```
1枚目  大きな角丸テキストボックスが左半分を占有
       ★採用案 E の画像そのものが、右下に小さく貼り込まれ、見切れている
       ★「A × E」という内部コード（型×テイストの記号）が投稿画像に印字されたまま
2枚目  ネイビー帯＋見出し＋箇条書きカード2つだけ
       ★イラストが一切ない。テイストが適用されていない
```

## なぜこうなったか

**「テイスト」を、こちらが定義していなかった。**

- E・G・H・I・J は、すべて **`_表紙.png`** という名前で作られた**表紙1枚の案**だった
- 当方はそれを「画風（5枚すべてに適用するもの）」のつもりで「組み合わせろ」と言った
- Manus は「**その画像を素材として使え**」と受け取り、**表紙へ貼り込んだ**
- 2枚目以降にはテイストの定義が無いので、**従来の図解パターンのまま**残った

```
当方の意図    テイスト＝画風。5枚すべてをその画風で描き起こす
伝わった意味  テイスト＝素材。その画像を配置する
```

**「揃えろ」で型を潰し、「こだわらなくていい」で世界観を外しかけたのと、同じ構造。**
指示語（組み合わせる）に対象と意味を添えていない。

## どう指示すべきか

- **「テイスト」を使うなら、それが何を指すかを定義してから渡す。**
  「E のテイスト＝リアル人物イラストの画風。**その画風で5枚すべてを新規に描き起こす**。
  　E の表紙画像そのものを貼り込むことではない」
- **表紙だけの案を採用したら、「2枚目以降をどうするか」を必ず同時に決める。**
  表紙案は表紙の答えでしかない
- **内部コード（A×E などの記号）を成果物に出さないことを明示する。**
  作業用の識別子が投稿画像に残る
- **完成したら1本を全枚めくって見る。** 表紙だけ見て良し悪しを判断しない
  （今回、こちらは表紙コンタクトシートだけ見て「完成」と報告していた）
