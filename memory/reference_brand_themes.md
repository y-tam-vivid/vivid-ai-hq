## 切り替えの設計（フランキー案・着手前）

```
themes/{fukuchi, f119, tane}.json を1テーマ1ファイル（色・フォント・ロゴパスの3点のみ）
  → 各スキルは「テーマキー」を1つ受け取るだけ。スキル側が配色を書くのを禁止
  → 専用テーマが無い場合（NPO等）は ふくち。を既定フォールバック
  → 新テーマは JSON を1本足すだけ。出力コードは変更しない
```

**★テーマキーをどこで持つかは未決**（NotionイベントDBに列を足すか／毎回指定か）。
